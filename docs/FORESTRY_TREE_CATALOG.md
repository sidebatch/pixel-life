# FORESTRY_TREE_CATALOG

상태: **50종 이미지·게임 데이터 연결 완료 / 4~10단계 맵 배치 대기**
기준일: 2026-10-04
프로젝트 반영: 2026-10-04

## 0. 목적

Pixel Life 벌목 확장을 위한 나무 50종의 마스터 카탈로그다.

- Tier 1–7: 실제 나무 35종
- Tier 8–10: 판타지 나무 15종
- 기존 8종 ID는 유지한다.
- 이 문서는 이미지 제작과 게임 데이터 연결의 기준 문서다.
- 50종의 이름·나무·그루터기·목재 아이콘·도끼 제한·임시 HP/XP/가격이 등록됐다.
- 기존 저장을 보호하기 위해 참나무를 포함한 기존 수종의 현행 난이도는 유지한다.
- 실제 수종의 경도는 초기 Tier 선정 때 참고한 배경 정보다. **이 제작 카탈로그의 필수 필드가 아니며**, 게임 HP 공식이나 플레이어 표시 정보로 사용하지 않는다. 실제 HP/타수는 별도 밸런스 문서에서 정한다.
- 도감 설명은 짧고 기억에 남게 유지한다.
- 특정 지역성이 강하면 지역명을 직접 쓰고, 넓게 분포하면 기후·권역으로 표현한다.

기준 설계:
- `FORESTRY_10_STAGE_DESIGN.md`
- `FORESTRY_TIER1_ASSET_BRIEF.md`
- `LIFE_ASSET_STANDARD.md`

## 1. 기존 ID 보호

다음 기존 ID는 삭제·재사용·변경하지 않는다.

`oak`, `pine`, `birch`, `maple`, `spruce`, `willow`, `cypress`, `broadleaf`

> 표시명이나 Tier를 재해석하더라도 내부 ID와 기존 보유/저장 연결은 유지한다.

### 기존 이름과 신규 이름의 확정 매핑

| 내부 ID | 현재 게임 표시 | 이 카탈로그의 표시 | 목재 아이템 ID | 처리 |
| --- | --- | --- | --- | --- |
| `cypress` | 편백나무 | **편백나무** | 기존 `cypress_log` | ID·기존 보유 수량 유지, 표시명 변경 완료 |
| `cedar` | 삼나무 | **삼나무** | 신규 `cedar_log` | 새 수종·새 목재 추가; 기존 `cypress_log`를 변환하지 않음 |

두 이름은 함께 변경했다. `cypress`의 현행 단계는 3이며 카탈로그 단계 2로의 재배치는 아직 적용하지 않았다. `cedar`는 현행 기본 도끼로 벨 수 있는 단계 1이다. `broadleaf` → 플라타너스는 이 목록의 표시명/원화 대응안이며 기존 `broadleaf_log`를 삭제하지 않는다. 기존 그림이 플라타너스로 읽히는지는 추후 시각 확인한다.

## 3. 단계별 방향

### Tier 1–3
익숙한 실제 나무 중심. 플레이어가 수종 차이를 쉽게 익히는 구간.

### Tier 4–5
세계적으로 유명하거나 생김새가 강한 실제 나무가 늘어난다.

특히 바오밥과 세쿼이아는 목재 경도만으로 Tier를 결정하지 않는다.
줄기 크기와 거목성은 이후 HP 설계에서 별도로 반영한다.

### Tier 6–7
생소하더라도 실제로 존재하며 목재 특성이 강한 수종을 배치한다.
도감에서 새로운 지식을 얻는 구간이다.

### Tier 8
현실과 판타지의 경계. 실제로 있을 법한 고대 숲 분위기를 유지한다.

### Tier 9
자연에서 보기 어려운 색과 형태가 등장한다.

### Tier 10
벌목 콘텐츠의 시각적 최종 구간.
각 나무는 줄기/수관/뿌리/내부색/전체 분위기 중 서로 다른 핵심 요소를 가진다.

## 4. 이미지 제작 계약

각 **신규 수종**은 다음 3장으로 제작한다.

1. 살아 있는 나무: `120×144` 투명 PNG
2. 그루터기: `96×96` 투명 PNG
3. 목재 아이콘: `96×96` 투명 PNG

경로:

- `incoming/forestry-chat/trees/{id}.png`
- `incoming/forestry-chat/stumps/{id}.png`
- `incoming/forestry-chat/items/{id}.png`

기존 8종의 **살아 있는 나무와 그루터기**는 우선 유지한다. 단, 목재 아이콘은 사용자 제공 [목재 아이템 스타일 예시](references/forestry-item-style-2026-09-28.png)처럼 나이테·껍질·수종을 암시하는 잎/열매 등이 읽히는 **일관된 새 아이콘 후보**를 기존 8종까지 제작한다. 예시 이미지 전체는 글씨·배경이 있는 비교판이지 게임용 투명 PNG가 아니다. 96×96에서 나이테/껍질의 차이를 먼저 살리고, 장식 때문에 통나무가 가려지지 않게 한다. 작은 Android 3열 가방 카드에서 비교한다.

이 경우 새 수종 42종×3장=**126장**, 기존 8종의 목재 아이콘 후보 **8장**으로 제작 검토 대상은 총 **134장**이다. 후보는 `incoming/forestry-chat/items/{id}.png`에 두고, 현재 `assets/forestry/items/{id}.png`는 승인·검수 전까지 덮어쓰지 않는다. 기존 나무/그루터기 그림을 교체해야 한다면 역시 별도 후보로 제시한다.

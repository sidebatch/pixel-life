## 배포 범위

- 마을 굴 → 던전 갈림길 → 10개 지역 출입. 총 60종·110마리.
- 왜가리·아르마딜로로 두 불쾌한 외형을 교체하고 브락·보른을 재제작.
- 우두머리 10종의 지역색 후광·빛고리·금색 픽셀 왕관, 동작 줄이기 지원.
- 관련 그림 33개 PNG와 구성·밸런스·그림 제작·프롬프트 문서.

기존 동물 5종의 전투는 유지하며 새 55종은 외형 미리보기다. 새 몬스터 전투·드롭·경험치·조합·철검은 아직 구현하지 않았다. 이름 변경과 그림, 우두머리 식별 연출을 별도 전투 기능으로 해석하지 않는다.

# 벌목 진행·밸런스 표

기준: 사용자 제공 「Pixel Life 벌목 시스템 최종 설계 문서 v1.3」. 아래 **수치는 첫 플레이 테스트용 임시 밸런스**이며, 구조(도끼 단계로 나무 제한, 완료 보상, 저장, 상점 강화)는 구현 기준이다. 실제 값의 단일 기준은 `src/data/life-content-data.js`다.

후속 방향: [`LONG_TERM_CONTENT_DESIGN.md`](LONG_TERM_CONTENT_DESIGN.md)에서 **낮은 도끼로도 상급 나무를 매우 느리게 벨 수 있는 방식**을 요청했다. 따라서 이 문서의 나무별 최소 도끼 단계는 **현행 구현 설명이지 최종 장기 규칙이 아니다**. 내구력·파손·마을 수리는 구현됐으며, 소프트 난이도 변경 시 기존 철 도끼까지의 도달감, 종별 보상/시간, 부분 HP·저장, 기존 장비 소유권을 함께 검증한다.

10단계 이름·단계당 기본 5종(총 50종)의 전 세계 실제/판타지 나무 확장과 고장 규칙은 [`FORESTRY_10_STAGE_DESIGN.md`](FORESTRY_10_STAGE_DESIGN.md)를 본다. 도끼 10종, 나무·그루터기·목재 50종, 숲 12개, 단계별 생성, 실제 제작 레시피, 상점·가방·저장·나무 도감, 내구력·수리·고장·빈손은 적용됐다. 기본 도끼는 사용자 결정에 따라 무료 수리형이 아니라 **내구도가 닳지 않는 장비**다. 낮은 도끼의 소프트 난이도만 미구현이다. 50종 제작 목록은 [`FORESTRY_TREE_CATALOG.md`](FORESTRY_TREE_CATALOG.md)에 있다.

현행 완전 벌목 드롭은 `0/1/2/3개` 균등 확률로 평균 1.5개다. 목재가 나오지 않아도 벌목 XP·도감 발견·벤 횟수는 지급하며 무획득 전용 문구는 표시하지 않는다. 실제 벌목 XP는 아래 수종 데이터 기준값의 5%를 반올림하며 최소 1이다. 수리비 인상으로 늘어난 코인 파밍에서도 Lv.100이 최종 장비보다 먼저 되지 않게 조정했으며, 공통 생활 스킬 요구량과 기존 저장 누적 XP는 유지한다.

> 아래 날짜별 문단은 단계적으로 적용해 온 제작 기록이다. 당시의 `미적용`, `16종` 같은 표현은 현재 상태가 아니며, 최신 범위는 이 문서의 첫머리와 [`HANDOFF.md`](HANDOFF.md)를 우선한다.

청금 도끼 재료는 강철 도끼로 얻을 수 있다. 4~10단계 나무는 신규 숲 7개에 배치됐고 각 단계 도끼로 벌목할 수 있다. 5~10단계는 바로 이전 단계 숲의 목재만 사용하므로 아직 얻을 수 없는 상위 재료 때문에 진행이 막히지 않는다. 위 목재 수량은 전체 기능 확인용 임시값이며 최종 밸런스에서 조정한다.

준의 도구점에는 열 도끼가 모두 보인다. 미구매 장비는 각 재료·코인 요구량을 표시하되 실제 구매는 현재 보유 최고 단계의 바로 다음 도끼만 가능하다.

철 도끼 재료는 기본 도끼로 얻고, 강철 도끼 재료는 철 도끼로 얻는다. 따라서 상위 등급 나무를 먼저 베어야 강화되는 순환 잠금은 없다. 도끼 단계는 벌목 레벨과 별도이며, 벌목 레벨이 높아도 미장착 상위 도끼를 대신하지 않는다. 일반 통나무(옛 저장 데이터)는 계속 개당 12코인에 팔고 밭 확장에도 사용하지만 도끼 재료에는 포함하지 않는다.

숲 1-2는 남쪽 입구에서 북쪽으로 진행한다. 입구 주변에도 참나무·소나무·자작나무가 있으며, 같은 종은 숲 1-1과 똑같이 기본 도끼로 벤다. 중급 나무는 중간 구역, 상급 나무는 북쪽 구역(`y≤23`)에서 생성한다. 단풍나무의 붉은 잎과 가문비나무의 청록색 가지는 참나무·소나무와 한눈에 구별되도록 별도 그림을 사용한다.

완전히 벴을 때 해당 나무 목재 0~3개와 실제 종별 XP를 한 번만 준다. 0개여도 XP·도감·벤 횟수는 지급한다. 중간 타격은 보상이 없고 남은 HP를 저장한다. 벤 나무는 현실 시간 5분 후 재생하며 게임을 꺼도 시간이 흐른다. 준의 도구점 `도끼` 탭에서 다음 도끼·재료·코인 정보를 보여주고 구매한다. 구매는 보유 도끼만 늘리며 자동 장착하지 않는다. 가방 장비 탭에서 직접 도끼를 장착해야 벌목 동작과 나무 단계에 반영된다. 평상시 캐릭터 위에 떠 있던 도끼 레이어는 숨긴다. 벌목 중에는 새 캐릭터 4방향 × 준비·휘두름 8칸 스프라이트와 현재 도끼 이미지를 결합한다. 준비 270ms 후 휘두름 타격 프레임에 피해·체력바·나무 조각·효과음을 함께 적용하고, 전체 동작은 700ms 유지한다.

내구도는 실제 피해 타격에만 대상 나무 단계만큼 감소한다. 0이 되는 타격은 정상 적용한 뒤 빈손이 된다. 마을 준의 도구점에서는 파손 여부와 무관하게 최대치보다 조금이라도 닳은 유료 도끼를 손상 비율만큼 수리할 수 있다. 예를 들어 철 도끼 126/180(70%)은 45코인이다. 사용 중인 부분 손상 도끼는 수리 후에도 장착을 유지하고, 망가져 빈손이 된 도끼만 가방에서 다시 장착한다. 같은 탭에서 `귀환석`(`Return Stone`)을 100코인에 살 수 있다. 장소와 관계없이 사용할 때마다 1개가 소모되고 마을 북쪽 입구로 이동하므로 마을에서 잘못 사용해도 환불되지 않는다. 다음 플레이 테스트에서는 25% 무획득의 체감, 5분 재생, 단계별 시간, 도보/귀환석 수리 왕복 빈도, 파손 안내를 확인한다. 공통 Lv.1–100 XP 곡선은 유지하고 벌목 획득량만 5%로 조정했다. 기존 저장의 누적 XP와 레벨은 강제로 초기화하지 않는다.

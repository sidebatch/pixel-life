# 낚시 경제·성장 기준선 — 16단계

정리일: 2026-10-08. 실제 74종·10개 서식지·현재 6종 낚싯대를 기준으로 한다.

## 변경 범위

같은 시간/날씨/낚싯대를 비교했을 때 빙하가 심해보다 불리한 조합이 기존 기준에서 24개였다. 높은 승선권 비용과 낮에 많이 나오는 설빙어의 낮은 판매가가 주요 원인이다. 전설어 또는 좋은 날씨가 나와야만 상위 항로의 이득을 얻는 구조를 피하기 위해 빙하의 기본 수익을 조정했다.

| 빙하 어종 | 이전 기준 판매가 | 현재 기준 판매가 |
| --- | ---: | ---: |
| 메로 | 190 | 280 |
| 설빙어 | 75 | 160 |
| 빙하송어 | 210 | 300 |
| 극지대구 | 340 | 480 |
| 그린란드상어 | 390 | 550 |

기준 판매가이며 실제 획득 가격은 크기/낚싯대/최대 크기 보정을 포함한다. 북극곤들매기 920·오로라빙어 2,000 및 다른 69종의 가격은 유지한다. 기존 가방의 물고기는 획득 시 저장된 `price` 그대로 판매하며 재평가하지 않는다. 앞으로 새로 잡은 위 다섯 어종부터 새 값이 적용된다.

승선권은 얕은 300·중간 900·심해 2,400·빙하 4,800코인, 모두 **앱 화면 표시 시간 10분**으로 확정한다. 현재 운항/티켓 저장을 이행하거나 시간을 초기화하지 않는다. 만료 시 진행 중인 한 번의 낚시는 획득/취소 후 귀항하는 계약을 유지한다.

XP·요구 XP 곡선·어종 Weight·시간/날씨·연속 동일 어종 보정·현재 6종 장비 효과와 재료·노선 해금·도감·보상·음향/그림은 변경하지 않는다. 기본 낚싯대가 74종 모두에 도전할 수 있는 규칙도 그대로다.

## 실제 로직을 사용하는 계산

- `scripts/lib/fishing-balance.mjs`가 실제 데이터와 추첨/크기/가격/XP/시간/날씨/장비 함수를 읽는다. 10서식지×4시간대×3날씨×6낚싯대 = **720개 조건**에서 첫 시도 확률과 장기 최종 확률을 보고한다.
- 같은 물고기 3회 이후 반감은 단순 독립 추첨으로 대체하지 않는다. 어종별 연속 1/2/3회 이상 상태의 전이 분포를 수렴시켜 장기 확률과 가격/XP를 구한다. 전설 첫 발견 시도 수는 목표 어종을 흡수 상태로 삼아 평균/중앙/상위 90%를 계산한다. 적격 조건이 고정됐을 때의 시도 수이며 실제 날씨 기다리는 시간을 포함한 발견 보장은 아니다.
- 가격은 실제 `calculateFishPrice`와 크기 보너스로 2,000개 표본을 적분한 근사값이다. 큰 개체의 1.5배 가격과 반올림도 포함한다.
- 기준 조작 오버헤드는 입질 반응·결과 확인·다음 입력 합계 3초다. 0초 빠른 입력과 8초 느린 입력도 검사한다. 처음 난간까지 15초, 승선/항구 이동/판매 왕복 45초를 가정한다. 이는 실제 Android 측정값이 아니며 측정 후 `--overhead`로 다시 계산한다.
- 정적인 비교는 조건별 수익 역전을 찾는 용도다. 실제 시간/날씨가 계속 바뀌는 운항과 레시피 파밍·맹목적 도감 순회는 `scripts/lib/fishing-progression.mjs`에서 실제 시계·날씨·캐스팅 당시 조건 고정·무작위 대기·반복 보정·장비 구매·최초 보상·승선 비용을 사용해 별도로 표본을 만든다.
- 정적 분당 XP는 반복 획득 XP만 포함한다. 장비 성장 모델은 실제 5종 코인/10종 XP/20종 낚싯대 보상도 포함한다. 일반 운항 표본 수익에는 최초 코인 보너스를 섞지 않는다.

## 항로 비교

기본 낚싯대·조작 오버헤드 3초에서 모든 12개 조건의 범위다. 아래 각 범위의 최저/최고는 서로 다른 조건일 수 있으므로 범위끼리 수익 역전을 판정하지 않는다. 판정은 반드시 같은 조건의 행끼리 한다.

| 항로 | 1회 순수익 범위(승선권 차감 후) | 순수익/분 범위(항구 왕복 포함) | 획득 XP/분 범위 |
| --- | ---: | ---: | ---: |
| 얕은 바다 | 6,034~7,747 | 560~719 | 79~91 |
| 중간 바다 | 9,667~12,580 | 897~1,168 | 84~97 |
| 심해 | 12,413~15,949 | 1,152~1,480 | 111~130 |
| 빙하 해역 | 16,205~23,733 | 1,504~2,203 | 91~117 |

0/3/8초 각각 216개의 같은 조건 인접 항로 비교에서 역전은 **0개**다. 모든 표본 조건에서 정상적으로 운항 시간을 낚시에 사용하는 경우 승선권 회수가 가능하다. 빙하의 XP가 심해보다 항상 많아야 한다는 규칙은 추가하지 않는다. 상위 노선에 입장했다는 이유로 Lv.100을 더 빨리 만들지 않는다.

방치·긴 메뉴/발견 카드 읽기·중도 취소·조기 귀항까지 이익을 보장하는 것은 아니다. 승선권은 기존처럼 소모되며 조기 귀항 환불을 추가하지 않는다. 실제 조작 시간을 측정해 느린 기기에서 전제 자체가 달라지는지 확인해야 한다.

## 희귀도·성장

전설어 확률은 수정하지 않았다. 적격 조건과 기본 낚싯대에서 각 전설의 처음 확률은 약 0.65~0.93%, 연속 보정 포함 평균 첫 발견은 약 106~152시도다. 상위 90%는 약 242~350시도다. 부적격 시간/날씨에는 풀에 들어오지 않으며, 이 숫자는 그때의 대기 시간을 제외한다. 한 번의 운항에서 전설이 나와야 승선권을 회수하는 경제는 아니다. 조건 자체를 공개하는 게임 힌트도 추가하지 않는다.

Fishing Lv.100 요구 누적 XP는 기존 **106,690**이다. 장비 모델은 현재 네 구매 장비의 코인·물고기를 실제로 지불하고 20종 보상 장비를 해금해야 심해 낚싯대를 구입한다. 미래 재료는 보관하고 나머지는 판매하며, 조건이 안 맞는 재료를 즉시 지급하지 않고 실제 시계/날씨를 기다리면서 낚는다. 이는 재료를 아는 파밍 전략의 한 모델이지 모든 플레이 방식의 예측은 아니다.

64개 진행 시드가 모두 심해 낚싯대 준비와 빙하 첫 진입을 완료했다. 해당 모델의 현재 최상위 장비 준비 레벨은 중앙 Lv.55·표본 90%분위 Lv.66·최대 Lv.75, 준비까지 중앙 약 6시간 31분이었다. 최대 누적 XP는 51,628로 Lv.100 요구량의 약 48.4%다. 16개 시드를 전체 자동 회귀에 넣고 65% 성장 예산 상한을 보호한다. 현재 장비 구간을 위해 XP를 임의로 낮추지 않는다.

시간/날씨가 변하는 1,536개 운항 표본(4항로×6낚싯대×64시드)에서 승선권 차감 후 적자 표본은 0개였다. 기본 낚싯대의 평균 순수익은 얕은 약 6,970·중간 10,944·심해 13,106·빙하 20,863코인이었다. 한 번의 운항 결과가 반드시 같은 순서로 나올 것을 보장하지는 않는다.

**7~10단계 낚싯대는 아직 없다.** 이번에 존재하지 않는 최종 10단계의 비용·재료·필요 XP를 검증했다고 말하지 않는다. 17단계에서 신규 레시피를 연결하고 동일 모델을 확장해 최종 장비가 Lv.100보다 먼저 준비되는지 재확인해야 한다. 18단계 수리비가 생겨도 순수익/성장 예산을 다시 계산해야 한다.

74종 완성의 표본은 심해 낚싯대 보유 후 모든 서식지를 순회하는 별도 모델이다. 미발견 조건을 보지 않고 방문 길이를 바꾸며 돌아다닌다. 조건·방문 경로·우연에 따라 매우 오래 걸릴 수 있으며 평균을 플레이어의 완성 시간 약속으로 사용하지 않는다. Lv.100·현재 장비 구매·74종 졸업은 서로 다른 장기 목표다.

맹목 순회 8개 시드는 모두 74종을 완성했지만 약 19~201시간으로 편차가 컸다(표본 중앙 약 117시간, 표본 90%분위 약 158시간). 모든 지역을 계속 균등 순회하는 비효율적인 전략이며 일반 플레이 시간 추정으로 쓰지 않는다. 다만 마지막 조건부 전설어가 오래 남을 수 있는 위험은 분명하다. 사용자의 미발견 힌트 비공개·장기 파밍 방향을 유지하여 이번에 확률을 임의로 올리거나 보장 획득을 넣지 않았다. 실플레이에서 지나친 꼬리가 확인되면 정보 공개가 아니라 희귀 확률/출현 창 조정을 별도 승인 범위로 검토한다.

## 재현과 보호 검사

```text
node scripts/simulate-fishing-balance.mjs
node scripts/simulate-fishing-balance.mjs --overhead=8 --json
node scripts/simulate-fishing-balance.mjs --sessions --samples=64 --tour-samples=8 --output=output/fishing-balance-final.json
node scripts/qa-fishing-balance.mjs
node scripts/check.mjs
node scripts/build.mjs
```

`--samples`는 항로×장비별 운항 표본 및 성장 시드 수다. `--tour-samples`는 74종 맹목 순회 수다. `--sessions`는 실제 획득/저장 상태 함수를 반복하므로 단순 확률 보고보다 오래 걸린다. JSON/이미지 같은 `output/` 산출물은 커밋하지 않는다.

`qa-fishing-balance.mjs`를 전체 검사에 연결했다. 720개 풀·양수 확률/확률합·전설 36조건·기하분포/단일어종 첫 발견 수식·게임 추첨 10만회와 전이 모델 일치·크기 보너스·0/3/8초 수익 역전/승선권 회수·192개 동적 운항·16개 장비 성장을 보호한다. 기존 20종/6장비 기준선·저장 거래 롤백·공통 발견/XP·74종 기본 장비 접근은 별도 기존 검사로 유지한다.

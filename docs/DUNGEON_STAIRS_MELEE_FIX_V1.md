# 던전 계단 가림 · 이동 회피 수정 v1

2026-10-23 · 공개 배포 완료 · [게시·검증 기준](CRAFTING_DUNGEON_DEPLOYMENT_V2.md)

## 재현과 원인

- 남쪽 계단 PNG 전체가 발 기준 깊이 정렬에 들어가 캐릭터보다 나중에 그려졌다. 들녘 사냥터의 내려가는 동작 90%, 올라가는 동작 10%에서 캐릭터 픽셀 차이가 0으로 완전히 가려지는 것을 재현했다.
- 동물 공격은 준비 시작 때 목표 위치를 이미 고정하고 있었지만, 피해 판정은 반경 33.6px 원이고 예고는 30×18px 타원이었다. 실제 발보다 10px 위에 예고를 그려 시각적 범위도 어긋났다. 120ms 전에 옆으로 이동하여 31.14px 벗어난 경우 6종/4방향 모두 피해를 받았다.
- 내 장비 동작 700ms 전체가 이동을 막았다. 타격 전에 이동을 눌러도 공격은 취소되지 않고 270ms에 피해가 들어갔다.

## 수정

계단의 보행 바닥을 **지형 → 계단 → 캐릭터** 순서로 그린다. 실제 발 위치에 따라 전체 캐릭터 리그를 최대 18px 낮춰 내려갈 때 낮아지고 올라갈 때 높아지게 한다. 몸 크기·손·장비·사방향 동작 규격과 계단 PNG는 수정하지 않았다. 높은 굴 입구는 기존 깊이 정렬을 유지한다. 출입 좌표·남쪽 진입·던전 순서·자동 지역 이동도 유지한다.

동물은 계속 준비 시작 때의 위치/방향을 고정하고, 타격 순간의 **현재 화면상 위치**로 판정한다. 논리적 이동 목적지나 `moving` 여부만으로 회피를 허용하지 않는다. 바닥 발 위치(+20px)의 26.4×16.8px 타원을 예고와 피해 판정이 공유하며, 범위 밖이면 명중 난수·피해·피격 무적·타격음 없이 `회피`를 표시한다. 범위 안에 아직 있거나 타격 전에 다시 들어오면 피격될 수 있다. 사거리/벽 검사·무적·일반 동물 600ms/브락 1,500ms 준비·공격 간격·양쪽 명중률 60%·피해량은 유지한다.

사냥 중 검·도끼·낚싯대·낫의 대상 없는 휘두르기는 유효한 이동 입력으로 취소한다. 타격 전 취소는 뒤늦은 피해·보상·내구도 소모가 없고, 타격 후 이동은 이미 처리한 피해를 되돌리거나 중복 적용하지 않는다. 원래 동작 시작 시의 사냥 시계에 700ms 마감 시각을 기록하여 취소/장비 교체로 공격 간격을 줄이지 못하게 한다. 벽/동물 때문에 불가능한 이동은 공격을 취소하지 않는다. 나무 벌목·밭 수확·낚시·사냥터 밖의 기존 동작 잠금은 유지한다. 취소/준비 시각은 세션 상태이며 저장 형식은 버전 2 그대로다.

## 검증

- `scripts/qa-dungeon-combat-browser.mjs`: 소스와 단일 HTML 빌드에서 320/393/1280px. 11지역×상행/하행×3시점의 실제 픽셀 노출·그리는 순서·높이 변화, 모든 계단 출입을 확인했다.
- 6종(일반 5종+브락)×4방향×4상황: 제자리 피격, 120ms 전 이동 회피, 40ms 전 이동으로 아직 범위 안인 경우 피격, 범위에 다시 들어온 경우 피격. 타격 목표 고정·단일 피해·복귀 모션도 확인했다.
- 4장비×타격 전/후의 실제 이동 입력: 동작 취소, 뒤늦은 공격 없음, 피해 1회, 690ms 재공격 거절/701ms 재공격 허용. 막힌 이동과 벌목 잠금도 확인했다.
- 모바일은 실제 터치 이벤트로 조이스틱을 움직이고 PC는 방향키를 눌러 회피했다. 320px에서는 동작 줄이기도 적용했다.
- 기존 사냥·제작 브라우저 검사: 모바일/PC의 중립·개별 반격·벽·메뉴·귀소·처치·재등장·저장, 브락 보상·검 내구도·수리·저장 실패 복구·과거 장비 ID 이전을 통과했다.
- 전체 검사 60 scripts / 164 UI IDs / 533 runtime assets / 74 fish 통과. 최종 취소 간격 보완 후 사냥·제작 단위 검사와 브라우저·빌드를 재확인했다.

결과는 기존 출력 폴더 `output/dungeon-combat-qa/`를 재사용한다. `before-report.json`, `before-393-stairs.png`는 이번 버그의 수정 전 고정 재현이다. 배포용 전체 복사본은 만들지 않았다. 기존 별도 숲 배치 작업은 보존했다.

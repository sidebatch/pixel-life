NPC 상점에 말을 걸면 거래 목록 대신 서비스를 먼저 선택합니다. 서비스를 선택하면 그 기능만 표시되며, ‘서비스 선택’으로 돌아갈 수 있습니다.

| 상점 | 서비스 |
|---|---|
| 준 | 구매 → 귀환석 / 판매 → 목재 / 업그레이드 → 도끼 / 수리 → 도끼 |
| 엘리 | 구매 → 낚싯대 / 판매 → 물고기 / 수리 → 낚싯대 |
| 하루 | 구매 → 씨앗 / 판매 → 작물 / 주문 → 작물 납품 / 꾸미기 → 농장 소품 |
| 농장·가방 꾸미기 바로가기 | 소품 목록으로 바로 진입 |

판매할 물건이 없으면 해당 판매 서비스는 숨깁니다. 수리는 소유한 장비 중 내구도가 닳은 장비만 표시하며, 모두 수리하면 서비스 선택 화면에서도 숨깁니다. 소유한 장비와 도감 보상 장비는 구매 목록에서 제외합니다. 이후 단계 장비의 구매 조건과 재료는 확인할 수 있습니다. 기능 자체가 없는 서비스는 등록하지 않습니다. 모든 구매·판매·수리 조건이 비어 있는 경우에는 이용할 서비스가 없다는 안내와 재방문 조건만 표시합니다.

‘취소 → 전부’ 순서를 물고기·목재·작물에 동일하게 적용했습니다. 귀환석은 별도 구매 화면으로 이동하며 설명은 실제 귀환 위치인 마을 중앙 광장에 맞췄습니다. 기존 가격·거래식·수리식·수동 장착·저장 실패 시 복원·거래 성공 후 효과음은 유지합니다. 장비 재료가 임시 데이터라는 개발 설명은 상점에서 제거했습니다.

확장하려면 `src/market.js`의 `MARKET_SERVICES`에 서비스 이름·노출 조건을 등록하고 해당 NPC의 `MARKET_SHOPS.views`에 추가합니다. 새 동작의 거래 처리 및 검증은 별도로 구현해야 하며, 등록만으로 거래 권한이 생기지 않습니다.

생활 기술 아이콘은 기존 도구·작물·오브젝트 원본을 128px 투명 PNG로 정리해 카드와 레벨업 알림에 적용합니다. 지역 22곳은 이름마다 다른 그림을 사용합니다. 숲 12곳은 해당 숲의 실제 수종을 하나씩 선택하며, 다른 지역 10곳은 연못·밭·산악 호수·폭포·갈대 늪·항구·얕은 바다·중간 바다·심해·빙하를 개별 제작했습니다. 지도 이름과 이동 경로는 바꾸지 않습니다.

# 폭풍·벼락 QA와 시간 진행 보완

2026-10-16 로컬 수정·검증 중. 공개 배포 결과는 검증 후 갱신한다.

기존에는 6게임시간(정상 속도에서 현실 7분 30초)마다 맑음/비/폭풍을 65/27/8%로 추첨했다. 비 또는 폭풍을 보장하는 마지막 구간 보정은 있었지만 폭풍 자체의 최대 대기 시간은 없었다. 기존 코드로 1만 게임 날짜를 시뮬레이션한 결과 6,697일(66.97%)은 폭풍이 없었고, 최장 795분의 폭풍 없는 구간도 관측했다. 따라서 짧은 플레이에서 폭풍을 보지 못하는 것은 충분히 가능했다.

또 실제 프레임 루프가 이동용 최대 40ms 보정값을 달력에도 사용했다. 현실 10분 동안 60/30FPS에서는 480게임분이 흐르지만 20FPS에서는 384분, 10FPS에서는 192분만 흘렀다. 저성능 기기에서는 시간과 날씨 전환이 함께 늦어졌다.

수정한 달력은 전경의 실제 프레임 간격을 사용한다. 이동·충돌은 기존 최대 40ms를 유지한다. 백그라운드에서는 시간이 멈추며 visibilitychange/pageshow에서 시간 기준을 초기화한다. 긴 정지로 복귀할 때 한 프레임의 달력 반영은 최대 1초로 제한한다. 개발자 시간 고정은 유지한다.

기본 추첨과 6게임시간 구간은 유지하되 폭풍이 아닌 구간이 3번 연속이면 다음 구간은 폭풍으로 정한다. 연속 플레이 중 임의의 4개 구간(최대 현실 약 30분)에 폭풍이 최소 1번 있다. 초기 구간은 일부만 남아 있을 수 있다. 보정 카운터는 현재 세션의 상태이며 재접속 시 새로 시작한다. 개발자 날씨 고정에는 보정이 개입하지 않는다.

이 보정으로 최종 폭풍 비중은 기본 추첨값 8%보다 높아진다. 수정 후 동일한 1만 날짜 시뮬레이션은 맑음 20,217구간, 비 8,442구간, 폭풍 11,341구간(28.35%)이며 폭풍 없는 날짜는 0이다. 날씨에 의존하는 물고기의 출현 기회도 그만큼 늘지만 어종별 조건·Weight·가격·보상·장비 수치는 바꾸지 않는다. 기존 저장 키/버전 2·보유 데이터는 유지하며 날씨 효과가 게임 추첨 난수를 소비하지 않게 한다.

벼락은 기존의 서로 다른 위치·길이·꺾임·가지·간격을 유지한다. 번개 때 배경을 더 어둡게 만들던 처리를 약한 밝은 색조와 선 주변의 빛으로 바꿔 작은 화면에서 알아보기 쉽게 한다. 4.8초 단위로 한 번, 약 300~500ms이며 동작 줄이기에서는 벼락과 빛 효과를 계속 생략한다. 비/폭풍과 날씨 이름은 그 설정에서도 유지한다.

- 수치 검증: `scripts/qa-weather.mjs` — 실제 프레임 루프, 5/10/20/30/60FPS, 이동 보정, 비활성/복귀/BFCache, 시간 고정, 자동/수동 날씨, 최악 난수의 보정 상한, 1만 게임 날짜.
- 화면 검증: `scripts/qa-weather-browser.mjs` — 모바일 320/393px·PC 1280px, 자동 폭풍·실제 실행 중인 벼락, 6개 모양, 모든 지역 렌더링, 동작 줄이기, 수동/자동 전환, 저장/게임 난수 불변.
- 전체 검사에 수치 회귀 검증을 포함한다. 결과: `output/weather-qa/`. 수정 전 비교: `baseline.json`.

메뉴·상점 UI 조정: 여행 메뉴는 가방·물고기 도감의 동일 크기 이미지 카드 2개만 보여준다. 낚싯대 장비 전용 화면은 제거했고, 장착은 기존처럼 가방의 장비 탭에서 한다. 엘리의 낚싯대 탭에는 기본·튼튼한·강철·전문가·강태공·심해 6종을 모두 표시한다. 강태공은 도감 보상으로 표기하고 구매 버튼이 없으며, 나머지는 기존 순차 구매 조건을 지킨다. 엘리·준의 장비 목록은 아이콘·이름·대표 효과·상태만 보여주고, 항목을 펼치면 필요한 재료 총량·부족분·구매 버튼을 볼 수 있다. 여행 메뉴 가방·도감 아이콘은 투명 배경 픽셀 아트 `assets/ui/menu/` 2종이다. 최신 Android 실기기에서 좁은 화면의 카드·재료 펼침·뒤로가기를 확인할 것.

목재 이름 표시 조정: 나무 종류별 아이템 이름은 `참나무`, `소나무`처럼 종명만 표시하고, 옛 종류 없는 `log` 아이템은 `일반 목재`로 표시한다. 가방·상점 판매·도끼 재료·벌목 획득 알림·밭 확장 문구에 적용했다. 내부 아이템 ID와 판매가·재료 수량은 바꾸지 않았으며 기존 저장의 긴 이름도 불러올 때 새 표시 이름으로 정규화한다.

이 문서가 다음 개발 세션의 시작점이다. 먼저 이 문서를 읽고, 생활 스킬 성장의 확정 설계 기준은 `docs/LIFE_SKILL_PROGRESSION.md`, 벌목 단계별 임시 수치와 적용 범위는 `docs/FORESTRY_BALANCE.md`, 세부 낚시 사양과 현재 구현 기록은 `docs/FISHING_PLAN.md`, 구조 원칙은 `docs/ARCHITECTURE.md`에서 확인한다. 이후 사용자가 변경을 요청하면 성장 설계도 갱신할 수 있다.

성장 설계와 현재 코드의 관계: 낚시는 독립 Lv.1–100과 Lv.100 이후 숙련도, 획득 직후 +XP·가로 경험치 바·레벨업·새 장비 구매 가능 안내를 연결했다. 벌목도 나무 완전 벌목 시에만 독립 XP·레벨·공통 +XP 바/레벨업을 연결했다. Lv.1–20의 기존 공통 XP 요구량은 성장 곡선의 기준으로 유지했고, Lv.21 이후 곡선과 숙련도 요구량은 임시 수치다. 2026-09-25 초기화 버전부터 이전 저장은 자동으로 불러오지 않는다. `src/data/life-skill-data.js`에 6개 스킬의 공통 메타데이터가 있고 농사는 기본 행동과 저장만 구현했으며 스킬 분류·XP는 미연결이다. 설계 문서의 예시 XP와 보상은 확정 밸런스나 이미 구현된 콘텐츠로 간주하지 않는다.

### 벌목·농사 기본 루프

- 공용 근접 대상 판정으로 출구·NPC·벌목 나무·밭·낚시를 구분한다. 농장의 가까운 밭은 화면 터치로도 선택할 수 있다.
- 숲 1-1의 참나무·소나무·자작나무는 숲 1-2 입구 주변에도 나타나며 어느 맵에서든 기본 도끼로 벤다. 숲 1-2 중간에는 철 도끼가 필요한 단풍나무·가문비나무·버드나무, 북쪽에는 강철 도끼가 필요한 삼나무·활엽수가 있다. 요구 도끼는 지역이 아닌 **나무 종류**로 정한다. 비슷하게 보이던 단풍나무·가문비나무 그림을 각각 붉은 단풍·청록 침엽수로 구별했다. 나무별 HP와 도끼별 피해·재료·코인·XP·통나무 가격은 `docs/FORESTRY_BALANCE.md` 참조. 완전 벌목 시 같은 종 통나무 1~3개를 주고 현실 시간 5분 후 게임을 꺼두어도 다시 자란다. 타격 중 HP는 저장되고 옛 3회 체력 저장값은 새 비율로 변환된다. 숲 가장자리 나무도 단계만 맞으면 벌목 가능하지만 맵 바깥 경계는 계속 막힌다.
- 나무 체력바는 타격 후 나타나며 남은 HP만 색으로 채우고 손실 영역은 검정색이다. HP 0인 막타 직후에는 전체가 검정색으로 잠시 보인다. 타격 중 체력 퍼센트 문구는 표시하지 않는다. 완전 벌목 시에만 종별 벌목 XP를 지급하고 공통 +XP 바·레벨업을 보여 준다. 레벨·XP·보유/장착 도끼는 저장된다. 저장 실패 시 목재·체력·XP·코인·도끼를 함께 되돌린다. 도끼는 마을 오른쪽 준의 도구점 `도끼` 탭에서 목재와 코인으로 구매하고, 가방 장비 탭에서 직접 장착한다. 현재 이동·벌목·낚시 캐릭터는 공통 96px 셀과 발 기준을 사용한다. 장착 도끼는 방향/프레임별 손 좌표에 붙이고 손 그림을 손잡이 위에 표시한다. 남쪽 나무의 자연스러운 가림과 북쪽 휘두름 방향, 타격 시점의 피해·효과음·조각 이펙트는 유지한다. 원본 320px 벌목 시트는 제작 참고용으로 보존하고 런타임에서는 정규화된 192×384 레이어 시트를 사용한다.
- 밭은 처음 4칸을 사용하고 나머지 12칸은 하나씩 코인(후반부는 통나무도 사용)으로 영구 확장한다. 비용은 `src/data/life-content-data.js`에 둔다.
- 엘리의 상점에서 당근·순무·감자·양파·양배추·밀·옥수수·토마토·딸기·호박 씨앗을 구매해 빈 밭에 심는다. 현실 시간 2~35분 뒤 물 주기 없이 수확 가능하며 오프라인 경과 시간도 반영한다. 추가 6종의 성장 시간·씨앗 가격·판매가는 `src/data/life-content-data.js`의 임시 밸런스 값이다.
- 씨앗을 심은 뒤에는 덮인 흙(성장 0~15%) → 공통 새싹(15~45%) → 작물별 어린 잎(45~100%) → 완성 작물(수확 가능) 순서로 보인다. 어린 잎 10종은 완성 작물과 별개의 PNG이며 수확물이 미리 보이지 않는다. 밭 바탕과 잠긴 칸도 작물 그림의 흙 색감에 맞춘다.
- 수확 작물과 종류별 통나무는 물고기처럼 상점에서 수량을 선택해 판매한다. 가방의 `재료` 탭에서 씨앗·수확물·통나무를 각자의 이미지로 확인한다. 종류별 통나무는 종별 판매가를 적용하고, 기존 일반 통나무는 개당 12코인을 유지한다. 밭 확장에는 기존·종류별 통나무를 합쳐 사용할 수 있다. 이전 저장의 일반 통나무도 보존한다. 거래·밭·벌목 변경은 저장 실패 시 되돌린다.

### 낚시 수직 슬라이스

- 낚싯대를 장착한 채 물을 바라보고 상호작용하면 낚시 시작. 도끼 장착 시에는 물가에서도 도끼 휘두름.
- 캐스팅 0.32초 → 기본 낚싯대 기준 랜덤 3~6초 대기 → 입질 → 버튼 입력 → 100% 획득. 장착 낚싯대의 대기 감소 효과는 이 범위에 적용된다.
- 낚싯줄, 찌, 입질 `!` 연출. 투척 중·입질 대기 중·입질 시 상황 설명 문구는 숨기고, 입질은 효과음과 찌 옆의 `!`로만 알린다. 취소·상호작용 버튼은 유지한다.
- 공식 20종 물고기를 `src/data/fish-data.js`에 데이터로 분리
- 현재 지역·시간대·날씨 조건으로 Fish Pool을 필터링한 뒤 상대 Weight로 추첨
- 같은 어종이 3회 연속 나오면 다음 추첨부터 해당 Weight를 절반으로 낮추고, 다른 어종이 나오면 해제
- 새 바닷가 맵과 지역별 어종 밸런스가 정리되기 전에는 마을 연못에서 20종 모두 등장할 수 있다. `src/fishing.js`의 `FISHING_CONFIG.temporaryAllFishAtVillagePond`가 마을에서만 지역 조건을 임시로 풀며 시간·날씨·Weight는 유지한다. 숲의 강과 농장 연못은 각자의 출현 풀을 사용한다. 바닷가 확장 시 이 플래그와 도감 임시 안내를 다시 검토한다.
- 모든 어종에 공통 크기·가격 계산 적용
- 어종별 낚시 XP를 누적하고 Lv.100 및 이후 숙련도까지 계산 (Lv.21 이후 요구량은 임시 밸런스)
- 첫 발견, 획득 수, 최소·최대·평균 크기를 `GAME_STATE.collections.fish`에 기록
- 저장 버전 v1로 코인·Fishing 진행도·인벤토리·발견 통계를 `localStorage`에 저장·복원
- 결과 카드에 등급·크기·가격·경험치 바를 표시하고, +XP·100% 채움·레벨업을 별도 피드백으로 표시
- 낚시 결과창은 모바일 게임 화면의 중앙 부근(높이 56%)에 배치하고, `확인` 버튼을 우하단에 고정한다. 작은 화면에서는 내용 영역만 스크롤하며 희귀도 등장 애니메이션도 창의 중앙 정렬을 유지한다.
- 결과창 제목은 어종 이름만 굵고 크게 표시하고 등급별 글자색을 적용. 등급 글자는 결과창과 도감 카드에 표시하지 않고, 도감 상세에서 확인 가능
- 레벨업 알림은 약 5초 유지되며 X·취소키·Android 뒤로가기로 즉시 닫힘
- 낚시 투척·입질·획득에는 사용자가 제공한 MP3를 각각 `assets/fishing/audio/cast.mp3`, `bite.mp3`, `catch.mp3`로 연결하고, 레벨업에는 `assets/audio/level-up.mp3`, 상점 판매 성공에는 `assets/audio/market-sale.mp3`를 연결한다. 모바일 재생 지연 완화를 위해 다섯 음원을 로딩 시 Web Audio 버퍼로 미리 디코딩하고 첫 조작에서 오디오 컨텍스트를 활성화한다. 미지원·로딩 실패 시 기존 MP3 플레이어로 재생한다. 단일 HTML 빌드에도 다섯 음원을 포함하며 희귀도 축하음은 별도 Web Audio 합성음으로 유지한다.
- 첫 발견은 `NEW` 배지와 도감 등록 문구로 구분
- 월드 메뉴의 물고기 도감에서 전체 20종과 전체·연못·강·바다 필터 제공
- 도감의 연못·강·바다 탭과 상세 서식지는 원래 분류를 유지하며, 상단에 모든 어종의 마을 연못 임시 출현 안내를 표시한다.
- 발견 어종은 설명·등급·획득 수·최소·최대·평균 크기·출현 조건 표시
- 도감 카드를 누르면 중앙 상세 팝업이 열리고, X·뒤로가기로 목록에 복귀
- 미발견 어종은 `???` 카드와 서식지·시간·날씨 힌트 표시
- 20종 전용 96×96 투명 픽셀 아트를 도감 카드·상세 화면·낚시 결과에 연결
- 생성 원본은 `assets/fishing/source/`, 게임용 정규화 파일은 `assets/fishing/`에 분리
- 도감 5종은 코인 300, 10종은 Fishing XP 240, 15종은 희귀어 상세 힌트, 19종은 마지막 단서, 20종은 강태공 칭호와 특별 낚싯대 지급
- 도감 상단에 다음 보상과 진행 막대를 표시하며, 보상은 저장 플래그로 한 번만 자동 지급
- 15종 전에는 미발견 희귀 이상 어종의 정확한 시간·날씨를 숨기고, 19종 달성 후 마지막 한 종의 정확한 단서를 공개
- 희귀·영웅·전설 결과에 각각 16·22·30개의 등급색 파티클, 등장 배너·카드 애니메이션과 상승형 합성 효과음 적용
- `prefers-reduced-motion`에서는 방사형 모션을 숨기고 등급 배너만 유지
- `?debug&fish=fish.catfish`처럼 지정하면 조건·지역과 관계없이 해당 어종이 즉시 입질하여 결과 연출을 반복 검증할 수 있음
- 기본 낚싯대는 처음부터 지급한다. 튼튼한·강철·전문가 낚싯대는 Fishing Lv.5/10/15 달성 후 엘리의 상점에서 잡은 물고기와 코인을 주고 차례로 구매한다. 도감 20종 보상 강태공 낚싯대는 구매하지 않는다. 낚싯대 구매 시 물고기 가방 수량만 줄고 도감 기록은 남으며, 구매 즉시 장착되지 않는다. 가방 장비 탭에서 직접 장착한다. 교환 비용은 `docs/FISHING_PLAN.md`의 임시 수치를 따른다.
- 낚시 경험치 바는 획득·가방 장비 탭에서 확인한다. 낚싯대 전체 목록과 잠금 조건·효과·재료는 엘리 상점의 낚싯대 탭에서 확인하며 장착은 가방에서만 한다.
- 장착 장비의 입질 대기 감소, 희귀 이상 Weight 증가, 큰 개체 보정을 실제 낚시 결과에 적용
- 장착 낚싯대 ID를 저장·복원하고 유효하지 않거나 잠긴 저장값은 기본 낚싯대로 보정
- 획득 물고기를 `GAME_STATE.inventory`에 한 마리씩 추가하고 저장·복원
- 월드 메뉴에는 가방·물고기 도감의 같은 크기 픽셀 아트 이미지 카드만 표시한다. 낚싯대 장비 전용 메뉴와 월드·디펜스·생활의 비동작 안내 카드는 제거했다. 가방은 물고기·장비·외형·재료 네 탭이며 모두 3열 이미지 카드형 바둑판으로 표시한다. 물고기·재료에는 오른쪽 위 보유 수를 표시하고, 장비·외형에는 수량 대신 별도 i 상세 버튼을 둔다. 이름은 PC 커서·키보드 포커스·모바일 선택 때 보인다. 물고기 개체별 크기·판매가는 목록에 노출하지 않지만 저장 데이터에는 유지한다. `장비` 탭은 보유 도끼·낚싯대 카드 즉시 장착과 활성 무기 하나의 밝은 테두리/✓를 지원한다. `외형` 탭은 옷·가방 구역 각각 3열·부위별 독립 착용이며 모자/헤어 선택은 없다. 정보 팝업은 X·취소·뒤로가기로 닫는다. 판매는 가방에서 하지 않는다.
- 마을 남쪽 길가의 빈 공간 `(27,34)`에 5×4타일 충돌 영역을 갖춘 상점 PNG(`assets/buildings/elli_market.png`)를 배치했다. 지붕·벽이 보이는 좌우·뒤쪽 타일을 모두 막고, 문 앞 `(29,38)`의 엘리까지 기존 남쪽 길에서 짧은 길을 연결했다. 표지판은 연못 옆 원래 자리로 되돌렸다. 엘리는 물고기·작물 판매와 씨앗·낚싯대 구매를 담당한다. 마을 오른쪽 무기 그림 작업실(`carpenter_workshop`) 앞 `(30,20)`에는 임시 NPC 준이 고정으로 서서 통나무 판매와 도끼 구매를 담당한다. 두 NPC를 바라볼 때 `상점`이 나타나며 서로의 거래 탭은 보이지 않는다. 월드 메뉴나 가방에서는 거래하지 않는다.
- 판매창에서 어종별 `−`·`+`·`전부`로 수량을 선택하고 예상 합계를 확인한다. 하단에는 `나가기`와 `선택한 물고기 판매` 버튼을 나란히 두며, `나가기`는 상단 X·뒤로가기와 같은 닫기 경로를 사용한다. 같은 어종의 판매 개체는 낚은 순서가 빠른 것부터 정하며, 각 개체의 저장 가격을 합산한다. 판매 확정 시 선택한 물고기만 차감하고 코인을 올려 저장한다. 저장 실패 시 둘 다 되돌린다.
- 판매 성공 후 판매창 상단 보유 코인과 월드 HUD 코인이 약 0.9초에 걸쳐 증가하고, `+금액` 배지와 사용자 제공 돈 소리가 재생된다. 저장 실패 시 소리·증가 연출은 실행하지 않는다. 모션 감소 설정에서는 숫자를 즉시 확정한다. 판매창을 닫거나 다시 열 때 이전 판매의 배지·코인 강조 효과를 지우고 최종 코인 숫자로 맞춰, 재진입 시 과거 판매 연출이 다시 나타나지 않게 한다.
- 화면에 표시되는 돈에서 `G` 접미사를 사용하지 않는다. 상점 보유 코인·가격·합계·판매 완료·증가 배지, 낚시 결과 판매가, 도감 보상 안내에 적용하며 내부 코인 값과 저장 형식은 그대로다.
- 새로고침 후에도 코인·남은 물고기가 유지되며, 판매해도 도감 발견 기록은 보존한다. 상점은 씨앗 구매와 물고기·통나무·작물 판매를 지원한다. 미끼 등 추가 품목과 요리는 아직 없다.
- 모바일 `낚시 취소` 버튼 제공
- 취소 버튼은 조작 버튼 위에 표시되며, 취소는 `click` 시점에 처리해 모바일 고스트 클릭을 막는다.
- 낚시 중 메뉴 버튼은 보이지만 흐리게 표시되고 터치는 비활성화된다.
- 캐스팅부터 결과창을 닫을 때까지 메뉴 버튼은 실제 `disabled` 상태로 유지되어 키보드·접근성 입력으로도 겹침 메뉴가 열리지 않는다.

## 3. 아직 구현되지 않은 항목

낚시가 완성된 상태는 아니다. 현재 코드는 전체 시스템을 검증하기 위한 첫 수직 슬라이스다.

- 바닷가 실제 월드와 낚시터, 임시 마을 전체 어종 출현 정책 정리
- 씨앗 외 추가 구매 품목과 요리
- 벌목 도끼 3단계·상점 업그레이드·종별 목재 가격과 4방향×2프레임 전용 캐릭터 모션을 연결했다. 수치와 도끼 손 위치는 모바일 플레이 테스트 후 조정 가능하다. 농사는 이미 플레이 가능하지만 성장 스킬의 분류는 별도 결정이 필요하다. 확정 설계의 초기 6개 스킬에 Farming은 없고 향후 확장 목록에 있다.

중요: 이번 초기화 이후 저장은 각 브라우저의 새 키 `pixel-life.save.v2`(버전 2)에 기록한다. 이전 `pixel-life.save`는 삭제하지 않지만 새 게임은 읽지 않는다. 새 버전을 연 각 기기는 낚시·벌목 Lv.1, 코인 0, 기본 장비부터 다시 시작한다. 이미 열린 옛 탭은 새로고침해야 초기화가 적용된다. 기기 간 서버 계정/저장 동기화는 없다. 도감은 새 저장의 발견·크기 통계를 읽어 표시한다.

시간·날씨도 다음 항목은 남아 있다.

- 날씨 상태가 바뀔 때의 페이드 전환
- 비·폭풍 사운드와 밤 환경음
- 젖은 지면·물웅덩이·바람 반응
- 계절 시스템

## 4. 다음 권장 작업 순서

1. **실기기 Android QA 및 회귀 확인.** 마을 남쪽으로 옮긴 상점의 옆·뒤 충돌, 예전 상점 자리 통행, 엘리 앞 `상점` 버튼, 구매·일부 판매·나가기·뒤로가기를 실제 손 조작으로 확인한다. 숲·농장 이동, 밭 터치, 재접속 후 위치·재고·코인 복원도 함께 본다. 5×4타일 충돌과 길 연결은 자동 검사 및 좁은 브라우저 화면에서 확인했지만 최신 배포본의 Android 실기기 확인은 남아 있다. 문제가 있으면 확장보다 먼저 수정한다.
2. **벌목 플레이 테스트와 밸런스 조정.** 사용자 제공 벌목 v1.3 설계의 도끼 단계·상점 강화·종별 XP·판매가·4방향 × 2장 스프라이트는 연결했다. `docs/FORESTRY_BALANCE.md`의 임시 수치와 도끼 손 위치·전후 레이어를 실제 모바일 플레이에서 검토한다.
3. **농사 성장 분류 결정 후 연결.** 확정 설계의 초기 6개 스킬에는 Farming이 없고 향후 확장 목록에 있다. 수확 XP를 독립 Farming 스킬로 둘지, 기존 Gathering에 포함할지 사용자와 결정한 뒤 저장 형식·피드백·보상을 설계한다. 결정 전에는 농사 레벨이나 보상을 임의로 추가하지 않는다.
4. **코인 사용처와 경제 조정.** 현재 코인은 씨앗·밭 확장에 쓸 수 있다. 그다음 구매 품목을 하나 정해 엘리 상점에 추가하고, 작물 10종의 임시 성장 시간·씨앗 가격·판매가와 나무 5분 재생/통나무 판매가를 실제 플레이 흐름으로 조정한다. 구매·판매·저장 실패 롤백을 함께 검증한다. 미끼·도구·요리는 후보이지 확정 품목이 아니다.
5. **새 낚시 지역.** 바닷가 맵과 낚시터를 추가해 지역별 어종을 확인한 다음 `FISHING_CONFIG.temporaryAllFishAtVillagePond`를 제거한다. 새 지역·출구·저장 복원과 도감의 임시 출현 안내를 함께 점검한다. 날씨 전환·환경음 등 연출은 이 핵심 루프 뒤의 후속 작업이다.

우선순위는 안정성 → 이미 가능한 벌목의 성장 체감 → 농사 성장 방식 결정 → 경제 → 새 지역이다. 기능 구현을 시작할 때는 한 단계씩 완료·검증한 뒤 다음 단계로 넘어간다.

현재 구현·검증 범위와 과거 회차별 결과는 `QA_REPORT.md`에 구분해 기록했다. 브라우저 크기 모의 확인을 Android 실기기 확인으로 취급하지 않는다.

## 6. 개발자 테스트

`?debug`가 있으면 게임 화면에 시간·날씨 조절 패널이 표시된다.

```text
?debug&time=06:30&weather=clear   새벽
?debug&time=12:00&weather=rain    낮+비
?debug&time=18:30&weather=rain    저녁+비
?debug&time=22:00&weather=storm   밤+폭풍
```

예시: https://sidebatch.github.io/pixel-life/?debug&time=22:00&weather=storm

키보드 보조 기능:

- `F3`: 월드 충돌·배치 디버그
- `[` / `]`: 디버그 상태에서 30분 단위 시간 조절
- 방향키/WASD: 이동
- Space/Z: 상호작용
- X/Escape: 취소

모바일 낚시 QA:

1. 가방의 장비 탭에서 낚싯대를 장착하고 물가를 바라볼 때 상황 문구가 `낚시`인지 확인한다. 도끼를 장착하면 `낚시`가 뜨지 않고 손 버튼/Space/Z가 도끼 휘두름이어야 한다.
2. 손 버튼을 누르면 찌와 낚싯줄이 표시되는지 확인한다.
3. `낚시 취소`가 조작 버튼 위쪽에 보이는지 확인한다.
4. 메뉴 버튼은 보이되 흐리고 눌리지 않는지 확인한다.
5. 취소 후 메뉴가 함께 열리지 않는지 확인한다.
6. 입질 후 손 버튼으로 붕어 결과가 100% 표시되는지 확인한다.
7. 메뉴의 `도감`을 열어 발견 수와 발견 어종 통계가 최신인지 확인한다.
8. 전체·연못·강·바다 탭 전환과 미발견 어종 힌트를 확인한다.
9. 도감을 닫은 뒤 이동과 낚시가 정상적으로 다시 가능한지 확인한다.
10. 발견 어종 카드·상세 화면·낚시 결과에서 같은 전용 물고기 이미지가 표시되는지 확인한다.
11. 도감 상단에 다음 보상 목표와 현재 진행도가 표시되는지 확인한다.
12. 희귀 미발견 어종은 15종 전까지 정확한 시간·날씨가 숨겨지는지 확인한다.
13. `?debug&fish=fish.catfish`, `fish.golden_koi`, `fish.coelacanth`로 희귀·영웅·전설 결과 배너·파티클·효과음을 확인한다.
14. 엘리 상점의 `낚싯대` 탭에서 전체 제품과 Lv.5/10/15·도감 20종 조건을 확인한다. 별도 낚시 장비 메뉴는 없다.
15. 구매한 낚싯대는 가방의 장비 탭에서 눌러 장착한 뒤 새로고침 후 상태가 유지되는지 확인한다. 도끼로 바꾸면 낚싯대의 장착 표시가 사라지고, 다시 낚싯대로 바꾸면 마지막 선택 제품을 기억해야 한다.
16. 낚시 결과의 +XP와 경험치 바가 100%까지 차고 레벨업 후 다음 레벨 진행도로 전환되는지 확인한다.
17. 발견 물고기를 눌러 중앙 팝업을 열고 X·Android 뒤로가기로 도감 목록에 복귀하는지 확인한다.
18. 결과창·도감 카드에 등급 글자 없이 어종 이름만 등급색으로 표시되고, 도감 상세에 등급 글자가 남는지 확인한다.
19. 레벨업 알림이 3초에는 유지되고 약 5초 후 사라지는지, X·뒤로가기·결과창 닫기로 즉시 사라지는지 확인한다.
20. 실제 기기에서 캐스팅 첨벙·획득 성공음의 음량과 겹침을 확인한다.
21. 월드 메뉴의 가방·도감 버튼과 X·게임으로 돌아가기 버튼을 확인한다. 가방의 물고기·장비·재료 탭에서 모두 3열 카드·오른쪽 위 수량 배지·PC 커서/모바일 터치 이름 노출이 되는지 본다. 같은 어종을 2마리 낚았을 때 `2` 배지, 보유 목재·씨앗·작물의 실제 수량, 도끼·낚싯대 중 무기 하나만 장착 표시가 있는지 확인한다.
22. 가방을 X·뒤로가기로 닫고 새로고침한 뒤 물고기 기록과 장착 장비가 유지되는지 확인한다.
23. 마을 남쪽 길가 상점의 옆·뒤로 들어갈 수 없는지 확인한다. 문 앞 엘리에게 다가가 `상점`을 누르면 판매창이 열리고, 어종별 수량·예상 금액·`전부` 선택이 동작하는지 확인한다. 하단 `나가기`로 닫은 뒤 다시 상호작용해 정상적으로 열리는지도 확인한다.
24. 일부만 판매하면 남은 개체 가격이 유지되고 코인·가방·도감이 올바른지 확인한다. 전부 판매·재접속·X·뒤로가기도 확인한다.
25. 판매 성공 후 사용자 제공 돈 소리와 판매창 상단 코인 증가·`+금액` 표시를 확인한다. 창을 즉시 닫거나 모션 감소를 켜도 최종 코인과 저장 데이터가 정확한지 확인한다. 판매 후 창을 닫았다가 다시 열 때 이전 `+금액`·코인 강조 연출이 재생되지 않는지 확인한다.
26. 마을 북쪽에서 숲, 동쪽에서 농장으로 이동하고 각 지역의 되돌아오는 출구를 확인한다. 재접속 시 마지막 지역과 위치가 복원되는지 확인한다.
27. 기본 도끼로 숲 1-1의 나무를 다섯 번 때려 통나무가 1~3개 지급되고, 그루터기에서 반복 보상이 없는지 확인한다. 숲 1-2의 같은 참나무·소나무·자작나무도 기본 도끼로 베어지고, 붉은 단풍나무·청록 가문비나무 등 중급·상급 나무만 각각 철·강철 도끼를 요구해야 한다. 스페이스바/모바일 손 버튼을 눌렀을 때 평상시 도끼가 떠 있지 않고 4방향 준비→휘두름 모션과 손에 쥔 도끼가 확실히 보이며 타격 프레임에 체력 감소·소리가 맞는지 본다. 체력 퍼센트 문구는 없어야 하고, 체력바 손실 부분은 검정색으로 늘며 완전 벌목 때만 종별 +XP가 나온다. 준의 도구점 도끼 구매·재료/코인 차감·가방에서 수동 장착·재접속 후 XP/레벨/도끼/부분 HP 보존·5분 재생, 숲 간 왕복과 강 낚시도 확인한다.
28. 엘리 앞 상점은 물고기·작물·씨앗·낚싯대 네 탭만, 준 앞 도구점은 통나무·도끼 두 탭만 보여야 한다. 낚시 Lv.5에서 붕어 25·잉어 20·코인 1,800으로 튼튼한 낚싯대를 사고, 물고기 수량·코인 차감, 기존 장비 유지, 가방에서 직접 장착, 도감 기록 보존, 새로고침 후 구매·장착 유지까지 확인한다. 심해 낚싯대와 명장의 도끼는 각각 이전 단계를 산 뒤 표시되며, 구매만으로 자동 장착되지 않아야 한다. 준비물이 부족할 때 구매 버튼은 비활성이다. 두 NPC 모두 모바일 뒤로가기와 나가기 버튼으로 닫힌다.
28. 농장 4칸의 시작 밭, 잠긴 밭의 단계별 비용과 구매 후 영구 저장을 확인한다. 부족한 코인·통나무로는 구매되지 않아야 한다.
29. 엘리에게서 씨앗을 사서 빈 밭에 심고, 게임을 종료한 상태로 성장 시간을 넘긴 뒤 수확한다. 같은 밭에서 중복 수확되지 않아야 한다.
30. 가방의 재료 탭과 상점의 씨앗 구매·물고기/재료 판매 탭을 확인한다. 통나무·작물을 일부만 팔고 새로고침해 코인·잔량이 정확한지 확인한다.
31. 숲의 강과 농장 연못에서 낚시가 시작되고, 두 지역의 기본 어종이 서로 다른지 확인한다. 마을 연못의 임시 전체 어종 출현은 유지된다.
32. 숲의 벌목 나무 8종이 서로 구별되고, 벌목 후 대응 그루터기가 보이는지 확인한다. 엘리 상점·가방·밭 창에서 통나무와 씨앗 10종 PNG가 로드되는지 확인한다.

자동 검사는 데이터·충돌·저장·거래 등 핵심 규칙을 확인했고, 일부 화면은 로컬 브라우저에서 확인했다. 위 목록 전체가 Android 실기기에서 통과한 것은 아니다. 실제 손 조작·성능·음량은 별도 확인해야 한다.

현재 기준 요약과 과거 자동·모바일·배포 QA 기록은 저장소 루트의 `QA_REPORT.md`에 구분해 정리되어 있다.

## 7. 배포와 저장소

`main`에 push하면 `.github/workflows/deploy-pages.yml`이 다음 순서로 자동 배포한다.

```text
check → build → Pages artifact 업로드 → GitHub Pages 배포
```

배포 전에는 항상 아래 세 검사를 수행한다.

```bash
node scripts/check.mjs
node scripts/build.mjs
git diff --check
```

현재 `sidebatch/pixel-life` 하나가 공개 소스이자 배포 저장소다. 이전 별도 배포 저장소 `sidebatch/pixel-life-web`은 보관 처리되었으므로 다시 사용하지 않는다.

## 8. 변경 시 지켜야 할 규칙

- 모바일 이동 감각을 PC 수정과 함께 바꾸지 않는다.
- 월드 시간·날씨를 낚시 전용 코드로 옮기지 않는다.
- 새 어종·지역은 조건문 덩어리보다 데이터 파일로 추가한다.
- 통과 가능한 식생은 actor보다 아래에서 렌더링한다.
- 캐릭터와 건물 가림은 기존 Y-depth 규칙을 유지한다.
- 사용자 에셋과 기존 변경을 임의로 삭제하거나 덮어쓰지 않는다.
- 기능 완료 후 검사·빌드·모바일 화면 확인·Pages 성공 확인까지 수행한다.

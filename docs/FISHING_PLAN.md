# Fishing System v0.1 공식 사양

상태: 구현 기준 확정

이 문서는 낚시를 어렵게 만드는 대신, 결과·수집·성장·월드 변화가 재미를 만드는 방향을 고정한다. 낚시에서 검증한 시간, 날씨, 조건부 보상, 도감, 자원 획득 구조는 이후 벌목·채집·퀘스트에도 재사용한다.

## 1. 핵심 철학

낚싯대를 던지면 반드시 무언가가 낚인다.

- 타이밍 실패 없음
- 줄 끊김 없음
- 물고기 도망 없음
- 어려운 미니게임 없음
- 재미의 중심은 “잡을 수 있을까?”가 아니라 “무엇이 나올까?”

기본 흐름은 다음과 같다.

```text
낚시 버튼 → 찌 던짐 → 1~3초 대기 → 입질 → 버튼 한 번 → 무조건 획득
```

입질 후 버튼을 누르는 조작은 손맛을 위한 연출이며, 늦게 눌러도 결과는 실패하지 않는다. 이후 옵션으로 입질 후 자동 획득을 제공할 수 있다.

## 2. 공통 WorldTime

낚시 전용 시간이 아니라 월드 전체가 사용하는 시간 시스템으로 구현한다.

- 게임 1일 = 현실 30분
- 현실 1분 = 게임 48분
- 시간은 프레임마다 계속 흐른다.
- UI는 `HH:MM`으로 표시한다.
- 구현 기본 시작 시각은 현재 UI와 호환되도록 `10:24`로 둔다.
- 개발 중에는 `?debug&time=18:30`으로 특정 시각을 고정할 수 있다.
- `?debug`로 접속하면 게임 화면에 시간 조절 패널이 나타난다.
- 패널의 새벽·낮·저녁·밤 버튼과 `±30분`, `실시간` 버튼으로 화면을 직접 비교할 수 있다.
- F3 디버그 화면과 `[`/`]` 키 조절도 보조 수단으로 유지한다.

### 시간대 판정

| 게임 시간 | 시간대 | 현실 지속시간 |
|---|---|---:|
| 05:00~08:00 | DAWN | 약 3분 45초 |
| 08:00~17:00 | DAY | 약 11분 15초 |
| 17:00~20:00 | DUSK | 약 3분 45초 |
| 20:00~05:00 | NIGHT | 약 11분 15초 |

시간대는 갑자기 바꾸지 않고 전후 약 30분부터 색과 조명을 보간한다.

## 3. 시간에 따른 월드 변화

- DAY: 밝은 하늘, 밝은 물, 약한 그림자, NPC 일반 활동
- DUSK: 따뜻한 주황색 색조, 긴 그림자, 상점 조명 점등 시작
- NIGHT: 어두운 색조, 집·상점·가로등 점등, 어두운 물, 벌레/귀뚜라미 분위기
- DAWN: 푸른 새벽색에서 밝은 색으로 천천히 전환

구현은 전체 화면 색조 오버레이와 물·그림자·조명 계층으로 나눈다. 시간 시스템은 낚시 모듈에서 직접 수정하지 않는다.

## 4. Weather Manager

날씨는 게임 시간 약 6시간 단위로 다음 상태를 판정한다. 현실 기준 약 7분 30초마다 다음 날씨 구간이 시작된다.

| 날씨 | 기본 비율 |
|---|---:|
| `clear` | 65% |
| `rain` | 27% |
| `storm` | 8% |

완전한 순수 랜덤은 사용하지 않는다. 게임 하루 동안 비 또는 폭풍이 최소 한 번쯤 등장하도록 약한 보정을 두되, 같은 날씨가 연속되는 것은 허용한다.

날씨 전환은 시각 효과를 통해 부드럽게 바뀐다.

- `clear`: 기본 조명과 맑은 하늘
- `rain`: 빗줄기, 젖은 색감, 빗소리 준비 지점
- `storm`: 더 어두운 색감, 강한 빗줄기와 번개 준비 지점

## 5. 낚시터

첫 버전은 세 지역을 데이터로 선언한다.

| 지역 | 난이도 | 특징 |
|---|---|---|
| 마을 연못 | 초급 | 시작 지역, 기본 어종 |
| 숲의 강 | 중급 | 시간·날씨 조건 어종 증가 |
| 바닷가 | 중~고급 | 고가·전설 어종 |

낚시 레벨이 낮아도 모든 지역에서 낚시할 수 있다. 장비는 접근을 막지 않고 희귀도·크기·입질 대기시간에 보너스만 준다.

## 6. 낚시 상태 머신

낚시 모듈은 이동 코어와 분리한다.

- `idle`: 낚시하지 않음
- `casting`: 찌를 던지는 짧은 연출
- `waiting`: 1~3초 대기
- `bite`: 입질 연출, 액션 입력 대기
- `catching`: 물고기·크기·보상 계산
- `result`: 결과 카드와 연출
- `cancelled`: 이동·취소로 종료

`waiting`과 `bite` 동안 플레이어 이동을 잠시 잠근다. `bite`에서 버튼을 누르지 않아도 자동으로 획득 처리할 수 있도록 상태를 설계한다.

입력:

- 모바일: 기존 큰 액션 버튼 탭
- PC: `Space`, `Z`, `Enter`
- 이동 입력: 낚시 취소

## 8. 등급과 보상

등급은 `common`, `uncommon`, `rare`, `heroic`, `legendary` 다섯 단계로 고정한다.

- common: 자주 등장, 기본 보상
- uncommon: 일부 조건 필요
- rare: 시간·날씨 조건
- heroic: 낮은 가중치와 조건
- legendary: 특별 조건과 초희귀 가중치

일반 물고기는 간결하게, rare 이상부터 결과 카드·사운드·빛 효과를 차별화한다.

## 9. 크기와 가격

같은 어종도 범위 안에서 소수점 한 자리 크기를 뽑는다. 도감은 발견 수, 최대·최소·평균 크기를 기록한다.

가격은 기본가와 크기로 계산한다.

```text
q = (size - minSize) / (maxSize - minSize)
sizeMultiplier = 0.8 + q * 0.4
q >= 0.95이면 sizeMultiplier = 1.5
finalPrice = round(basePrice * sizeMultiplier)
```

따라서 작은 개체는 약 0.8배, 평균은 약 1.0배, 큰 개체는 약 1.2배, 상위 5%는 1.5배가 된다.

## 10. 중복 피로 보정

같은 어종이 3회 연속 선택되면 다음 선택부터 해당 어종의 Weight를 일시적으로 절반으로 한다. 다른 어종이 나오면 보정을 해제한다. 플레이어에게는 이 규칙을 노출하지 않는다.

## 11. Fishing Level

최대 레벨은 20이다.

```text
nextLevelXP = 60 + currentLevel * 12
```

| 레벨 | 해금 |
|---:|---|
| 1 | 낚시 시작 |
| 3 | 도감 크기 기록 |
| 5 | 튼튼한 낚싯대, 입질 대기 -10% |
| 7 | 희귀 어종 힌트 |
| 10 | 강철 낚싯대, 희귀 이상 Weight +10% |
| 12 | 10% 확률로 추가 물고기 1마리 |
| 15 | 전문가 낚싯대, 희귀 Weight +20% 및 큰 개체 보정 |
| 17 | 전설 물고기 힌트 |
| 20 | 강태공 단계와 특수 낚싯대 퀘스트 |

초보도 운이 좋으면 전설을 잡을 수 있다. 장비는 지역 입장 조건이 아니다. 미끼는 v0.1에서 제외한다.

## 12. 도감

물고기를 잡는 즉시 자동 등록한다. 등록을 위해 기부하거나 소비하지 않는다.

- 물고기는 인벤토리에 남는다.
- 판매는 별도 상점 시스템에서 한다.
- 미발견은 `???` 이미지와 넓은 힌트만 보여준다.
- 발견 후 시간·날씨·서식지 조건을 공개한다.
- 도감은 전체·연못·강·바다 탭을 가진다.
- 선택한 물고기의 큰 이미지, 등급, 크기 통계, 서식지, 조건, 설명을 보여준다.

도감 보상:

| 발견 수 | 보상 |
|---:|---|
| 5종 | 300G |
| 10종 | 낚시 XP 보너스 |
| 15종 | 희귀어 힌트 해금 |
| 19종 | 마지막 미발견 물고기 단서 |
| 20종 | 강태공 칭호와 특별 낚싯대 |

## 13. 에셋 규격

물고기별 투명 PNG를 `assets/fishing/`에 둔다.

- 기준 캔버스: `96×96px`
- 32~48px로 줄여도 실루엣이 구분되는 픽셀 아트
- 물고기 20장
- 찌 기본/입질 2장
- 물튀김 효과 1장
- rare 이상 결과 카드용 이펙트는 코드 도형 또는 별도 에셋으로 결정

권장 파일명은 데이터 ID의 마지막 부분과 일치시킨다. 예: `crucian_carp.png`, `coelacanth.png`.

## 14. 구현 순서

1. `WorldTime` 공통 시스템
2. DAWN/DAY/DUSK/NIGHT 월드 색·조명 보간
3. 건물·가로등 조명
4. `WeatherManager`와 6시간 구간 판정
5. 비·폭풍 시각 효과
6. 낚시 기본 동작: 무조건 성공
7. 지역별 Fish Pool 필터와 상대 가중치
8. 20종 데이터와 크기·등급·가격
9. Fishing XP와 레벨 보상
10. 도감·힌트·수집 보상
11. rare/legendary 결과 연출
12. 판매·요리 등 다른 시스템 연결

1~5는 낚시 전용 코드로 만들지 않는다. 이후 밤 전용 몬스터, 비 오는 날 NPC, 야간 채집, 계절 시스템에 그대로 연결할 수 있어야 한다.

## 15. 완료 기준

- 물가에서 버튼을 누르면 100% 결과가 나온다.
- 결과는 현재 시간·날씨·지역에 맞는 Fish Pool에서 선택된다.
- 같은 어종 3연속 보정이 동작한다.
- 크기·가격·XP·도감·인벤토리가 한 번에 갱신된다.
- 월드 시간과 날씨가 낚시 외 월드에도 반영된다.
- 새로고침 후 수집과 레벨이 유지된다.
- 모바일 조이스틱 감각과 PC 키보드 이동을 변경하지 않는다.
- `node scripts/check.mjs`, `node scripts/build.mjs`가 통과한다.

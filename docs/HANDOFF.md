# Pixel Life 개발 인수인계

최종 정리일: 2026-09-22  
기준 브랜치: `main`  
공개 저장소: https://github.com/sidebatch/pixel-life  
공개 게임: https://sidebatch.github.io/pixel-life/

이 문서가 다음 개발 세션의 시작점이다. 먼저 이 문서를 읽고, 세부 낚시 사양은 `docs/FISHING_PLAN.md`, 구조 원칙은 `docs/ARCHITECTURE.md`에서 확인한다.

## 1. 세션 시작 체크리스트

```bash
git status --short
git pull --ff-only origin main
node scripts/check.mjs
node scripts/build.mjs
node scripts/serve.mjs
```

개발 서버는 `http://127.0.0.1:4173`에서 열린다. `dist/index.html`은 생성 파일이므로 직접 수정하거나 커밋하지 않는다.

스크립트 파일을 추가할 때는 반드시 다음 세 곳의 순서를 함께 맞춘다.

- `index.html`
- `scripts/check.mjs`
- `scripts/build.mjs`

## 2. 현재 구현 상태

### 월드 기반

- 64×48 라일락 연못 마을
- 플레이어 이동·충돌·카메라
- PC 연속 이동 보간과 모바일 픽셀 스냅 분리
- NPC 6명 로밍·대화
- 건물 2채, 입구 상호작용, Y축 가림
- 연결형 길, 물, 식생 레이어, 월드 배치 자동 검사
- 모바일 세로 HUD와 조이스틱

### 월드 시간

- 게임 하루는 현실 30분
- `DAWN / DAY / DUSK / NIGHT` 판정
- 새벽·저녁의 따뜻한 그라데이션
- 밤의 화면 색조, 플레이어 주변 비네팅, 가로등·건물 조명
- 갑작스러운 단색 전환 대신 시간 구간 사이 보간

### 날씨

- `clear / rain / storm`
- 게임 시간 6시간 단위 자동 판정
- 맑음 65%, 비 27%, 폭풍 8%
- 하루 종일 건조하지 않도록 약한 비 보정
- 화면 전체에 독립 분포되는 2겹 비와 3겹 폭풍
- 전체 화면 습윤 색조, 빗방울 파문, 폭풍 번개·플래시

### 낚시 수직 슬라이스

- 물을 바라보고 상호작용하면 낚시 시작
- 캐스팅 0.32초 → 1~3초 대기 → 입질 → 버튼 입력 → 100% 획득
- 낚싯줄, 찌, 입질 `!` 연출
- 현재는 붕어 1종만 획득
- 크기 12~35cm와 크기 기반 가격 계산
- 결과 창에 크기·가격·`+8 Fishing XP` 표시
- 획득 물고기를 현재 세션의 `GAME_STATE.inventory`에 추가
- 모바일 `낚시 취소` 버튼 제공
- 취소 버튼은 가방·설정 위에 표시되며, 취소는 `click` 시점에 처리해 모바일 고스트 클릭을 막는다.
- 낚시 중 가방·설정은 보이지만 흐리게 표시되고 터치는 비활성화된다.

## 3. 아직 구현되지 않은 항목

낚시가 완성된 상태는 아니다. 현재 코드는 전체 시스템을 검증하기 위한 첫 수직 슬라이스다.

- 20종 물고기 데이터와 실제 Fish Pool
- 연못·강·바다 지역 구분
- 시간·날씨 조건별 어종 필터
- 상대 Weight 추첨과 같은 어종 3연속 보정
- Fishing XP의 실제 누적과 레벨
- 도감, 최초 발견, 최대·최소·평균 크기 기록
- 희귀·영웅·전설 결과 연출
- 물고기 PNG 에셋
- 판매, 요리, 낚싯대, 보상
- 인벤토리 화면의 실제 아이템 표시
- 저장과 새로고침 후 복원

중요: 현재 `+8 Fishing XP`는 결과 문구일 뿐 실제 진행도에 더해지지 않는다. 인벤토리도 메모리에만 있어 새로고침하면 사라진다.

시간·날씨도 다음 항목은 남아 있다.

- 날씨 상태가 바뀔 때의 페이드 전환
- 비·폭풍 사운드와 밤 환경음
- 젖은 지면·물웅덩이·바람 반응
- 계절 시스템

## 4. 다음 권장 작업 순서

1. `src/data/fish-data.js`에 공식 20종을 데이터로 분리한다.
2. `src/fishing.js`에 지역·시간·날씨 필터와 상대 Weight 선택기를 추가한다.
3. 같은 어종 3연속 시 해당 Weight를 일시적으로 절반으로 낮춘다.
4. 크기·가격 계산을 모든 어종에 공통 적용한다.
5. Fishing XP, 레벨, 발견 기록과 크기 통계를 `GAME_STATE`에 연결한다.
6. `localStorage` 저장 버전을 정의한 뒤 인벤토리·도감 데이터를 저장한다.
7. 결과 카드와 도감 UI를 만든다.
8. 물고기 20종 이미지를 제작·연결한다.

다음 세션에서는 1~2번까지만 먼저 완성하고 실제 확률을 검증하는 것이 안전하다. UI와 저장을 동시에 크게 확장하면 원인 추적이 어려워진다.

## 6. 개발자 테스트

`?debug`가 있으면 게임 화면에 시간·날씨 조절 패널이 표시된다.

```text
?debug&time=06:30&weather=clear   새벽
?debug&time=12:00&weather=rain    낮+비
?debug&time=18:30&weather=rain    저녁+비
?debug&time=22:00&weather=storm   밤+폭풍
```

예시: https://sidebatch.github.io/pixel-life/?debug&time=22:00&weather=storm

키보드 보조 기능:

- `F3`: 월드 충돌·배치 디버그
- `[` / `]`: 디버그 상태에서 30분 단위 시간 조절
- 방향키/WASD: 이동
- Space/Z: 상호작용
- X/Escape: 취소

모바일 낚시 QA:

1. 물가를 바라볼 때 상황 문구가 `낚시`인지 확인한다.
2. 손 버튼을 누르면 찌와 낚싯줄이 표시되는지 확인한다.
3. `낚시 취소`가 가방·설정 위쪽에 보이는지 확인한다.
4. 가방·설정은 보이되 흐리고 눌리지 않는지 확인한다.
5. 취소 후 메뉴가 함께 열리지 않는지 확인한다.
6. 입질 후 손 버튼으로 붕어 결과가 100% 표시되는지 확인한다.

## 7. 배포와 저장소

`main`에 push하면 `.github/workflows/deploy-pages.yml`이 다음 순서로 자동 배포한다.

```text
check → build → Pages artifact 업로드 → GitHub Pages 배포
```

배포 전에는 항상 아래 세 검사를 수행한다.

```bash
node scripts/check.mjs
node scripts/build.mjs
git diff --check
```

현재 `sidebatch/pixel-life` 하나가 공개 소스이자 배포 저장소다. 이전 별도 배포 저장소 `sidebatch/pixel-life-web`은 보관 처리되었으므로 다시 사용하지 않는다.

## 8. 변경 시 지켜야 할 규칙

- 모바일 이동 감각을 PC 수정과 함께 바꾸지 않는다.
- 월드 시간·날씨를 낚시 전용 코드로 옮기지 않는다.
- 새 어종·지역은 조건문 덩어리보다 데이터 파일로 추가한다.
- 통과 가능한 식생은 actor보다 아래에서 렌더링한다.
- 캐릭터와 건물 가림은 기존 Y-depth 규칙을 유지한다.
- 사용자 에셋과 기존 변경을 임의로 삭제하거나 덮어쓰지 않는다.
- 기능 완료 후 검사·빌드·모바일 화면 확인·Pages 성공 확인까지 수행한다.

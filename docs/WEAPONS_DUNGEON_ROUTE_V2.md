# 목검 · 브락의 검 · 던전 남쪽 진입 v2

2026-10-22 · 로컬 구현 / 공개 미배포

후속 수정: [계단 가림·이동 회피 v1](DUNGEON_STAIRS_MELEE_FIX_V1.md). 계단을 바닥으로 그리고 캐릭터의 상행/하행 높이를 표현한다. 공격 범위와 이동 취소는 후속 문서를 따르며 아래 무기 수치·경로·좌표는 유지한다.

## 무기

| 단계 | 이름 / 저장 키 | 획득 · 능력 |
| --- | --- | --- |
| 시작 | 목검 / `sword.basic` | 기본 지급, 피해 16, 내구도 무제한 |
| 첫 제작 | 브락의 검 / `sword.brak` | 튼튼한 가죽 3개 + 브락 엄니 1개, 피해 24, 내구도 200 |
| 후속 기획 | 철검 | 폐광의 철 재료와 연결할 예정. 이번에는 등록하지 않음 |

목검은 나뭇결이 보이는 나무 칼날, 브락의 검은 큰 상아색 엄니 날과 가죽 손잡이로 새로 그렸다. 조합창·가방·장착·하단 선택·공격·수리는 같은 이름과 그림을 쓴다. 기존 금속 검 PNG는 보존하고 런타임 참조만 새 버전으로 바꿨다. 현재 공격력·제작 재료·내구도·수리비는 유지했다.

저장 버전 2 유지. 앞 로컬 구현의 `sword.iron` 보유/장착/내구도는 `sword.brak`으로 옮긴다. 이미 만든 장비를 다시 만들거나 재료를 다시 내지 않는다. 내구도 0도 그대로 보존한다. 기본 무기의 기존 `sword.basic` 저장 키는 유지한다.

캐릭터 몸·발·손·휘두르기 각도는 바꾸지 않는다. 96×96 도구 셀, 기본 30/38px·제작 검 34/44px 표시 길이를 유지한다. [기존 검 동작 계약](sword-action-v1.json)의 원본 그림 해시도 계속 검사하고, [재료별 그림 계약 v2](sword-materials-v2.json)로 새 두 그림을 검증한다.

## 남쪽부터 시작하는 던전

마을 굴 → **던전 갈림길 남쪽 (25,41), 북쪽 바라보기**. 첫 입구는 같은 x의 (25,37)로 바로 위 **4칸**이다. 넓게 흩어졌던 5열×2줄을 남북 주통로와 2열×5줄로 정리했다.

| 남쪽 → 북쪽 줄 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 입구 가까운 첫 줄 | 1. 들녘 숲 | 2. 이끼 골짜기 |
| 둘째 줄 | 3. 뒤엉킨 뿌리굴 | 4. 잿빛 폐광 |
| 셋째 줄 | 5. 독안개 습지 | 6. 붉은바위 협곡 |
| 넷째 줄 | 7. 서리송곳 산굴 | 8. 고요한 묘지 |
| 가장 북쪽 | 9. 잊힌 성소 | 10. 별무덤 유적 |

순서는 갈림길의 입구 이름 앞에 표시한다. 지역 이름 자체나 기존 벌목 숲 이름에는 숫자를 붙이지 않는다. 체험 중인 모든 지역에 계속 자유롭게 출입할 수 있고 새 레벨 잠금은 추가하지 않는다.

- 들녘 사냥터: 남쪽 (12,38)에서 북쪽을 바라보며 시작. 귀환은 (12,42)의 내려가는 계단.
- 나머지 9지역: 남쪽 (32,40)에서 북쪽을 바라보며 시작. 귀환은 (32,43)의 내려가는 계단.
- 갈림길에서 마을로 나가는 계단은 남쪽 (25,44).
- 각 던전에서 돌아오면 해당 굴 앞 2칸에 도착하여 즉시 재진입하지 않는다.
- 계단은 북쪽이 열리고 남쪽으로 어두워지는 그림이다. 양쪽 돌 테두리와 아래쪽만 막아 북쪽에서 걸어 들어갈 수 있다. 이름은 계단 위쪽에 표시하여 하단 조작 바에 가리지 않게 했다.
- 9지역의 첫 일반 몬스터 두 마리는 남쪽 중앙 방에 둔다. 일반 방들을 지나 북쪽 우두머리 방으로 탐험한다. 들녘 사냥터의 기존 동물 10마리와 브락 위치·전투·보상은 유지한다.

기존 저장 위치가 새 갈림길의 벽 안이면 기존 안전 위치 검사로 남쪽 시작점으로 복구한다. 안전한 탐험 중 저장 위치는 유지한다.

# 마을 정비 v1 — 2026-10-09

## 적용 범위

사용자 승인에 따라 마을의 기존 상점/집을 보존하면서 새 건물 5채·주민 3명을 추가했다. 전체는 건물 8곳(엘리 상점 포함), 주민 9명이다. 중앙 벽돌 격자는 없앴다. 마을·항구 및 기존 stone area 모두 연결된 흙/잔돌 표면을 사용하며 이동 타일·물·충돌 판정은 그대로다.

북쪽 회관, 북서쪽 여관, 중앙 기존 도구점/광장, 남서쪽 의상 공방과 주거 골목, 남쪽 기존 엘리 상점으로 구역을 나눴다. 새 건물은 색만 바꾼 복제품이 아니라 지붕·층수·가로세로 비율·문 위치·재료가 다르다. 마을 크기 64×48과 출구·연못·상점의 위치는 유지한다.

## 다양한 크기, 공통 배치 계약

| 크기 계열 | 충돌 footprint | 적용 건물 |
| --- | --- | --- |
| garden_hut | 3×3 | 소라의 정원집 |
| tall_atelier | 4×5 | 달실 의상 공방 |
| veranda | 5×3 | 바람마루 집 |
| cottage | 5×4 | 기존 파란 지붕 집 |
| workshop | 6×4 | 기존 준의 도구점 |
| wide_inn | 8×4 | 노을솥 여관 |
| hall | 8×5 | 초록종 회관 |

엘리 상점은 기존 독립 렌더링/5×4 충돌을 유지한다. 표는 현재 크기 계열이며 미래 건물을 두 가지 크기에 강제로 맞추는 제한이 아니다.

- 충돌 footprint와 실제 그림 크기는 분리한다. 지붕/처마는 밖으로 나올 수 있지만 문 앞을 가리는 나무나 장식은 두지 않는다.
- 실제 문 중심을 측정해 런타임 PNG 픽셀의 `artAnchor.doorCenterX`로 저장한다. `door`는 footprint 안, `approach`는 바로 앞의 비충돌 타일이다.
- 발밑 바닥선은 footprint 아래 끝에 맞추고 `depthLine=h`로 플레이어/NPC/나무와 같은 깊이 정렬을 사용한다.
- 건물 고유 ID·`sizeFamily`·`serviceKey`는 그림 이름이나 상점 기능과 분리한다. 향후 내부 지역은 `interiorId`에 연결한다. 현재 새 집은 `null`이며 실내 입장/가구 배치는 구현하지 않았다.
- 아직 기능이 없는 건물은 `살펴보기`와 짧은 분위기 설명만 제공한다. 구현되지 않은 상점/실내가 열린다고 표시하지 않는다. 기존 엘리 판매/낚싯대 수리, 준의 도끼/목재/귀환석, 하나의 외형 변경은 유지한다.

## 새 주민과 후속 연결

루카는 여관 주변의 요리 담당 후보, 소라는 정원집 주변의 원예 담당 후보, 이든은 회관 주변의 마을 안내/커뮤니티 담당 후보다. 현재는 각자의 대화와 집 주변 2타일 이내 산책만 제공하며 출입구 접근 타일을 점유하지 않는다. 요리/농사 성장/의뢰/숙박 판매를 임의 추가하지 않았다.

의상 공방과 바람마루 집은 의상·주거 기능을 연결할 자리다. 실제 기능은 별도 설계/승인 후 연결하며 기존 하나의 외형 변경을 옮기거나 잠그지 않는다.

## 그림 원본·재생성

새 건물/주민은 imagegen 스킬의 기존 게임 그림체 참조 절차와 내장 이미지 생성 도구를 사용했다. 기존 집·엘리·준을 스타일 참고로 삼았으며 기존 캐릭터/리그/도구/주민 그림은 변경하지 않았다.

- 건물 원본과 정확한 프롬프트: `assets/buildings/source/village-v1/`
- 주민 원본과 정확한 프롬프트: `assets/npcs/source/village-v1/`
- 패킹: `node scripts/pack-village-v1.mjs`
- 패킹 명세/문 좌표: `assets/buildings/source/village-v1/manifest.json`
- 패킹은 투명 경계 자르기·최근접 축소·발 위치 정렬만 한다. 주민은 288×384, 96px 셀 3열×4방향, 모든 프레임 공통 배율과 발 기준 88px이다.

바닥은 기존 Canvas 표면 렌더링을 개선했다. 시간/카메라가 변해도 잔돌 무늬가 재생성되지 않도록 월드 좌표 기준으로 고정하고 화면 밖 광장은 건너뛴다.

## 배포 범위

- 왜가리·아르마딜로로 두 불쾌한 외형을 교체하고 브락·보른을 재제작.
- 우두머리 10종의 지역색 후광·빛고리·금색 픽셀 왕관, 동작 줄이기 지원.

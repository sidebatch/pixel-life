# Pixel Life

세로형 모바일 화면을 기준으로 제작 중인 탑다운 픽셀 생활 어드벤처입니다. 라일락 연못 마을에서 서로 다른 경관의 숲 12개와 햇살 농장으로 이동할 수 있으며, 낚시와 벌목·농사·상점 거래를 즐길 수 있습니다. 월드 시간·날씨, 물고기 20종, 나무 50종, 도감·저장·성장 장비가 연결되어 있습니다.

- 공개 게임: https://sidebatch.github.io/pixel-life/
- 문서 안내: [`docs/README.md`](docs/README.md)
- 다음 세션 인수인계: [`docs/HANDOFF.md`](docs/HANDOFF.md)
- 확정 생활 스킬 성장 설계: [`docs/LIFE_SKILL_PROGRESSION.md`](docs/LIFE_SKILL_PROGRESSION.md)
- 벌목·농사 이미지 규격: [`docs/LIFE_ASSET_STANDARD.md`](docs/LIFE_ASSET_STANDARD.md)
- 배포 방법: [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)
- 이전 회차별 QA 기록: [`QA_REPORT.md`](QA_REPORT.md) (최신 숲 검증은 인수인계 문서 참조)

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
node scripts/serve.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 검사와 빌드

```bash
node scripts/qa-fishing-baseline.mjs
node scripts/qa-fishing-expansion-data.mjs
node scripts/qa-fish-dex.mjs
node scripts/check.mjs
node scripts/build.mjs
```

검사가 통과하면 Android 다운로드 폴더에서도 직접 열 수 있는 독립 실행형 `dist/index.html`이 생성됩니다. 이 파일에는 스타일, 코드, 이미지가 모두 포함됩니다. npm이 설치된 환경에서는 같은 작업을 `npm test`로 실행할 수 있습니다.

## 조작

- 모바일: 왼쪽 조이스틱으로 이동, 오른쪽 손 버튼으로 상호작용
- 키보드: 방향키 또는 WASD로 이동
- Space 또는 Z: 상호작용
- X 또는 Escape: 대화·메뉴 닫기

## 현재 범위

구현됨:

- 각각 64×48 타일인 마을·숲 12개·농장 지역과 카메라, 지역 간 왕복 출입구
- 플레이어 이동 및 충돌
- NPC 6명의 로밍과 대화
- 문 상호작용이 있는 집·작업실 2채와 엘리의 상점 건물
- 모바일·키보드 입력
- Android Chrome에서 홈 화면에 설치할 수 있는 세로형 PWA. 설치 후 주소창 없는 독립 창으로 실행하며 게임 본체와 지역 음악을 오프라인 캐시하고 새 배포 캐시를 자동 교체
- Y축 기반 가림과 식생 레이어
- 월드 배치 자동 검사와 F3 디버그 오버레이
- 현실 30분 기준 월드 시계와 시간대별 화면·조명
- 맑음·비·폭풍 자동 날씨와 화면 전체 강수 효과
- 물고기 20종 데이터와 지역·시간·날씨별 Fish Pool. 강·바다 맵 추가 전까지는 마을 연못에서 20종 모두 낚을 수 있도록 지역 제한만 임시 해제(시간·날씨 조건 유지)
- 상대 Weight 추첨과 같은 어종 3연속 보정
- 낚시 XP·레벨, 발견·크기 통계, 로컬 저장·복원
- 낚시 Lv.1–100·숙련도와 +XP·100% 경험치 바·레벨업 안내 (Lv.21 이후 XP는 임시 밸런스)
- `전체 / 내륙 / 해안 / 원양`과 3열 서식지 필터, 접이식 서식지 구역이 있는 물고기 도감
- 발견 물고기 중앙 상세 팝업과 X·뒤로가기 닫기
- 물고기 20종 전용 96×96 픽셀 아트
- 5·10·15·19·20종 도감 누적 보상과 단계별 힌트
- 희귀·영웅·전설 결과 카드의 등급별 파티클·등장 애니메이션·합성 효과음
- 물가 낚시 루프, 찌·입질·결과 카드·모바일 취소
- 기본 낚싯대 지급, 낚시 Lv.5·10·15에 엘리에게 물고기와 코인으로 순차 구매하는 낚싯대 3종, 도감 20종 보상 낚싯대 1종
- 엘리 상점의 낚싯대 6종 전체 목록과 준 도구점의 도끼 10종 목록. 도끼는 직전 단계 목재와 코인으로 순차 구매하고, 상점에는 내부 피해량 대신 이름·외형·가격·해금 조건만 표시한다. 항목을 펼쳐 재료·부족분을 확인하고, 구매 후 가방에서 직접 장착·저장
- 월드 메뉴는 가방·물고기 도감·나무 도감을 동일 크기의 픽셀 아트 이미지 카드로 표시. 가방의 물고기·장비·재료는 모두 3열 이미지 카드로 표시하며 오른쪽 위 수량 배지와 커서·터치 이름 확인을 공통 사용 (물고기 개별 크기·판매가 기록은 저장 유지)
- 기본 외형은 몸·머리·머리카락·옷·가방·그립 손의 독립 PNG로 구성. 걷기·벌목·낚시는 공통 96px 셀/발 기준을 사용하고 도끼 10종·낚싯대 6종을 프레임별 손 위치에 연결. 낚싯줄은 낚싯대 끝에서 이어짐. 기본 의상/외형 ID와 손에 들 도구 선택은 저장. 새 에셋의 현행 기준은 `docs/CHARACTER_ASSET_STANDARD.md`와 `docs/character-standard-v4.json`이며 `docs/CHARACTER_APPEARANCE.md`는 제작 이력
- 마을 남쪽 길가의 엘리 상점 건물: 엘리 앞에서 `상점`을 눌러 물고기·재료를 판매하거나 씨앗을 구매. 건물 전체에 충돌 판정을 적용하고, 판매 성공 시 제공받은 돈 소리와 코인 증가 연출
- 숲 12개에 나무 50종이 실제 생성된다. 나무 종류마다 필요한 도끼가 정해지며, 완전 벌목 시 목재 0~3개와 벌목 XP를 얻고 현실 시간 5분 후 재생한다. 25% 확률로 목재가 나오지 않아도 XP·도감·벤 횟수는 정상 반영되며 별도 무획득 문구는 띄우지 않는다. 도끼 10종과 상위 숲 7개까지 연결됐고, 낮은 도끼의 상위 나무 도전 규칙만 후속 설계다
- 기본 도끼는 내구도가 닳지 않는다. 철 도끼부터는 나무 단계만큼 실제 타격마다 내구도가 줄며, 0이 된 타격은 적용된 뒤 자동으로 빈손이 된다. 유료 도끼는 파손 전 70% 같은 상태에서도 마을 준의 도구점에서 닳은 비율만큼 수리할 수 있다. 망가진 도끼만 수리 뒤 가방에서 다시 장착하며, 사용 중인 부분 손상 도끼는 장착을 유지한다. 내구도·수리비·빈손과 기존 저장 이행은 저장된다
- 준의 도구점 도끼 탭에서 `귀환석`(`Return Stone`)을 100코인에 여러 개 살 수 있다. 가방 재료 탭에서 사용하면 장소와 관계없이 1개를 소모하고 마을 북쪽 입구로 이동한다. 마을에서 잘못 사용해도 돌려주지 않는다
- 타격 후 나무 체력바의 남은 영역은 체력 비율에 따라 색이 바뀌고, 깎인 영역은 검정색으로 늘어난다. 마지막 타격 직후에는 전체가 검정색이다.
- 타격 중 체력 퍼센트 문구는 표시하지 않는다. 나무를 완전히 벴을 때만 종별 벌목 XP를 받고 +XP 바·레벨업 알림이 나타난다. XP·레벨·장착 도끼는 저장된다. 종별 XP·판매가와 도끼 비용은 `docs/FORESTRY_BALANCE.md`의 임시 밸런스다.
- 나무·그루터기·목재 아이콘 50종과 벌목 캐릭터의 4방향×2자세 전용 스프라이트
- 완전히 벤 수종과 누적 벌목 횟수를 저장하는 나무 도감. 전체와 `새싹의 숲`·`거목의 경계`·`강철의 대삼림`·`정령의 성역`·`태초의 심연` 탭을 3열×2줄로 표시하고, 다음 숲 실루엣과 최초 발견 카드·3음 차임을 제공한다. UI에는 내부 단계 번호·체력·출현 지역·필요 도끼를 표시하지 않는다
- 햇살 농장의 4×4 고정 밭: 초기 4칸, 단계별 영구 확장, 씨앗 심기·오프라인 성장·수확
- 엘리는 물고기·작물 판매 및 씨앗·낚싯대 구매, 오른쪽 작업실 앞 준은 통나무 판매, 목재·코인 도끼 구매·수리, 귀환석 판매를 담당한다. 구매 장비는 가방에서 직접 장착
- 새 저장 키 `pixel-life.save.v2`로 전 기기/브라우저에서 낚시·벌목 Lv.1, 코인 0, 기본 장비로 새 출발. 기존 로컬 저장은 삭제하지 않지만 자동으로 불러오지 않음
- 씨앗 10종의 96×96 이미지가 상점·가방·밭 심기 창에 공통 적용
- 숲의 강과 농장 연못에서 낚시, 지역·플레이어 위치·밭·자원을 기존 브라우저 저장에 보존

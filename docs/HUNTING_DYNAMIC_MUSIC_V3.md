# 사냥터 밀도·지형 v3와 마을 음악 복구

2026-10-21 사용자 요청으로 구현했으며 공개 배포 준비 중이다. 이전 공개판은 9ec96fb / PWA 17bb8ceec9a6다. 별도로 진행 중이던 숲 세션 배치 변경은 보존하고 이번 게시에서 제외한다.

## 음악 중단 원인과 처리

수정 전 공개 게임에서 숲·농장·사냥터를 거쳐 마을로 돌아오는 실제 재생을 기록했다. 세 번째 마을 복귀에서 1.68초에 `PIPELINE_ERROR_READ: FFmpegDemuxer: data source error`가 발생하고 음악 시간이 멈췄다. 이때 HTML 오디오는 `paused=false`, `readyState=4`여서 기존 동기화가 재생 중으로 판단하고 재시도하지 않았다. 최초 기록은 `output/hunting-dynamic-qa/music-before.json`이다. 브라우저 미디어 읽기 오류 자체와 그 뒤 복구가 없던 코드 문제를 구별한다.

`src/region-music.js`는 오류 이벤트를 감지하면 같은 스트리밍 오디오를 다시 로드하고 메타데이터 준비 뒤 직전 위치로 돌아가 재생한다. 기존 사용자 입력으로 얻은 모바일 재생 권한을 유지하며 오디오 객체나 PCM 버퍼를 중복 생성하지 않는다. 음악이 오류 없이 멈춰 있는 경우도 1초 간격 감시에서 8초 이상 시간 진행이 없으면 복구한다. 소리를 다시 읽는 동안 짧은 버퍼링은 있을 수 있다.

재시도에는 새 요청 주소를 사용해 중단된 부분 응답을 재사용하지 않는다. 서비스 워커는 온라인 음악을 브라우저/서버의 원래 스트리밍 응답으로 전달하고, 네트워크 오류나 오프라인에서는 현재 버전의 완전한 음악 캐시에서 필요한 바이트 범위를 제공한다. 재시도 주소도 같은 원본 캐시로 연결한다. 첫 복구만 넣은 검사에서 연속 미디어 오류로 여러 번 재시도되는 현상이 있어 이 경로까지 보완했다.

자동 복구/재시도는 최대 3회로 제한한다. 지역 변경·음소거·화면 숨김·pagehide는 오래된 복구와 재생 요청을 취소한다. 같은 음악을 쓰는 지역 이동은 재생 위치를 초기화하지 않는다. 실제 사용자 입력은 다시 시도할 수 있다. 음소거와 음악 음량 0.3, 3개의 기존 음악 파일, 반복 재생, 별도 음소거 저장 키는 유지한다.

## 사냥터 구성

8개의 작은 능선 중심 배치를 25개의 지형 구역으로 확장했다. 길과 동물 사이를 두꺼운 나무 군락, 세로 절벽, 쓰러진 거목으로 나누고, 좁은 숲길에서 동물 공터로 열렸다가 다시 길목으로 이어지게 했다. 북쪽과 양옆의 빈 면적을 숲 벽으로 채우고 중앙 덩어리와 남쪽 군락으로 우회 동선을 만든다. 지형 위에 놓이던 기존 나무·바위·장식은 사냥터에서만 제거한다.

총 충돌 칸은 1,556개이며, 기존 연결 길 203칸과 10개체/40개 인접 공격칸, 연못 가장자리와 출구는 모두 접근 가능하다. 동물은 큰 군락을 돌아 추격한다. 지형 그림은 인물과 같은 깊이 정렬을 따르고, 인물이 절벽/수관 뒤에 가릴 때 해당 그림을 옅게 해 위치를 볼 수 있게 했다. 숲 군락은 작은 겹침과 고정 위치 차이를 두어 반복 틈을 줄이고, 세로 절벽은 바닥 능선으로 연결했다. 게임 난수와 자원 배치는 변경하지 않는다.

기존 5종/10마리, 양쪽 명중률 60%, 공격/피격음, 선공 없음과 개별 반격, 기존 피해·저장·생활 경제는 유지한다.

## 검증

- `scripts/qa-region-music-recovery.mjs`: 공개판 오디오 동작 fixture로 `paused=false` 오류 정지 재현, 자동 복구/위치 재개, 3회 제한, 오래된 지역 전환 무효화, 음소거/숨김/pagehide, 같은 곡 이동, 8초 정지 감시, 오디오 객체 1개 유지. fixture를 보존해 shallow CI에서도 과거 Git 이력이 필요하지 않다.
- `scripts/qa-region-music-browser.mjs`: 실제 음악 요청 1회 실패를 주입하고 추가 사용자 입력 없이 재생 복구. 6개 지역에서 마을로 복귀할 때 실제 오디오 시간 진행과 유효 파형, 마을에서 9초 추가 재생, 캐시 허용 브라우저, 음소거 유지 확인.
- `scripts/qa-region-music-cache.mjs`: 온라인 부분 응답을 그대로 전달하고, 오프라인의 재시도 주소/정확한 범위/끝부분/잘못된 범위/전체 파일/일시적 HTTP 오류를 현재 버전의 완전한 캐시로 처리한다.
- `scripts/qa-hunting-terrain.mjs`: 25구역/1,556 충돌 칸, 연결된 길 203칸, 모든 동물의 4방향 접근, 연못·출구·굴 접근 검사.
- `scripts/qa-hunting-polish-browser.mjs`: 320/393/1280px 지형과 큰 군락 우회, 4도구/동물 소리, 양쪽 각 1만 회 명중률·기존 경제 불변 확인.
- 기존 사냥터 입구/귀소/처치/저장, 동물 모션과 낚시·수확·장비 회귀도 배포용 빌드에서 확인한다.

# 설산·폭포·늪 시각 정비 v1 — 2026-10-10

사용자가 설산/폭포의 도형 같은 이미지와 늪의 단조로운 이미지를 개선하도록 승인했다. 새 픽셀 원화와 수면/물가 표현만 적용했으며 지역 정의·이동 충돌·입구·낚시/경제·기존 저장은 변경하지 않았다.

## 적용

- 설산: 산악 호수의 큰 단색 삼각형을 서로 다른 두 눈 덮인 바위 능선 원화로 교체했다. 기존 능선의 그리기 영역 안에만 표시하며 기존 이동 불가 영역은 그대로다. 잔디의 큰 타원 패치가 능선 위에 덮이지 않게 했다.
- 폭포: 규칙적인 돌 테두리/평행 줄무늬 대신 이끼 낀 불규칙한 바위 절벽·물줄기·포말 원화를 사용한다. 폭포 계곡뿐 아니라 기존 숲 1-5와 태초 숲의 폭포도 같은 방식을 쓴다. 작은 물결 강조는 물줄기 중앙에만, 물안개는 폭포 계곡의 낮은 발밑 부분에만 표시한다. 일반 수면의 반짝임이 폭포 바위에 겹치지 않는다.
- 늪: 진한 청록 수면과 낮은 대비 물결, 흙/이끼가 스며드는 물가, 기존 위치의 수련 원화, 갈대 주변 물 위의 뿌리/부들/통나무 군락과 작은 부유초를 사용한다. 물 위를 덮던 큰 초록 타원과 밝은 직선 물가 테두리는 없앴다. 장식은 실제 물 영역에만 잘라 그려 잔교/길/낚시 접근을 덮지 않는다.
- 늪 장식 위치는 지역 정의별로 캐시하며 시간/카메라가 바뀌어도 재생성하지 않는다. 수면 반짝임 뒤, 캐릭터 앞이 아닌 지상 장식 레이어에 그린다. 새 폭포/수련 효과는 모션 감소 설정에서 정지한다. 기존 게임 전체의 모든 움직임을 없애는 변경은 아니다.

## 원화·재현

imagegen 스킬의 기존 스타일 참조 절차와 내장 이미지 생성 도구를 사용했다. 기존 파란 지붕 집/바위는 스타일 참고일 뿐 수정하지 않았고, 기존 캐릭터·리그·도구·주민·다른 원화는 그대로다.

최종 투명 PNG:

- `assets/biomes/ridge-west-v1.png`
- `assets/biomes/ridge-east-v1.png`
- `assets/biomes/waterfall-v1.png`
- `assets/biomes/swamp-bank-v1.png`
- `assets/biomes/lily-pads-v1.png`

정확한 프롬프트·고해상도 원본·자르기 명세는 `assets/biomes/source/scenery-v1/`에 보관한다. `node scripts/pack-biome-scenery.mjs`는 투명 경계 자르기/종횡비를 유지한 최근접 축소/여백 배치만 재현한다. 원화 변경은 이미지 생성 도구로 처리하고 코드로 임의 그림을 다시 칠하지 않는다.

## 검증

`SCENERY_NAVIGATION_BASELINE_V1.json`은 변경하지 않은 지역 데이터에서 산악 호수/폭포/늪/숲 1-5/태초 숲의 실제 충돌·물·길·다리·나무·바위·출구/도착·낚시 지점/서식지 지문을 기록한다. `qa-biome-scenery.mjs`는 지문·5개 원화의 크기/진짜 투명 배경·런타임 자르기 명세·화면 밖 제외·늪 장식 캐시/물 안 배치를 보호하며 전체 검사에 포함한다.

`qa-biome-scenery-browser.mjs`는 393×780/320×568에서 원화 로딩/설산 양쪽/폭포 계곡/늪 물가·잔교/숲 폭포, 렌더링 중 게임 상태 불변, 낮/밤/비·모션 감소를 확인한다. 화면과 보고서는 `output/biome-scenery-v1/`에 보관한다.

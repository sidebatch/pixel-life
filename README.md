# Pixel Life

세로형 모바일 화면을 기준으로 제작 중인 탑다운 픽셀 생활 어드벤처입니다. 라일락 연못 마을에서 서로 다른 경관의 숲 12개, 햇살 농장, 바람결 해안 항구, 여명 산악 호수, 물안개 폭포 계곡과 그늘 갈대 늪과 얕은·중간·심해·빙하 어선으로 이동할 수 있으며, 낚시와 벌목·농사·상점 거래를 즐길 수 있습니다. 월드 시간·날씨, 물고기 74종, 나무 50종, 도감·저장·성장 장비가 연결되어 있습니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
node scripts/serve.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 조작

- 모바일: 왼쪽 조이스틱으로 이동, 오른쪽 손 버튼으로 상호작용
- 키보드: 방향키 또는 WASD로 이동
- Space 또는 Z: 상호작용
- X 또는 Escape: 대화·메뉴 닫기

## 현재 범위

구현됨:

- 각각 64×48 타일인 마을·숲 12개·농장 지역과 카메라, 지역 간 왕복 출입구
- 플레이어 이동 및 충돌
- NPC 6명의 로밍과 대화
- 문 상호작용이 있는 집·작업실 2채와 엘리의 상점 건물
- 모바일·키보드 입력
- Android Chrome에서 홈 화면에 설치할 수 있는 세로형 PWA. 설치 후 주소창 없는 독립 창으로 실행하며 게임 본체와 지역 음악을 오프라인 캐시하고 새 배포 캐시를 자동 교체
- Y축 기반 가림과 식생 레이어
- 월드 배치 자동 검사와 F3 디버그 오버레이
- 현실 30분 기준 월드 시계와 시간대별 화면·조명
- 맑음·비·폭풍 자동 날씨와 화면 전체 강수 효과
- 물고기 74종·10서식지의 지점/시간/날씨별 Fish Pool. 기존 20종+신규 54종을 연결했고, 기본 낚싯대와 Lv.1로도 장소·조건에 맞는 모든 어종에 도전 가능
- 상대 Weight 추첨과 같은 어종 3연속 보정
- 낚시 XP·레벨, 발견·크기 통계, 로컬 저장·복원
- 낚시 Lv.1–100·숙련도와 +XP·100% 경험치 바·레벨업 안내 (Lv.21 이후 XP는 임시 밸런스)
- `전체 / 내륙 / 해안 / 원양` 네 탭과 3열 단일 목록의 물고기 도감. 하위 서식지 탭/접이식 구역은 없고, 미발견 어종의 출현 조건/힌트는 숨김
- 발견 물고기 중앙 상세 팝업과 X·뒤로가기 닫기
- 물고기 74종 전용 96×96 픽셀 아트
- 오래된 숲 1-1 서쪽에서 여명 산악 호수로 이동. 차가운 물빛·설산 능선·낚시 부두와 7종 전용 풀, 맑은 새벽의 오로라송어
- 산악 호수 남쪽의 물안개 폭포 계곡. 위쪽 강·폭포·폭포 소·아래쪽 강, 육로와 다리, 7종 전용 폭포 풀과 맑은 새벽의 수정송어
- 폭포 계곡 남쪽의 그늘 갈대 늪. 좁은 육로·잔교, 탁한 물·수초·낮은 안개와 7종 전용 풀, 폭풍이 치는 밤의 늪왕장어
- 기존 5·10·15·19·20종 발견 보상과 30·40·50·60·74종 영구 꾸미기, 10서식지 졸업/도장. 과거 15/19종 힌트 플래그는 보존하지만 힌트는 공개하지 않음
- 희귀·영웅·전설 결과 카드의 등급별 파티클·등장 애니메이션·합성 효과음
- 물가 낚시 루프, 찌·입질·결과 카드·모바일 취소
- 마을 항구의 4항로 승선권과 앱 표시 중 10분 운항. 진행 중 낚시는 만료 후 획득 확인/취소까지 유지하고 항구로 귀환. 배 앞 갑판·연속 바다 장식은 화면 밖부터 통과하며 같은 수면의 추월을 방지
- 기본 낚싯대는 무한. 획득 마모는 내륙·해안 1 / 얕은 바다 6 / 중간 바다 8 / 심해 10 / 빙하 12이며 취소는 무소모. 마을 엘리의 부분 수리·0 빈손·저장 실패 원상 복원
- 나무/물고기 최초 발견 카드와 공통 +XP 연출 통일. 실제 준비 진행률 0~100%와 준비 화면 1회 표시
- 낚싯대 10종: 기본 지급·도감 20종 강태공 보상·물고기와 코인으로 8종 순차 구매. 장착은 가방에서 직접 수행하고 효과/소유/내구도를 저장
- 엘리 상점의 낚싯대 10종 전체 목록과 준 도구점의 도끼 10종 목록. 도끼는 직전 단계 목재와 코인으로 순차 구매하고, 상점에는 내부 피해량 대신 이름·외형·가격·해금 조건만 표시한다. 항목을 펼쳐 재료·부족분을 확인하고, 구매 후 가방에서 직접 장착·저장
- 월드 메뉴는 가방·물고기 도감·나무 도감을 동일 크기의 픽셀 아트 이미지 카드로 표시. 가방의 물고기·장비·재료는 모두 3열 이미지 카드로 표시하며 오른쪽 위 수량 배지와 커서·터치 이름 확인을 공통 사용 (물고기 개별 크기·판매가 기록은 저장 유지)
- 기본 외형은 몸·머리·머리카락·옷·가방·그립 손의 독립 PNG로 구성. 걷기·벌목·낚시는 공통 96px 셀/발 기준을 사용하고 도끼 10종·낚싯대 10종을 프레임별 손 위치에 연결. 낚싯줄은 낚싯대 끝에서 이어짐. 기본 의상/외형 ID와 손에 들 도구 선택은 저장. 새 에셋의 현행 기준은 `docs/CHARACTER_ASSET_STANDARD.md`와 `docs/character-standard-v4.json`이며 `docs/CHARACTER_APPEARANCE.md`는 제작 이력
- 마을 남쪽 길가의 엘리 상점 건물: 엘리 앞에서 `상점`을 눌러 물고기·재료를 판매하거나 씨앗을 구매. 건물 전체에 충돌 판정을 적용하고, 판매 성공 시 제공받은 돈 소리와 코인 증가 연출
- 숲 12개에 나무 50종이 생성된다. 종별 최소 도끼 제한을 유지하며 완전 벌목 시 목재 0~3개와 XP·도감 기록을 받고 5분 후 재생한다. 무획득 전용 문구는 없으며 낮은 도끼의 상위 나무 도전은 사용자 결정으로 넣지 않음
- 기본 도끼는 내구도가 닳지 않는다. 철 도끼부터는 나무 단계만큼 실제 타격마다 내구도가 줄며, 0이 된 타격은 적용된 뒤 자동으로 빈손이 된다. 유료 도끼는 파손 전 70% 같은 상태에서도 마을 준의 도구점에서 닳은 비율만큼 수리할 수 있다. 망가진 도끼만 수리 뒤 가방에서 다시 장착하며, 사용 중인 부분 손상 도끼는 장착을 유지한다. 내구도·수리비·빈손과 기존 저장 이행은 저장된다
- 준의 도구점 도끼 탭에서 `귀환석`(`Return Stone`)을 100코인에 여러 개 살 수 있다. 가방 재료 탭에서 사용하면 장소와 관계없이 1개를 소모하고 마을 북쪽 입구로 이동한다. 마을에서 잘못 사용해도 돌려주지 않는다
- 타격 후 나무 체력바의 남은 영역은 체력 비율에 따라 색이 바뀌고, 깎인 영역은 검정색으로 늘어난다. 마지막 타격 직후에는 전체가 검정색이다.
- 타격 중 체력 퍼센트 문구는 표시하지 않는다. 나무를 완전히 벴을 때만 종별 벌목 XP를 받고 +XP 바·레벨업 알림이 나타난다. XP·레벨·장착 도끼는 저장된다. 종별 XP·판매가와 도끼 비용은 `docs/FORESTRY_BALANCE.md`의 임시 밸런스다.
- 나무·그루터기·목재 아이콘 50종과 벌목 캐릭터의 4방향×2자세 전용 스프라이트
- 완전히 벤 수종과 누적 벌목 횟수를 저장하는 나무 도감. 전체와 `새싹의 숲`·`거목의 경계`·`강철의 대삼림`·`정령의 성역`·`태초의 심연` 탭을 3열×2줄로 표시하고, 다음 숲 실루엣과 최초 발견 카드·3음 차임을 제공한다. UI에는 내부 단계 번호·체력·출현 지역·필요 도끼를 표시하지 않는다
- 햇살 농장의 4×4 고정 밭: 초기 4칸, 단계별 영구 확장, 씨앗 심기·오프라인 성장·수확
- 엘리는 물고기·작물 판매 및 씨앗·낚싯대 구매/부분 수리, 준은 목재 판매·도끼 구매/수리·귀환석 판매를 담당한다. 구매 장비와 파손 후 수리 장비는 가방에서 직접 장착
- 2026-09-25 v1→v2 저장 전환은 과거 기록이다. 현재 `pixel-life.save.v2`의 기존 진행·아이템·도감·장비·내구도·운항을 보존하며 이번 확장/문서 정리에서 초기화하지 않음
- 씨앗 10종의 96×96 이미지가 상점·가방·밭 심기 창에 공통 적용
- 숲의 강과 농장 연못에서 낚시, 지역·플레이어 위치·밭·자원을 기존 브라우저 저장에 보존

# 숲 입구 재배치 v1 — 2026-10-09

이 문서는 정정 전 제작 이력이다. 사용자가 1-1~1-5 남쪽 연결과 나머지 일반 상위 숲 분기를 정정했으므로 현재 기준은 [FOREST_ROUTES_V2.md](FOREST_ROUTES_V2.md)다. 떠 있는 안내 배지도 현재 사용하지 않는다.

## 당시 구현된 지리 (현재 기준 아님)

사용자는 첫 숲을 마을 남쪽에 두고 첫 숲에서 위/서/동 방향으로 다음 숲을 찾아가며, 판타지 숲을 마을 북쪽으로 분리하는 구성을 승인했다. 기존 12개 지역의 ID·이름·나무 구성은 유지하고 입구와 연결길만 재배치했다. 숫자는 기존 지역 이름의 순서이지 새 벌목 레벨 제한이 아니다.

| 구역 | 연결 |
| --- | --- |
| 마을 남쪽 | 오래된 숲 1-1 |
| 첫 숲 북쪽 왼편 갈림길 | 오래된 숲 1-2 |
| 첫 숲 북쪽 중앙 | 마을 귀환 |
| 첫 숲 서쪽 아래 | 오래된 숲 1-3 |
| 첫 숲 동쪽 | 오래된 숲 1-4 |
| 첫 숲 남쪽 | 오래된 숲 1-5 |
| 숲 1-5 남쪽부터 | 거목 숲 → 붉은 거목림 → 은빛 경목림 → 검은 경목림 |
| 마을 북쪽부터 | 고대 숲 → 정령 숲 → 태초 숲 |
| 첫 숲 서쪽 위 | 기존 산악 호수 입구 유지 |

농장은 마을 동쪽, 항구는 마을 서쪽을 유지한다. 검은 경목림과 고대 숲 사이의 옛 직결은 제거했으며 판타지 구역은 마을 북쪽에서 방문한다. 모든 지역은 기존 64×48 독립 맵이고 이 표는 연결 관계다. 실제 전체 월드를 단일 좌표 평면으로 합치지 않았다.

## 입구/귀환 기준

- 마을 남쪽 출구 `(25,46)` → 첫 숲 북쪽 도착 `(25,3)`; 첫 숲 중앙 북쪽 출구 `(25,1)` → 마을 남쪽 도착 `(25,44)`.
- 마을 북쪽 출구 `(25,1)` → 고대 숲 남쪽 도착 `(25,44)`; 고대 숲 남쪽 출구 `(25,46)` → 마을 북쪽 도착 `(25,3)`.
- 첫 숲의 두 번째 숲 입구는 `(14,1)`로 마을 귀환길과 11타일 떨어져 있다.
- 첫 숲 서쪽 세 번째 숲 입구는 `(1,36)`, 동쪽 네 번째 숲 입구는 `(62,40)`, 남쪽 다섯 번째 숲 입구는 `(25,46)`.
- 기존 산악 호수 입구 `(1,24)`와 호수 쪽 귀환 좌표를 유지한다.
- 모든 도착 좌표는 대응 귀환 출구보다 2타일 안쪽이다. 지역 진입 직후 자동 귀환하거나 이동 입력이 연속 지역 전환을 일으키지 않는다.
- 입구 접근 때 목적지/방향 배지를 표시한다. 나무·날씨 위에 표시하고 상단 정보창·하단 조작부/화면 밖을 피한다. 배지는 정보 표시일 뿐 클릭 버튼이나 충돌 오브젝트가 아니다.
- 노아와 마을 표지판도 북쪽 고대 숲/남쪽 오래된 숲으로 안내를 수정했다.

## 기존 콘텐츠/저장 보존

원래 나무 생성이 끝난 뒤 `connectForestEntrances`가 기존 나무·바위·물 좌표를 피하는 최단 연결길을 추가한다. 새 길을 `forestTierTrees`의 생성 입력으로 되돌려 넣지 않는다. 길을 위해 나무를 삭제하거나 이동하지 않으며 다리·물 영역도 새로 바꾸지 않는다. 사용하지 않는 기존 끝부분 길은 경계 안에서 끝나도록 짧게 정리했다.

`FOREST_ROUTES_BASELINE_V1.json`은 변경 전 12숲의 실제 생성 나무 2,565그루의 ID·좌표·수종, 물 영역·낚시 지점·바위·지형과 나무/도끼 수치의 지문이다. 새 자동 검사는 변경 후 결과가 정확히 일치하는지 확인한다.

저장 키/버전·나무 체력/재생 시간·목재·XP/도감/보상·장비/내구도·귀환석 동작은 변경하지 않았다. 기존 저장 지역과 좌표는 여전히 유효하며 이전 위치 그대로 재접속한다. 새 진입의 기본 위치만 새 입구 방향에 맞춘다. 낮은 도끼로 상위 나무를 벨 수 없다는 기존 제한은 유지하며 지역 입장에 새 레벨/코인/아이템 잠금을 추가하지 않았다.

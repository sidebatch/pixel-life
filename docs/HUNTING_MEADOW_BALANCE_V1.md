# 들녘 숲 · 전투·조합·보상 표

작성일: 2026-10-22 · **개정 2: 가죽 조합과 철검 재료 변경** · 상태: 기획 검토 / 게임 적용 전

후속 [던전 외형·탐방 v1](DUNGEON_VISUAL_PREVIEW_V1.md)에서 브락 그림과 지역 출입만 먼저 구현했다. 이 문서의 브락 전투·재료·조합·철검 수치는 계속 미적용 상태다.

첫 지역의 흐름은 **접근 → 직접 공격 → 이동해서 피하기 → 일반 가죽 획득 → 튼튼한 가죽 조합 → 철검 제작**이다. 최신 사용자 수정에 따라 일반 가죽 30개로 튼튼한 가죽 1개를 만들고, 철검에는 튼튼한 가죽 3개와 브락 엄니 1개를 사용한다. 단단한 가죽은 철검 재료에서 제외한다.

지역·몬스터 이름은 [사냥 지역 구성안 개정 5](DUNGEON_REGIONS_MONSTERS_V1.md)를 따른다. 이 문서의 가격·보상·장비·개별 공격 시간은 검토할 제안이며 현재 게임에 적용된 수치가 아니다.

## 1. 현재 구현과 이번 제안

| 항목 | 현재 구현 | 이번 초안 |
| --- | --- | --- |
| 플레이어 체력 | 100 | 유지 |
| 기본 검 피해 | 명중 시 16 | 유지 |
| 기본 검 공격 동작 | 0.7초, 타격 시점 0.27초 | 유지 |
| 양쪽 명중률 | 유효 범위의 공격마다 60% | 유지 |
| 선공 여부 | 실제 피해를 받은 개체만 반격 | 브락도 같은 규칙 |
| 일반 몬스터 | 멧돼지·사슴·여우·늑대·곰, 종마다 2개체 | 5종 유지. 개체 수는 실제 순환 사냥으로 검토 |
| 보스 | 없음 | 브락 1개체 |
| 기본 검 내구도 | 검 내구도 소모 기능 없음 | 기본 검은 무제한으로 유지 |
| 전리품·판매 | 사냥 보상 없음 | 사냥에서는 일반 가죽·브락 엄니 지급. 상위 가죽은 조합 |
| 다음 검 | 없음 | 철검: 피해 24, 튼튼한 가죽 3개 + 브락 엄니 1개. 추가 코인 비용 없음 |
| 아이템 조합 | 없음 | 가죽 등급 조합과 철검 제작. 아래는 기능 설계이며 아직 게임에 구현되지 않음 |
| 수렵 레벨·XP | 없음 | 이번 표에서는 추가하지 않음 |
| 체력 소진 | 마을 복귀·체력 회복, 재화 차감 없음 | 유지. 획득 전리품도 잃지 않는 방향 |

도끼 10·낫 6·낚싯대 4의 현행 사냥 피해도 바꾸지 않는 초안이다. 철검은 신규 장비이며 검별 피해·보유/장착·저장·내구도·수리 연결이 필요하다.

## 2. 몬스터 전투 수치

**기본 검 피해 16, 플레이어 체력 100 기준**이다. 일반 5종의 체력과 공격력은 현재 값이고, 브락은 신규 제안값이다.

| 몬스터 | 체력 | 공격력 / 명중 1회 | 기본 검 필요 명중 | 평균 공격 시도 | 체력 100에서 버티는 기준 |
| --- | ---: | ---: | ---: | ---: | --- |
| 멧돼지 | 64 | 12 | 4회 | 약 6.7회 | 9번째 피격에 체력 소진 |
| 사슴 | 48 | 8 | 3회 | 5회 | 13번째 피격에 체력 소진 |
| 여우 | 40 | 7 | 3회 | 5회 | 15번째 피격에 체력 소진 |
| 늑대 | 80 | 14 | 5회 | 약 8.3회 | 8번째 피격에 체력 소진 |
| 곰 | 128 | 20 | 8회 | 약 13.3회 | 5번째 피격에 체력 소진 |
| 브락 | 320 | 26 | 20회 | 약 33.3회 | 4번째 피격에 체력 소진 |

- 필요 명중 횟수 = 체력 ÷ 검 피해를 올림한 값이다. 마지막 공격의 남는 피해도 한 번으로 센다.
- 평균 공격 시도 = 필요 명중 ÷ 0.6이다. 모두 거리·방향·벽 조건을 만족한 공격을 가정한 계산상 평균이며 횟수가 보장되지는 않는다.
- 적의 공격도 60% 명중하므로 표의 피격 횟수는 **실제로 피해를 받은 횟수**다. 적이 시도한 횟수와 다르다.
- 접근·이동 회피·헛스윙·귀소·회복 시간은 위 평균에 포함하지 않는다. 아직 실전 처치 시간으로 환산하지 않는다.

### 공격 준비와 빈틈 제안

현재 일반 5종은 모두 준비 0.6초, 타격 후 다음 준비까지 기본 대기 1.5초를 공유한다. 아래는 모바일에서 종별로 구별되도록 바꿔볼 후보값이다.

| 몬스터 | 준비 동작 | 준비 시간 제안 | 타격 후 다음 준비까지 기본 대기 | 목표 대응 |
| --- | --- | ---: | ---: | --- |
| 멧돼지 | 땅 긁기 | 0.9초 | 1.5초 | 돌진 방향의 옆으로 이동 |
| 사슴 | 머리 낮추기 | 0.8초 | 1.5초 | 뿔의 정면 벗어나기 |
| 여우 | 몸 웅크리기 | 0.7초 | 1.5초 | 짧은 도약이 끝나면 접근 |
| 늑대 | 어깨 낮추기 | 0.8초 | 1.5초 | 물기 범위 밖으로 물러나기 |
| 곰 | 상체와 앞발 들기 | 1.2초 | 1.5초 | 앞발을 들 때 측면 이동 |
| 브락 | 몸 낮추고 땅을 길게 긁기 | 1.5초 | 2.5초 | 넓게 옆으로 피한 뒤 반격 |

대기 시간은 다음 공격을 준비하기 전 최소 간격이며 실제로는 거리·추격·방향과 복귀 모션의 영향도 받는다. 대기 중에는 피해를 주지 않되, 적의 추격 이동 여부와 실제 반격 가능 시간은 동작을 붙인 뒤 확인한다. 브락은 빠른 연속 돌진 대신 큰 돌진 한 번을 사용한다.

## 3. 조합 규칙

**최신 사용자 지정: 철검에는 튼튼한 가죽 3개를 사용한다. 단단한 가죽 3개를 요구하던 앞 제안은 대체한다.**

| 조합 | 투입 재료 | 결과 | 적용 범위 |
| --- | --- | --- | --- |
| 가죽 등급 올리기 | 일반 가죽 30개 | 튼튼한 가죽 1개 | 첫 지역의 기본 조합 |
| 철검 제작 | 튼튼한 가죽 3개 + 브락 엄니 1개 | 철검 1개 | 첫 장비 성장 목표 |
| 상위 가죽 조합 | 튼튼한 가죽 10개 | 단단한 가죽 1개 | 앞 요청의 비율 유지. 철검에는 사용하지 않고 후속 장비용으로 보류 |

튼튼한 가죽 3개는 **일반 가죽 90개 분량**이다. 철검 제작에는 이 가죽 분량과 별도로 브락 엄니 1개가 필요하다. 첫 지역에서 단단한 가죽까지 만들 필요는 없다.

| 조합 기능 항목 | 설계 |
| --- | --- |
| 성공률 | 100% |
| 추가 비용·대기 | 코인 수수료와 제작 대기 시간 없음 |
| 조작 위치 | 가방에서 조합 목록을 열고 보유/필요 재료 확인 |
| 재료 조합 수량 | 1회 또는 최대 가능 횟수. 예: 일반 가죽 95개면 최대 3회, 결과 튼튼한 가죽 3개와 일반 가죽 5개 |
| 철검 제작 수량 | 미보유 상태에서 1회. 보유한 철검이 파손돼도 새로 만들지 않고 수리 |
| 재료 부족 | 조합 버튼 비활성화, 부족한 수량 표시 |
| 결과 | 가죽은 재료 탭, 검은 장비 탭에 지급. 자동 장착하지 않음 |
| 거래 처리 | 재료 확인 → 재료 소모와 결과 지급 → 저장. 저장 실패 시 전체 원상 복구 |
| 중복·범위 | 연속 터치·다른 조합 뒤 재고 변경·결과 수량 한도에 대한 재검증 필요 |
| 상위 가죽 노출 | 단단한 가죽은 사용할 후속 장비가 정해질 때 조합 목록에 노출하는 방향 제안 |

## 4. 전리품과 판매 가격

첫 지역에서는 **일반 가죽을 모아 조합하는 과정**을 살린다. 곰이나 브락이 튼튼한 가죽을 직접 주던 앞 초안을 바꾸어, 첫 지역의 모든 동물은 일반 가죽을 지급한다. 브락은 엄니를 추가로 준다. 수량은 확정 지급하며 바닥 줍기 조작 없이 가방으로 받는 방향이다.

앞 문서의 기획명 ‘가죽 조각’은 이번 표에서 **일반 가죽**으로 통일한다. 현재 게임에는 해당 사냥 재료가 아직 없으므로 구현된 아이템을 교체했다는 뜻은 아니다.

| 아이템 | 개당 판매가 제안 | 획득 | 용도 |
| --- | ---: | --- | --- |
| 일반 가죽 | 3코인 | 일반 동물·브락 | 튼튼한 가죽 조합, 남는 수량 판매 |
| 튼튼한 가죽 | 90코인 | 일반 가죽 30개 조합 | 철검 재료, 남는 수량 판매 |
| 단단한 가죽 | 900코인 | 튼튼한 가죽 10개 조합 | 후속 장비용. 첫 철검에는 불필요 |
| 브락 엄니 | 160코인 | 브락 | 철검 재료, 남는 수량 판매 |

판매가는 **일반 30×3 = 튼튼 90**, **튼튼 10×90 = 단단 900**으로 조합 전후의 판매 가치가 같다. 조합 자체만으로 코인이 늘어나거나 손실되는 가격 구조를 만들지 않는다.

| 몬스터 | 처치당 확정 전리품 | 전량 판매 시 |
| --- | --- | ---: |
| 멧돼지 | 일반 가죽 3개 | 9코인 |
| 사슴 | 일반 가죽 2개 | 6코인 |
| 여우 | 일반 가죽 1개 | 3코인 |
| 늑대 | 일반 가죽 4개 | 12코인 |
| 곰 | 일반 가죽 6개 | 18코인 |
| 브락 | 일반 가죽 10개 + 브락 엄니 1개 | 190코인 |

일반 5종을 한 마리씩 잡으면 일반 가죽 **16개**다. 앞 초안의 곰은 튼튼한 가죽을 주는 대신 일반 가죽 4→6개로 조정했다. 처치 보상과 별도로 같은 코인을 중복 지급하지 않는다.

## 5. 기본 검 → 철검

| 항목 | 기본 검 | 철검 제안 |
| --- | --- | --- |
| 피해 / 명중 1회 | 16 | 24 |
| 획득 | 처음부터 보유 | 튼튼한 가죽 3개 + 브락 엄니 1개 |
| 추가 코인 비용 | 없음 | 없음. 앞 초안의 2,400코인 요구 제거 |
| 재료 처리 | 없음 | 제작 저장 성공 시 필요한 수량만 소모 |
| 공격 동작 길이 | 0.7초 | 같은 0.7초 |
| 명중률 | 60% | 같은 60% |
| 내구도 | 무제한 | 200 |
| 마모 | 없음 | 적에게 실제 피해를 준 공격 1회당 1 |
| 마모 제외 | 해당 없음 | 빗나감·범위 밖·허공 공격·메뉴 취소 |
| 전체 수리비 | 없음 | 100코인. 앞 초안 200코인에서 조정 |
| 부분 수리비 | 없음 | 부족한 내구도 ÷ 2를 올림 |
| 파손 | 없음 | 철검 사용 불가. 기본 검을 직접 선택해 계속 사냥 가능 |

추가 코인 요구는 빼고 첫 성장 목표를 **재료 수집·조합·브락 처치**에 둔다. 판매 수익을 조정한 만큼 철검 전체 수리비도 100코인으로 낮춘다. 정상 명중 1회당 장기 수리비는 0.5코인이며, 부분 수리 시에는 올림 때문에 차이가 날 수 있다.

| 몬스터 | 기본 검: 필요 명중 | 철검: 필요 명중 | 철검의 소모 내구도 |
| --- | ---: | ---: | ---: |
| 멧돼지 | 4회 | 3회 | 3 |
| 사슴 | 3회 | 2회 | 2 |
| 여우 | 3회 | 2회 | 2 |
| 늑대 | 5회 | 4회 | 4 |
| 곰 | 8회 | 6회 | 6 |
| 브락 | 20회 | 14회 | 14 |

철검 재료의 판매가 환산은 **3×90 + 160 = 430코인**이다. 제작 시 430코인을 내는 것이 아니라, 재료를 팔았다면 받을 수 있는 가치를 뜻한다. 보관 재료를 판매 수입에도 더하고 제작에도 사용하는 중복 계산을 하지 않는다.

브락은 기본 검으로 잡을 수 있어야 한다. 브락을 잡으려면 철검이 필요하고, 철검을 만들려면 브락을 잡아야 하는 순환 잠금은 만들지 않는다.

## 6. 재등장과 첫 장비까지의 계산

| 항목 | 초안 |
| --- | --- |
| 일반 동물 재등장 | 현재 60초 유지. 플레이어와 겹치지 않는 기존 지연 규칙 유지 |
| 브락 재등장 | 처치 후 활동 시간 5분 후보 |
| 브락 재접속 처리 | 재등장 대기를 저장해 왕복·재접속으로 즉시 다시 등장하지 않도록 설계 필요 |
| 보상 중복 방지 | 한 생존 주기의 한 번의 처치에 한 번만 지급. 거래도 저장 성공과 연결 |
| 체력 소진 시 전리품 | 보존하는 방향. 복귀·재접근 시간을 플레이 손실로 계산 |

### 재료 확보 예시

| 행동 | 일반 가죽 | 브락 엄니 |
| --- | ---: | ---: |
| 일반 5종을 각각 5마리: 총 25마리 처치 | 80개 | 0개 |
| 브락 1마리 처치 | 10개 | 1개 |
| 합계 | 90개 | 1개 |
| 일반 가죽 조합 | 일반 가죽 90개 소모 → 튼튼한 가죽 3개 | 보관 |
| 철검 제작 | 튼튼한 가죽 3개 소모 | 1개 소모 |

이 예시에서는 일반 25마리 + 브락 1마리로 철검 재료가 정확히 모인다. 이는 다섯 종을 같은 수씩 잡는 예시이며 모든 경로에서 25마리면 된다는 보장은 아니다. 브락 처치 시점도 자유다.

### 시간 가정에 따른 범위

기본 검으로 위 26마리를 잡으려면 명중 135회, 명중률 60%에서 평균 **225회의 유효 공격 시도**가 필요하다. 한 동작 0.7초로 공격 동작 시간만 합하면 평균 **157.5초**다.

아래는 여기에 가정한 비공격 시간을 더한 계산이다. 실제 전투 AI·길찾기·사망·재등장·판매 동선 시뮬레이션이나 모바일 측정 결과가 아니다.

| 일반 1마리당 이동·회피 등 가정 | 일반 25마리 + 브락 1마리의 계산상 시간 |
| --- | ---: |
| 10초 | 약 7.3분 |
| 20초 | 약 11.5분 |
| 30초 | 약 15.6분 |

계산식은 **157.5초 + 일반 25마리×가정 시간 + 브락 이동·회피 추가 30초**다. 공격을 계속 누르는 이상적 시도 간격을 가정했으므로 거리 밖 헛스윙·입력 지연·회복·재등장 대기를 실제 모델에 추가해야 한다. 첫 철검 검토 목표는 앞 초안의 30~40분에서 **대략 10~15분**으로 낮추어 시작하고 실제 플레이로 조정한다.

### 판매 수익의 구분

| 가정 | 일반 가죽 합계 | 엄니 포함 전량 판매액 |
| --- | ---: | ---: |
| 일반 20마리: 종마다 4마리 + 브락 1마리 | 74개 | 382코인 |
| 일반 30마리: 종마다 6마리 + 브락 1마리 | 106개 | 478코인 |

전량 판매하면 철검 재료는 남지 않는다. 일반 30마리 + 브락 1마리의 예시에서 철검 재료를 보관·사용하면 일반 가죽 16개가 남으므로, 남은 가죽만 팔 때는 **48코인**이다. 실제 시간당 순수익에는 재료 보관·판매 왕복과 철검 수리비도 반영해야 한다.

## 변경 내용

- 숲 12지역에서 광장용 큰 사각형 바닥을 그리지 않는다. 해당 영역의 세부 지면도 숲의 잔디/기존 길로 표시한다. 마을 광장과 항구·호수 등의 바닥은 유지한다. 숲별 색상/원화/나무·물·바위·출구/나무 ID·재생시간·기존 저장은 바꾸지 않았다.
- 하루의 v1 원화는 셀 치수는 맞았지만 길쭉한 체형과 화풍이 주민들과 달랐다. 준을 기준으로 머리/몸통/팔다리 비율과 픽셀 화풍을 새로 보정했다. 공통 렌더러/기존 NPC/플레이어/옷/낫 등은 변경하지 않는다. 96px 셀, 288×384 시트, 표시 배율 1, 발 (48,88), 목 (48,54), 최대 그림 높이 66px을 유지한다.
- 하루와 농사 상점 건물을 농장에서 **마을 동쪽, 농장 출구 이전 길가**로 옮겼다. 건물 (54,19), 4×4칸, 문 (56,22), 접근 (56,23), 하루 (57,23), 방문 위치 (57,24), 농장 출구 (62,24). 문과 NPC 접근/출구를 막지 않는다. 기존 농장 상점·NPC·짧은 진입로를 제거했다. 마을은 시장 포함 건물 9채/주민 10명, 농장은 상점/주민 없음이다.
- 낫으로 수확해 작물·XP 저장에 성공했을 때 한 번만 짧은 잎 베는 소리와 작은 수확음을 재생한다. 실제 270ms 수확 타격에 연결되며 구경/실패/중복 지급에는 소리를 내지 않는다. Web Audio 합성음이고 별도 MP3는 추가하지 않았다. 소리용 노이즈는 독립된 결정적 상태를 사용하여 게임의 Math.random 순서를 바꾸지 않는다. 기존 오디오 잠금 해제/예외 처리 경로를 따른다.
- 재배 중/수확 가능 창의 제목에 현재 작물의 기존 수확 아이콘(56px)과 큰 이름(21px)을 함께 보여준다. 작물이 없는 밭/미구매 부지는 그림을 제거하여 이전 작물 이미지가 남지 않는다. 기존 한국어 조사·남은 시간·농사 레벨·행동 버튼은 유지한다.

숲의 과거 stoneAreas 데이터는 나무 배치를 생성할 때 빈터를 예약하는 역할도 한다. 이를 삭제하면 자원 수와 ID가 달라질 수 있으므로 데이터는 유지하고, 숲에서 광장 그림과 stone 지면 표현만 제거했다. 숲의 기존 원화와 저장 계약을 보존하기 위한 구분이다.

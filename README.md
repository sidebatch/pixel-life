## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
node scripts/serve.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

검사가 통과하면 코드·스타일·이미지·짧은 효과음 8개가 내장된 `dist/index.html`을 생성합니다. 긴 지역 BGM 3개와 PWA 파일은 별도이므로 배포/오프라인 검사는 **dist 전체**를 사용합니다. Android에서는 공개 URL의 설치형 PWA를 권장하며 HTML 파일 하나만으로 설치·음악·오프라인 동작 전체를 보장하지 않습니다. npm이 있으면 `npm test`로 검사와 빌드를 실행할 수 있습니다.

## 현재 범위

구현됨:

- 각각 64×48 타일인 마을·숲 12개·농장 지역과 카메라, 지역 간 왕복 출입구
- 플레이어 이동 및 충돌
- 마을 주민 9명의 대화·기존 로밍/짧은 산책, 항구 선장
- 마을 동쪽 농장 가는 길의 농가/고정 상인 하루: 씨앗 14종·작물 판매·주문·꾸미기. 엘리는 물고기/낚싯대, 준은 목재/도끼 담당
- 마을 건물 8채·7개 크기 계열, 기존 상점과 새 집의 살펴보기(새 실내/판매 기능은 미구현)
- 모바일·키보드 입력
- Android Chrome에서 홈 화면에 설치할 수 있는 세로형 PWA. 설치 후 주소창 없는 독립 창으로 실행하며 게임 본체와 지역 음악을 오프라인 캐시하고 새 배포 캐시를 자동 교체
- 현재 남쪽 숲 1-1~1-5/거목 연결과 1-1의 일반 상위 분기, 마을 북쪽 판타지 숲, 길옆 팻말 27개
- 흙·잔돌 마을/항구 광장, 설산/폭포/늪 새 픽셀 원화와 기존 48칸 나무 다리·잔교 정비
- Y축 기반 가림과 식생 레이어
- 월드 배치 자동 검사와 F3 디버그 오버레이
- 현실 30분 기준 월드 시계와 시간대별 화면·조명
- 맑음·비·폭풍 자동 날씨와 화면 전체 강수 효과
- 물고기 74종·10서식지의 지점/시간/날씨별 Fish Pool. 기존 20종+신규 54종을 연결했고, 기본 낚싯대와 Lv.1로도 장소·조건에 맞는 모든 어종에 도전 가능

- 낚시 Lv.1–100·숙련도와 +XP·100% 경험치 바·레벨업 안내. 승인된 공통 성장 v2는 Lv.80 이후 요구량을 점차 늘리며 Lv.100 누적 187,230 XP다

- 마을 남쪽 길가의 엘리 상점 건물: 엘리 앞에서 `상점`을 눌러 물고기를 판매하거나 낚싯대를 구매/수리. 건물 전체에 충돌 판정을 적용하고, 판매 성공 시 제공받은 돈 소리와 코인 증가 연출

- 기본 도끼는 내구도가 닳지 않는다. 철 도끼부터는 나무 단계만큼 실제 타격마다 내구도가 줄며, 0이 된 타격은 적용된 뒤 자동으로 빈손이 된다. 유료 도끼는 파손 전 70% 같은 상태에서도 마을 준의 도구점에서 닳은 비율만큼 수리할 수 있다. 망가진 도끼만 수리 뒤 가방에서 다시 장착하며, 사용 중인 부분 손상 도끼는 장착을 유지한다. 내구도·수리비·빈손과 기존 저장 이행은 저장된다
- 준의 도구점 도끼 탭에서 `귀환석`(`Return Stone`)을 100코인에 여러 개 살 수 있다. 가방 재료 탭에서 사용하면 장소와 관계없이 1개를 소모하고 마을 북쪽 입구로 이동한다. 마을에서 잘못 사용해도 돌려주지 않는다
- 타격 후 나무 체력바의 남은 영역은 체력 비율에 따라 색이 바뀌고, 깎인 영역은 검정색으로 늘어난다. 마지막 타격 직후에는 전체가 검정색이다.
- 타격 중 체력 퍼센트 문구는 표시하지 않는다. 나무를 완전히 벴을 때만 종별 벌목 XP를 받고 +XP 바·레벨업 알림이 나타난다. 완전 벌목 XP는 나무 단계별 7/8/9/10/11/12/15/16/17/18이다. XP·레벨·장착 도끼는 저장되며 기존 진행은 레벨·바·숙련도를 보존해 성장 v2로 이행한다. 판매가·도끼 비용은 `docs/FORESTRY_BALANCE.md`의 임시 밸런스다.
- 나무·그루터기·목재 아이콘 50종과 벌목 캐릭터의 4방향×2자세 전용 스프라이트
- 완전히 벤 수종과 누적 벌목 횟수를 저장하는 나무 도감. 전체와 `새싹의 숲`·`거목의 경계`·`강철의 대삼림`·`정령의 성역`·`태초의 심연` 탭을 3열×2줄로 표시하고, 다음 숲 실루엣과 최초 발견 카드·3음 차임을 제공한다. UI에는 내부 단계 번호·체력·출현 지역·필요 도끼를 표시하지 않는다

# FORESTRY_TIER1_ASSET_BRIEF

상태: **9장 게임 연결 완료 / Android 실기기 최종 확인 전**
기준일: 2026-09-28
프로젝트 반영: 2026-09-29
상위 문서: `FORESTRY_TREE_CATALOG.md`

제작·검수 결과: [`FORESTRY_TIER1_ASSET_QA.md`](FORESTRY_TIER1_ASSET_QA.md). 신규 나무 2종·그루터기 2종·목재 아이콘 5종이 후보 폴더와 실제 게임 자산에 있다. 삼나무 선 나무는 v2를 채택했다. 기존 PNG는 덮어쓰지 않고 새 파일을 등록했다. 이 문서의 나무 단계는 50종 장기 설계 기준이며, 현행 플레이 밸런스의 단계 재배치는 별도다.

## 1. 목적

50종 전체를 한 번에 만들지 않고 Tier 1을 수직 슬라이스로 먼저 제작한다.

Tier 1은 총 5종이다. 기존 3종의 살아 있는 나무·그루터기는 유지하되, 목재 아이콘은 새 스타일의 후보를 만든다.

| 표시명 | id | 나무·그루터기 신규 | 목재 아이콘 후보 |
|---|---|---|---|
| 오동나무 | `paulownia` | 제작 | 제작 |
| 버드나무 | `willow` | 기존 유지 | 새 스타일 제작 |
| 가문비나무 | `spruce` | 기존 유지 | 새 스타일 제작 |
| 소나무 | `pine` | 기존 유지 | 새 스타일 제작 |
| 삼나무 | `cedar` | 제작 | 제작 |

이번 검토용 제작 수량: **9 PNG** — 신규 2종×3장=6장 + 기존 3종 목재 아이콘 후보 3장. 기존 파일은 덮어쓰지 않는다. `cedar`(삼나무)는 기존 `cypress`(추후 편백나무 표시)의 이름 변경과 별개 신규 ID다.

## 2. 공통 규격

### 살아 있는 나무
- 120×144 px
- 투명 PNG
- 밑동 하단 중앙
- 글씨/워터마크/배경 없음
- 기존 `oak`, `maple-v2`, `spruce-v2` 스타일 참조
- 48×48 게임 타일에 배치될 때 자연스럽게 보이도록 한다.

### 그루터기
- 96×96 px
- 투명 PNG
- 원래 나무의 수피와 단면 특징 연결
- 지나치게 크게 꽉 채우지 않는다.

### 목재 아이콘
- 96×96 px
- 투명 PNG
- 가방/상점에서 쓰는 별도 아이템 그림
- 선 나무/그루터기의 축소판 금지
- Android 3열 카드 크기에서도 종류 차이가 보여야 한다.
- [`references/forestry-item-style-2026-09-28.png`](references/forestry-item-style-2026-09-28.png)는 **스타일 비교판**이다. 게임에는 배경·글씨 없이 통나무, 나이테, 껍질과 작은 수종 단서만 담은 **개별 PNG**를 쓴다.
- 첫 비교는 5종 목재 아이콘 전부 같은 시각 문법으로 만든다. 기존 3종 후보는 `incoming/forestry-chat/items/{willow,spruce,pine}.png`에 두고 기존 게임 아이콘과 나란히 비교한다.

## 3. 오동나무 `paulownia`

### 역할
Tier 1의 부드럽고 가벼운 활엽수.

### 살아 있는 나무
핵심:
- 밝고 비교적 매끈한 줄기
- 큰 하트형/넓은 잎의 인상
- 풍성하지만 무겁지 않은 둥근 수관
- 버드나무처럼 늘어지지 않고 참나무처럼 묵직하지 않게
- 전체 인상은 '밝고 가벼운 시작 나무'

피해야 할 것:
- 단풍나무처럼 붉은 잎
- 참나무와 거의 같은 수관
- 지나치게 열대 야자수 같은 모습

파일:
- `trees/paulownia.png`

### 그루터기
핵심:
- 밝은 회갈색~연갈색 수피
- 연한 단면
- Tier 1답게 거칠고 무거운 느낌을 피함

파일:
- `stumps/paulownia.png`

### 목재 아이콘
핵심:
- 밝고 가벼운 목재
- 연한 황갈색/크림 계열
- `oak` 목재보다 밝고 부드러워 보여야 함

파일:
- `items/paulownia.png`

### 도감
지역: 동아시아
한줄: `가볍고 빨리 자라는 나무로 알려진 동아시아의 나무다.`

## 4. 삼나무 `cedar`

### 역할
Tier 1의 두 번째 신규 수종.
기존 소나무·가문비나무와 반드시 다른 실루엣을 만든다.

### 살아 있는 나무
핵심:
- 곧고 세로로 긴 줄기
- 잎 덩어리가 층층이 나뉘는 구조
- 짙은 녹색
- spruce의 완전한 삼각형 실루엣과 다르게, 가지 층이 눈에 보여야 함
- pine의 둥근/불규칙한 수관과도 달라야 함

피해야 할 것:
- spruce 색만 바꾼 복제품
- 너무 가늘어 cypress와 헷갈리는 모습
- 크리스마스트리처럼 완벽한 원뿔

파일:
- `trees/cedar.png`

### 그루터기
핵심:
- 적갈색이 살짝 도는 수피
- 오동나무보다 진한 단면
- 침엽수의 곧은 결 느낌

파일:
- `stumps/cedar.png`

### 목재 아이콘
핵심:
- 따뜻한 적갈색/황갈색
- 향목 느낌의 깔끔한 결
- pine/spruce 아이콘과 색상·결 차이가 보여야 함

파일:
- `items/cedar.png`

### 도감
지역: 산지 숲
한줄: `곧게 자라는 줄기와 진한 녹색 수관이 특징인 침엽수다.`

## 5. Tier 1 완료 판정

검토용 9개 PNG가 완성되면 기존 나무·그루터기와 함께 아래를 확인한다.

- 오동 / 버드 / 가문비 / 소나무 / 삼나무가 실루엣만으로도 어느 정도 구별되는가
- 5종이 같은 시작 숲에 있어도 지나치게 복잡하지 않은가
- 신규 두 종이 기존 자산보다 지나치게 고해상도/화려하지 않은가
- 그루터기와 목재 아이콘이 각 원본 나무와 연결돼 보이는가
- 기존 3종의 새 목재 아이콘 후보가 새 2종 아이콘과 같은 스타일로 보이는가

통과하면 Tier 2 신규 수종 제작으로 이동한다.

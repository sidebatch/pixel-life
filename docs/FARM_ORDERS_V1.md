# 농장 주문·교환권·꾸미기 v1

2026-10-13 사용자 회의에서 ‘랜덤 주문 → 재배·수확 → 납품 → 보상 → 농장 확장·꾸미기 → 더 다양한 주문’을 선택했다. 랜덤 1개 자동 지급/완료 후 다음 주문/재접속 유지와 허수아비·표지판·울타리의 지정 가장자리 배치를 승인했다. 구현 후 ‘배포해주세요’ 요청으로 공개 배포·검증을 완료했다. 게임 커밋 `f1a37af`, PWA `61b8656eecda`, [성공 배포](https://github.com/sidebatch/pixel-life/actions/runs/38444649859). 기존 농사 레벨/14종과 저장을 보존한다.

## 이용 방법

1. 마을의 엘리 상점에서 **농장 주문** 탭을 연다. 랜덤 주문 하나를 자동으로 생성하고 저장한다. 별도의 선택/수락/새로 뽑기 과정은 없다.
2. 필요한 작물을 키워 수확하거나 기존 재고를 모아 **작물 납품하기**를 누른다.
3. 지정 수량만 소비하며 코인/농장 교환권을 지급하고 즉시 다음 랜덤 주문을 저장한다. 이미 끝난 주문 ID로 다시 제출해도 지급하지 않는다.
4. 엘리의 **농장 꾸미기** 탭에서 교환권으로 소품을 얻는다.
5. 농장에서는 인접한 밭 관리 창의 **농장 꾸미기** 버튼으로 소품을 설치/회수한다. 이 창은 꾸미기만 제공하며 다른 상점 물품을 원격 구매하는 창이 아니다.
6. 기존 부지 구매는 코인/목재를 그대로 사용한다. 밭 규모와 농사 레벨을 높이면 다음 주문부터 더 다양한 작물을 요구한다.

현재 주문은 기한/일일 제한 없이 유지한다. 모든 기존 작물은 기존 조건으로 재배할 수 있다. 주문 난도는 다음 주문 생성 시 결정하며, 진행 중인 주문은 레벨/밭 수가 바뀌어도 내용과 보상을 유지한다. 주문 납품 자체에 XP를 추가하지 않고 기존 수확 XP를 유지한다.

## 주문과 경제

| 주문 단계 | 농사 레벨 / 보유 밭 | 서로 다른 작물 수 | 작물당 수량 | 후보 성장시간 | 교환권 |
| --- | --- | ---: | ---: | --- | ---: |
| 1 | 기본 | 1 | 4–8 | 5분 이하: 당근·비트·상추·감자 | 1장 |
| 2 | Lv.10 이상 / 8칸 이상 | 2 | 6–10 | 12분 이하 | 2장 |
| 3 | Lv.20 이상 / 12칸 이상 | 3 | 8–12 | 40분 이하: 현행 14종 | 3장 |

두 조건을 함께 만족해야 다음 단계 주문이 생성된다. 작물은 중복 없이 추첨하며 직전 주문의 첫 작물을 첫 항목에서 피한다. 수량도 단계 범위 안에서 추첨한다.

코인 보상은 **요구 작물의 일반 판매가 합계 × 1.25를 올림 + 단계 × 15**다. 예: 당근 6개는 일반 판매 48코인, 납품 보상 75코인 + 교환권 1장이다. 단순 판매보다 보상을 높이고 농장 꾸미기라는 별도 목표를 제공한다. 요구 작물·수량·보상을 저장하므로 접속마다 재추첨하지 않는다.

## 꾸미기

| 소품 | 교환권 | 설치 위치 | 효과 |
| --- | ---: | --- | --- |
| 허수아비 | 3장 | 밭 왼쪽 (13,22) | 농장 외형 |
| 농장 표지판 | 5장 | 밭 오른쪽 (23,22) | 농장 외형 |
| 꽃 울타리 | 8장 | 밭 아래 (15–21,27), 7구간 | 농장 외형 |

소품은 한 번 교환하면 영구 보유하고 무료로 설치·회수·재설치할 수 있다. 같은 소품을 중복 구매하지 않는다. 통계/수확량/성장시간/XP 보너스는 없으며 기존 가격/부지/작물·성장 계약을 유지한다. 설치 시 해당 타일은 이동을 막지만 밭과 통로·기존 경로를 침범하지 않는다. 플레이어가 설치 위치에 서 있으면 설치를 거부해 몸 위에 객체를 만들지 않는다. 모든 밭의 인접 접근과 농장 출구를 유지한다.

꾸미기는 나무/캐릭터와 같은 깊이 정렬 큐에 등록한다. 기존 몸·손·도구·캐릭터 규격을 변경하지 않는다.

## 저장과 실패 복원

메인 키 pixel-life.save.v2 / 버전 2는 유지한다. progression.farmOrders는 schemaVersion:1, tickets, completed, current, ownedDecorationIds, placedDecorationIds를 가진다. 소품 좌표는 고정 데이터에서 찾고 사용자 저장의 임의 좌표를 사용하지 않는다.

기존 저장에 새 필드가 없으면 교환권 0장/납품 0회/주문 없음/소품 없음으로 시작하며 기존 코인·아이템·밭·작물/시간·농사/다른 스킬·장비·도감·운항을 보존한다. 엘리의 주문 탭을 열 때 첫 주문을 저장한다.

주문 생성/납품/교환/설치·회수는 commitLifeChange의 farmOrders 스냅샷에 포함한다. 저장이 실패하면 작물/코인/교환권/완료 횟수/다음 주문/소유/설치를 모두 복원한다. 설치 충돌은 저장 성공 후 갱신한다. 재접속 시 소유한 소품의 설치만 복원하고 월드 구성 때 충돌도 반영한다.

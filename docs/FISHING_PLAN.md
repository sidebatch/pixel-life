# Fishing System — 현재 계약과 v0.1 기준 이력

상태: 2026-10-09 기준 낚시 확장 1~18단계와 수리 빈도 보정 완료. 본문 최초 20종/초기 특전은 역사 기준이며 현재 74종/10장비 상세는 확장 설계를 우선한다.

2026-10-08 확정 UI를 유지한다. 물고기 최초 발견은 나무와 같은 뒤집기 카드(그림·서식지·이름·설명·확인)로 표시한다. 반복 어종은 일반 결과창을 유지하지만 중복 경험치 카드는 없으며 벌목과 같은 공통 +XP/막대/레벨업 알림을 사용한다. 발견/보상 카드 마지막 확인 후 경험치 표시를 시작하고 실제 획득/기록/XP는 저장 성공 시 한 번만 지급한다. 최신 검증과 완료 범위는 `HANDOFF.md` 상단을 따른다.

생활 스킬 성장의 상위 기준은 [`LIFE_SKILL_PROGRESSION.md`](LIFE_SKILL_PROGRESSION.md)다. 낚시는 Lv.1–100과 이후 숙련도를 구현했다. 공통 성장 곡선과 현재 `pixel-life.save.v2` 저장을 유지하며 이번 확장/수리 보정에서 초기화하지 않았다. 2026-09-25의 v1→v2 전환은 과거 이력이다. 아래 초기 특전 아이디어는 현재 구현과 구별한다.

장기 방향은 [`LONG_TERM_CONTENT_DESIGN.md`](LONG_TERM_CONTENT_DESIGN.md)를 따른다. 현재 낚싯대 10종과 내구도/마을 부분 수리는 구현됐다. 기본 낚싯대는 무한이고 획득 마모는 내륙·해안 1 / 얕은 바다 6 / 중간 바다 8 / 심해 10 / 빙하 12다. 남은 내구도보다 마모량이 커도 마지막 물고기는 정상 지급하고 0/빈손으로 저장한다. 수리 후 파손 장비는 직접 장착하며 저장 실패는 개체/보상/XP/도감/노선 해금/내구도를 함께 취소한다. **입질 후 100% 획득**을 실패/줄 끊김으로 바꾸지 않는다.

74종·10서식지 로스터, 항구 승선권/시간제 어선, 도감/보상/저장, 10낚싯대와 내구도/수리의 현행 기준은 [`FISHING_74_EXPANSION_DESIGN.md`](FISHING_74_EXPANSION_DESIGN.md), 경제/수리 표본과 전제는 [`FISHING_BALANCE_SIMULATION.md`](FISHING_BALANCE_SIMULATION.md)를 따른다. 아래 최초 20종 표는 확장 전 역사 기준선이며 현재 어종 수를 뜻하지 않는다.

현재 구현 범위(2026-10-09): 캐스팅/기본 3~6초 대기/입질/100% 획득·찌/줄·취소, 74종의 지점/시간/날씨/Weight 및 3연속 보정, Lv.100/숙련도·저장/복원, 나무와 통일된 최초 카드/공통 XP, 네 탭 단일 도감/미발견 힌트 비공개, 기존 5/10/15/19/20 및 확장 30/40/50/60/74·서식지 졸업 보상, 10낚싯대 순차 구매/직접 장착/효과/내구도/엘리 부분 수리, 4항로 승선권/표시 중 10분 운항/만료 낚시 종료 후 귀항/연속 바다 장식을 연결했다. 실제 Android 체감은 사용자 요청대로 나중에 확인한다.

이 문서는 낚시를 어렵게 만드는 대신, 결과·수집·성장·월드 변화가 재미를 만드는 방향을 고정한다. 낚시에서 검증한 시간, 날씨, 조건부 보상, 도감, 자원 획득 구조는 이후 벌목·채집·퀘스트에도 재사용한다.

기본 낚싯대와 낚시 Lv.1로도 현재 74종 전체를 조건에 맞춰 잡을 수 있다. 물고기에 최소 낚싯대·최소 낚시 레벨 제한은 없다. 좋은 낚싯대는 효율만 개선하며 입질 후에는 100% 획득한다. 모든 어종의 기본 낚싯대 접근은 `qa-fishing-waterfall.mjs`의 정상 Weight 선택 검사로 보호한다.

## 1. 핵심 철학

낚싯대를 던지면 반드시 무언가가 낚인다.

- 타이밍 실패 없음
- 줄 끊김 없음
- 물고기 도망 없음
- 어려운 미니게임 없음
- 재미의 중심은 “잡을 수 있을까?”가 아니라 “무엇이 나올까?”

기본 흐름은 다음과 같다.

```text
낚시 버튼 → 찌 던짐 → 랜덤 3~6초 대기(기본 낚싯대) → 입질 → 버튼 한 번 → 무조건 획득
```

입질 후 버튼을 누르는 조작은 손맛을 위한 연출이며, 늦게 눌러도 결과는 실패하지 않는다. 이후 옵션으로 입질 후 자동 획득을 제공할 수 있다.

## 2. 공통 WorldTime

낚시 전용 시간이 아니라 월드 전체가 사용하는 시간 시스템으로 구현한다.

- 게임 1일 = 현실 30분
- 현실 1분 = 게임 48분
- 시간은 프레임마다 계속 흐른다.
- UI는 `HH:MM`으로 표시한다.
- 구현 기본 시작 시각은 현재 UI와 호환되도록 `10:24`로 둔다.
- 개발 중에는 `?debug&time=18:30`으로 특정 시각을 고정할 수 있다.
- `?debug`로 접속하면 게임 화면에 시간 조절 패널이 나타난다.
- 패널의 새벽·낮·저녁·밤 버튼과 `±30분`, `실시간` 버튼으로 화면을 직접 비교할 수 있다.
- 패널의 맑음·비·폭풍·자동 버튼으로 날씨 효과도 직접 비교할 수 있다.
- F3 디버그 화면과 `[`/`]` 키 조절도 보조 수단으로 유지한다.

### 시간대 판정

| 게임 시간 | 시간대 | 현실 지속시간 |
|---|---|---:|
| 05:00~08:00 | DAWN | 약 3분 45초 |
| 08:00~17:00 | DAY | 약 11분 15초 |
| 17:00~20:00 | DUSK | 약 3분 45초 |
| 20:00~05:00 | NIGHT | 약 11분 15초 |

시간대는 갑자기 바꾸지 않고 전후 약 30분부터 색과 조명을 보간한다.

## 3. 시간에 따른 월드 변화

- DAY: 밝은 하늘, 밝은 물, 약한 그림자, NPC 일반 활동
- DUSK: 따뜻한 주황색 색조, 긴 그림자, 상점 조명 점등 시작
- NIGHT: 어두운 색조, 집·상점·가로등 점등, 어두운 물, 벌레/귀뚜라미 분위기
- DAWN: 푸른 새벽색에서 밝은 색으로 천천히 전환

구현은 전체 화면 색조 오버레이와 물·그림자·조명 계층으로 나눈다. 시간 시스템은 낚시 모듈에서 직접 수정하지 않는다.

## 4. Weather Manager

날씨는 게임 시간 약 6시간 단위로 다음 상태를 판정한다. 현실 기준 약 7분 30초마다 다음 날씨 구간이 시작된다.

| 날씨 | 기본 비율 |
|---|---:|
| `clear` | 65% |
| `rain` | 27% |
| `storm` | 8% |

완전한 순수 랜덤은 사용하지 않는다. 게임 하루 동안 비 또는 폭풍이 최소 한 번쯤 등장하도록 약한 보정을 두되, 같은 날씨가 연속되는 것은 허용한다.

날씨 전환은 시각 효과를 통해 부드럽게 바뀐다.

- `clear`: 기본 조명과 맑은 하늘
- `rain`: 빗줄기, 젖은 색감, 빗소리 준비 지점
- `storm`: 더 어두운 색감, 강한 빗줄기와 번개 준비 지점

## 5. 낚시터

마을/농장 연못·숲의 강·해안 항구·산악 호수·폭포 계곡·늪지와 얕은/중간/심해/빙하 어선이 실제 연결돼 10서식지 모두 플레이 가능하다. 물 영역의 `spotId`와 `fishingHabitat`이 풀을 결정한다. 산악 호수는 오래된 숲 서쪽, 폭포 계곡은 호수 남쪽, 늪은 계곡 남쪽에서 왕복하며 계곡의 강/폭포 소는 서로 다른 어종을 고른다. 어선 목적지는 마을 항구에서 선택하고 승선권을 사용한다.

| 지역 | 난이도 | 특징 |
|---|---|---|
| 마을 연못 | 초급 | 시작 지역, 기본 어종 |
| 숲의 강 | 중급 | 현재 플레이 가능, 강 어종 풀 |
| 농장 연못 | 초급 | 현재 플레이 가능, 연못 어종 풀 |
| 바닷가 | 중~고급 | 해안 어종 및 승선권 4항로의 항구, 실제 플레이 가능 |

낚시 레벨이 낮아도 모든 지역에서 낚시할 수 있다. 장비는 접근을 막지 않고 희귀도·크기·입질 대기시간에 보너스만 준다.

## 6. 낚시 상태 머신

낚시 모듈은 이동 코어와 분리한다.

- `idle`: 낚시하지 않음
- `casting`: 찌를 던지는 짧은 연출
- `waiting`: 기본 낚싯대 기준 랜덤 3~6초 대기. 장착 낚싯대의 대기 감소율을 적용
- `bite`: 입질 연출, 액션 입력 대기
- `catching`: 물고기·크기·보상 계산
- `result`: 결과 카드와 연출
- `cancelled`: 이동·취소로 종료

`waiting`과 `bite` 동안 플레이어 이동을 잠시 잠근다. `bite`에서 버튼을 누르지 않아도 자동으로 획득 처리할 수 있도록 상태를 설계한다.

입력:

- 모바일: 기존 큰 액션 버튼 탭
- PC: `Space`, `Z`, `Enter`
- 이동 입력: 낚시 취소

## 8. 등급과 보상

등급은 `common`, `uncommon`, `rare`, `heroic`, `legendary` 다섯 단계로 고정한다.

- common: 자주 등장, 기본 보상
- uncommon: 일부 조건 필요
- rare: 시간·날씨 조건
- heroic: 낮은 가중치와 조건
- legendary: 특별 조건과 초희귀 가중치

일반 물고기는 간결하게, rare 이상부터 결과 카드·사운드·빛 효과를 차별화한다.

## 9. 크기와 가격

같은 어종도 범위 안에서 소수점 한 자리 크기를 뽑는다. 도감은 발견 수, 최대·최소·평균 크기를 기록한다.

가격은 기본가와 크기로 계산한다.

```text
q = (size - minSize) / (maxSize - minSize)
sizeMultiplier = 0.8 + q * 0.4
q >= 0.95이면 sizeMultiplier = 1.5
finalPrice = round(basePrice * sizeMultiplier)
```

따라서 작은 개체는 약 0.8배, 평균은 약 1.0배, 큰 개체는 약 1.2배, 상위 5%는 1.5배가 된다.

## 10. 중복 피로 보정

같은 어종이 3회 연속 선택되면 다음 선택부터 해당 어종의 Weight를 일시적으로 절반으로 한다. 다른 어종이 나오면 보정을 해제한다. 플레이어에게는 이 규칙을 노출하지 않는다.

## 11. Fishing Level

현재 낚시는 Lv.100까지 성장하며 이후 숙련도가 오른다. Lv.1–20의 요구량은 기존 저장 파일과 호환되도록 유지한다.

```text
nextLevelXP = 60 + currentLevel * 12
```

| 레벨 | 초기 특전 아이디어 (현재 계약 아님) |
|---:|---|
| 1 | 낚시 시작 |
| 3 | 도감 크기 기록 |
| 5 | 튼튼한 낚싯대, 입질 대기 -10% |
| 7 | 희귀 어종 힌트 |
| 10 | 강철 낚싯대, 희귀 이상 Weight +10% |
| 12 | 10% 확률로 추가 물고기 1마리 |
| 15 | 전문가 낚싯대, 희귀 Weight +20% 및 큰 개체 보정 |
| 17 | 전설 물고기 힌트 |
| 20 | 강태공 단계와 특수 낚싯대 퀘스트 |

위 표의 Lv.7/17 출현 힌트는 미발견 비공개 결정에 따라 사용하지 않는다. 추가 물고기/특수 퀘스트 등도 미구현이며 다음 작업의 승인으로 보지 않는다.

초보도 운이 좋으면 전설을 잡을 수 있다. 장비는 지역 입장 조건이 아니다. 미끼는 v0.1에서 제외한다.

실제 장비는 기본·튼튼한·강철·전문가·강태공·심해·조류·폭풍·심연·극광의 10종이다. 기본은 처음 지급하고 강태공은 도감 20종 보상, 나머지 8종은 엘리에게 레벨/선행 조건·물고기·코인으로 순차 구매한다. 제작 재료는 가방에서 소비하지만 도감 기록은 남으며 자동 장착하지 않는다. 실제 재료/효과/내구도/전체 수리비는 확장 설계 8절을 따른다. 레벨 특전 표와 과거 수치를 현재 구매표로 해석하지 않는다.

## 12. 도감

물고기를 잡는 즉시 자동 등록한다. 등록을 위해 기부하거나 소비하지 않는다.

- 물고기는 인벤토리에 남는다.
- 판매는 별도 상점 시스템에서 한다.
- 미발견은 `? / ???`와 아직 발견하지 못했다는 안내만 표시한다. 서식지·출현 시간/날씨·설명·힌트는 공개하지 않으며, 과거 15/19종 해금이나 서식지 마지막 1종도 예외가 아니다(2026-10-08 승인 기준).
- 발견 후 시간·날씨·서식지 조건을 공개한다.
- 도감은 `전체 / 내륙 / 해안 / 원양` 네 탭만 사용한다. 선택한 분류의 물고기를 3열의 한 목록에 표시하고 하위 서식지 탭/접이식 구역은 두지 않는다. 발견 수는 제목 옆, 보상/칭호/서식지 완성 기록은 작은 `보상 보기` 버튼의 읽기 전용 창에 표시한다(2026-10-08 승인 기준).
- 선택한 물고기의 큰 이미지, 등급, 크기 통계, 서식지, 조건, 설명을 보여준다.

도감 보상:

| 발견 수 | 보상 |
|---:|---|
| 5종 | 코인 300 |
| 10종 | 낚시 XP 보너스 |
| 15종 | 15종 발견 기록 (과거 힌트 효과는 사용하지 않음) |
| 19종 | 19종 발견 기록 (과거 단서 효과는 사용하지 않음) |
| 20종 | 강태공 칭호와 특별 낚싯대 |
| 30/40/50/60/74종 | 물길 탐험가/물결 테두리/어선 깃발/심해 탐사자/세계의 강태공·오로라 테두리 |

10서식지별 졸업 카드/도장도 구현됐으며 보상 확인·미확인 카드 복원은 확장 설계를 따른다.

## 13. 에셋 규격

물고기별 투명 PNG를 `assets/fishing/`에 둔다.

- 기준 캔버스: `96×96px`
- 32~48px로 줄여도 실루엣이 구분되는 픽셀 아트
- 물고기 20장
- 찌 기본/입질 2장
- 물튀김 효과 1장
- rare 이상 결과 카드용 이펙트는 코드 도형 또는 별도 에셋으로 결정

권장 파일명은 데이터 ID의 마지막 부분과 일치시킨다. 예: `crucian_carp.png`, `coelacanth.png`.

## 14. v0.1 초기 구현 순서 (역사 기록)

1. `WorldTime` 공통 시스템
2. DAWN/DAY/DUSK/NIGHT 월드 색·조명 보간
3. 건물·가로등 조명
4. `WeatherManager`와 6시간 구간 판정
5. 비·폭풍 시각 효과
6. 낚시 기본 동작: 무조건 성공
7. 지역별 Fish Pool 필터와 상대 가중치
8. 20종 데이터와 크기·등급·가격
9. Fishing XP와 레벨 보상
10. 도감·수집 보상 (구현 완료, 현재 미발견 힌트는 비공개)
11. rare/heroic/legendary 결과 연출 (구현 완료)
12. 낚싯대 장비 선택과 효과 (구현 완료)
13. 인벤토리 실제 아이템 화면 (구현 완료)

## 15. 현재 기본 완료 기준

- 정상 장비로 낚시 가능한 물가에서 시작한 입질은 실패/도망 없이 획득한다. 파손 장비는 시작할 수 없고 저장 실패 때는 입질 상태에서 동일 개체로 재시도한다.
- 결과는 현재 시간·날씨·지역에 맞는 Fish Pool에서 선택된다.
- 같은 어종 3연속 보정이 동작한다.
- 크기·가격·XP·보상·도감·인벤토리·내구도는 저장 성공 시 한 번에 갱신되고 실패 시 함께 취소된다.
- 월드 시간과 날씨가 낚시 외 월드에도 반영된다.
- 새로고침 후 수집과 레벨이 유지된다.
- 장착한 낚싯대와 해금 조건이 저장 후에도 유지되고 실제 추첨·대기·크기에 반영된다.
- 모바일 조이스틱 감각과 PC 키보드 이동을 변경하지 않는다.
- `node scripts/check.mjs`, `node scripts/build.mjs`가 통과한다.

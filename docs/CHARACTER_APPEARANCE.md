# 캐릭터 외형·장비 표시 기준

## 현재 연결된 것

- 기본 의상은 `outfit.traveler`(여행자의 옷)로 등록한다. 보유·착용 의상 ID와 손에 들 도구(`axe` 또는 `rod`)를 저장한다. 이전 저장에 외형 정보가 없으면 기본 의상·도끼를 사용한다.
- 가방 장비 탭에서 손에 들 도구를 선택한다. 새 도끼나 낚싯대를 장착하면 해당 종류가 손에 표시된다. 낚시 중에는 선택 도구와 관계없이 낚싯대를, 벌목 동작 중에는 도끼를 잠시 표시한다.
- 기본 걷기 시트와 벌목 시트는 로딩 시 몸·기본 의상 두 캔버스 레이어로 나누어 같은 위치에 재합성한다. 원본 PNG는 변경하지 않으며 현재 모습도 바꾸지 않는다. 가방에 기본 의상을 장착 항목으로 표시한다.
- 새 의상 정의는 투명한 **의상 전용** 걷기·벌목 시트를 같은 프레임 배치로 제공해야 한다. 몸 레이어는 공유하고 의상 레이어만 교체한다. 의상 그림 하나만 등록하고 벌목 프레임을 빼먹는 방식은 허용하지 않는다.

## 이미지·좌표 계약

| 동작 | 시트 크기 | 셀 | 프레임·방향 |
| --- | --- | --- | --- |
| 걷기/대기/현재 낚시 | 288×384 | 96×96 | 가로 3프레임, 세로 아래·오른쪽·왼쪽·위. 실제 왼쪽 걷기는 오른쪽 행을 반전한다. |
| 벌목 | 640×1280 | 320×320 | 가로 준비·휘두름, 세로 아래·오른쪽·왼쪽·위. |

두 시트 모두 각 프레임의 발 위치와 머리 중심을 기존 그림에 맞춰야 한다. 원본 해상도가 같아도 손잡이 끝·손 위치가 다르면 도구별 그리기 범위와 손 좌표를 별도로 확인한다. 손에 든 도끼·낚싯대는 캐릭터 그림에 합치지 않고, 방향과 동작에 따라 앞/뒤에 그린다.

## 아직 남은 부분

- 현재 기본 몸 레이어는 기존 합성 그림에서 옷 색상/몸 위치를 기준으로 추출한 것이다. 옷 아래 맨몸 형태가 완성된 별도 원화는 아니다. 새 옷은 기본 의상 영역을 충분히 덮는 그림으로 제작해야 하며, 첫 새 의상 제작 시 몸·의상 경계의 잔여 픽셀을 검수해야 한다.
- 머리카락과 가방은 아직 독립 교체 레이어가 아니다. 캐릭터 생성에서 머리/얼굴을 선택하거나 의상 실루엣을 크게 바꾸기 전에 전용 몸·머리·가방 레이어를 만들어야 한다. 지금의 분리가 모든 조합을 자동으로 해결한다는 뜻은 아니다.
- 전용 낚시 자세는 아직 없어서 낚시 중에는 걷기/대기 자세에 낚싯대를 표시한다. 새 자세를 만들면 모든 착용 의상의 대응 프레임도 함께 마련한다.
- 의상 구매·교체 상점은 아직 없다. 현재는 기본 의상 한 벌만 보유한다.

Android에서는 네 방향 이동 중 도끼·낚싯대 손 위치, 벌목·낚시 시 임시 도구 전환, 가방의 도구 선택·재접속 저장을 확인한다.

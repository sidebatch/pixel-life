# 던전 외형·탐방 v1

작성: 2026-10-22 · 상태: 로컬 구현, 공개 배포 전

최신 그림은 후속 [몬스터 교체·우두머리 표시 v2](DUNGEON_ART_ROYAL_V2.md)를 따른다. 리치·샌드웜을 왜가리·아르마딜로로 교체했고 브락·보른을 다시 그렸으며 모든 우두머리에 식별 효과를 넣었다. 아래 제작 규격·출입·미구현 전투 범위는 유지한다.

사용자 요청은 조합·보상 구현보다 **많은 몬스터의 그림을 먼저 만들고, 실제 굴 입구로 들어가 둘러보는 것**이다. 확정한 지역 10곳과 이름 60종을 적용했다. 일반 50종·우두머리 10종이며, 기존 야생동물 5종을 재사용하고 55종을 새로 제작했다.

## 들어가는 방법

마을 우측 아래의 기존 굴 입구 → **던전 갈림길** → 원하는 지역의 굴 입구로 걸어 들어간다. 갈림길에는 지역 입구 10개와 마을 귀환 입구 1개가 있다. 입구 이름은 바닥 가까이에 표시하여 상단 정보창에 가리지 않도록 했다.

모든 지역은 들어온 북쪽 굴로 돌아가면 갈림길로 나온다. 들녘 숲은 기존 들녘 사냥터를 활용하고 입구를 북쪽 바위 아래에 배치했다. 갈림길 서쪽의 **라일락 마을** 굴에서 마을로 나간다. 출입 때 도착 지점을 입구에서 떨어뜨려 즉시 되돌아가거나 캐릭터가 굴 그림 뒤에 숨는 것을 방지했다. 기존 저장 위치는 유지하며 안전 스폰과 새 진입 위치만 새 입구 앞을 사용한다.

신규 9개 지역은 여섯 방과 연결 통로를 사용한다. 지역별 바닥·벽 색, 굴 입구, 몬스터를 구분했다. 현재는 공통 방 구조를 사용하는 외형 확인 단계이며, 최종 사냥 동선·기믹·지역별 독자 지형은 후속 작업이다.

## 제작 기준과 파일

내장 `image_gen.imagegen`으로 기존 멧돼지·곰·굴의 픽셀 질감과 시점을 참고하여 투명 배경으로 생성했다. [전체 프롬프트·원본 위치](art/dungeon-prompts-v1.json)에 10회 생성 기록을 남겼다. 외부 게임의 그림을 복사하지 않았다.

- `assets/dungeons/brak-v1.png`: 192×192, 96px 셀 네 방향. 발 기준 90px.
- 나머지 `*-v1.png`: 384×256, 128px 셀 3열×2행. 일반 5종과 우두머리 1종, 발 기준 118px.
- `*-gate-v1.png`: 320×256 투명 굴 입구 9개. 기존 들녘 입구 그림도 재사용한다.
- `*-icon-v1.png`: 128×128 지역 아이콘 9개와 갈림길 전용 합성 아이콘 1개.
- 총 29개 PNG를 등록했다. 이름이 다른 지역은 다른 아이콘을 사용한다.

그림 가공은 `scripts/pack-dungeon-assets.mjs`에서 생성된 픽셀의 연결 영역을 찾아 자르고 최근접 축소·배치만 한다. 원본은 생성 도구가 저장한 위치에 보존한다. 캔버스 코드로 몬스터를 대신 그리지 않는다. 표시할 때 발 위치와 깊이 정렬을 고정하고, 작은 호흡 움직임은 동작 줄이기 설정을 따른다.

## 구현 범위

새 몬스터 55종은 이름·외형·배치·충돌·호흡 표시까지 구현했다. 새 몬스터의 이동·피격·공격·반격·처치·재등장·드롭·경험치·도감 등록은 아직 구현하지 않았다. 기존 동물 5종의 전투만 유지한다. 브락 역시 이번에는 외형 확인용이다.

[들녘 숲 전투·조합·보상 표](HUNTING_MEADOW_BALANCE_V1.md)의 일반 가죽 30→튼튼한 가죽 1, 철검 재료 튼튼한 가죽 3+브락 엄니 1은 계속 기획 상태다. 이번 탐방으로 돈·아이템·레벨을 지급하거나 소모하지 않는다.

저장 버전 2를 유지하고 새 지역 저장·재접속을 지원한다. 물이 없는 새 던전은 낚시 지점을 두지 않으며, 해당 지역에만 건조 지역 검증을 적용한다. 기존 낚시 지역의 수면·지점 검증은 유지한다. 기존 세이브 위치에 새 장애물이 생기면 기존 안전 스폰 선택 로직을 따른다.

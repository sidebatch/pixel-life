상태: **설계안 / 게임 코드 미적용**

기준일: 2026-09-28

상위 방향: [`LONG_TERM_CONTENT_DESIGN.md`](LONG_TERM_CONTENT_DESIGN.md)
현재 구현 수치: [`FORESTRY_BALANCE.md`](FORESTRY_BALANCE.md), `src/data/life-content-data.js`

## 1. 목표와 지켜야 할 기존 상태

도끼를 총 10단계로 확장한다. 하급 도끼로 상급 나무를 베는 도전은 **오래 걸리고 비효율적이지만 가능**해야 한다. 상급 도끼를 얻으면 예전 나무는 눈에 띄게 빨리 베어지고, 새 나무도 현실적인 시간에 벨 수 있어야 한다. 현재 철 도끼까지의 획득 난이도는 사용자가 괜찮다고 평가했으므로 무턱대고 올리지 않는다. 그다음 강화는 훨씬 길고 다층적인 목표로 만든다.

현재 게임은 도끼 4종, 나무 8종, 나무 종별 최소 도끼 제한, 명장의 도끼라는 이름, 수리/내구력 없음, 장비 하나 필수 선택 상태다. **이 설계의 표와 규칙은 아직 게임에 적용되지 않았다.** 새 그림과 저장 이행·Android QA를 끝내기 전까지 현재 구현 문서를 미래 규칙으로 덮어쓰지 않는다.

## 2. 도끼 이름과 진행표

| 단계 | 제안 이름 | 기존/신규 | 대표 성격 | 획득 장벽 방향 |
| ---: | --- | --- | --- | --- |
| 1 | 기본 도끼 | 기존 `axe.basic` | 시작 장비, 무료 수리 | 처음부터 소유 |
| 2 | 철 도끼 | 기존 `axe.iron` | 하급 나무에서 벌목 속도 첫 도약 | 현재 철 도끼의 재료·코인 흐름 유지 |
| 3 | 강철 도끼 | 기존 `axe.steel` | 중급 나무 효율 개선 | 현재 소유/구매 흐름 유지, 효율 재시험 |
| 4 | **청금 도끼** | 기존 `axe.master`의 표시명 변경 제안 | 현행 파란 보석·금장식 이미지와 맞는 장비 | 현재 소유 ID·그림·재료/가격은 우선 보존 |
| 5 | 흑철 도끼 | 신규 | 일반 금속보다 무겁고 강한 고급 단계 | 4단계 보유 + 벌목 성장 + 4단계 목재 + 코인 |
| 6 | 룬 도끼 | 신규 | 새겨진 문양과 고유 이펙트 | 5단계 보유 + 5단계 재료 + 코인 + 분야 목표 |
| 7 | 정령 도끼 | 신규 | 숲과 연결된 장비 | 6단계 보유 + 6단계 재료 + 코인 + 도전 |
| 8 | 달빛 도끼 | 신규 | 희소성이 눈에 보이는 장비 | 7단계 보유 + 7단계 재료 + 코인 + 장기 목표 |
| 9 | 별빛 도끼 | 신규 | 최고 구간 직전의 상징 | 8단계 보유 + 8단계 재료 + 코인 + 장기 목표 |
| 10 | **태초의 도끼** | 신규 | 매우 느리게 도달하는 최종 장비 | 9단계 보유 + 9단계 재료 + 큰 비용 + 벌목 장기 성취 |

1–5단계는 금속·보석, 6–10단계는 숲의 판타지라는 시각적 상승 흐름이다. `청금`은 기존 4단계의 파란 보석·금장식 원화에서 따온 **표시명 제안**이다. 4단계의 내부 ID `axe.master`는 저장 호환 때문에 즉시 바꾸지 않는다. 더 높은 단계의 그림은 그보다 분명하게 구별돼야 한다. 이 이름들은 이번 설계의 제안이지 새 에셋 제작/구매 UI에 이미 반영된 이름이 아니다.

신규 5–10단계의 벌목 레벨 조건 초안은 순서대로 **Lv.30 / 45 / 60 / 75 / 90 / 100**이다. 기존 2–4단계에 새 레벨 제한을 소급하지 않는다. 레벨만으로 자동 지급하지 않고, 이전 도끼의 **소유**, 코인, 바로 전 구간 나무의 보편적으로 얻을 수 있는 목재/분야 목표를 함께 요구한다. 0.1%짜리 희귀 재료나 아직 만들 도끼로만 얻을 수 있는 나무를 필수 제작 재료로 요구하지 않는다. 정확한 목재 개수·코인·XP 조건은 실제 시간당 수익을 잰 뒤 확정한다. Lv.100 이후 숙련도는 최종 도끼의 필수 구매 조건보다는 외형/칭호의 추가 장기 목표로 남긴다.

## 3. 나무 10단계·50종 제작 목록

제작 대상 50종의 **이름·ID·단계·이미지 특징**은 [`FORESTRY_TREE_CATALOG.md`](FORESTRY_TREE_CATALOG.md)를 단일 기준으로 삼는다. 단계마다 5종, 1–7단계 실제 수종 35종과 8–10단계 판타지 수종 15종이다. 이전 이 문서의 22종 계획과 3개씩 나열한 후보 표는 폐기했다. 현재 목록의 50종은 이미지 제작을 시작하기 위한 명단이며, 현재 게임에 적용됐거나 HP·도끼 난도가 확정됐다는 뜻은 아니다.

현실 목재의 경도는 초기 Tier 구성을 생각할 때 참고한 배경 정보일 뿐이다. **제작 카탈로그에 경도값·출처 필드를 추가할 필요가 없고, 게임 HP 공식이나 플레이어 표시 정보로 사용하지 않는다.** 나무의 HP와 도끼 피해·타수는 줄기 크기·지역·희소성·플레이 시간을 별도로 시험해 정한다. 판타지 수종의 현실 경도값을 만들지 않는다.

| 구간 | 제작 기준 | 검토할 게임 맥락 |
| --- | --- | --- |
| 1–3단계 | 익숙한 실제 나무 15종 | 시작 숲과 새 숲으로 차근차근 확장 |
| 4–5단계 | 수형·지역성이 강한 실제 나무 10종 | 숲의 깊이, 거목의 크기·체력은 경도와 별도 |
| 6–7단계 | 고급 목재의 특징이 뚜렷한 실제 나무 10종 | 지역·목재 용도·시각적 차이 |
| 8단계 | 고대 숲 판타지 나무 5종 | 현실 숲과 판타지 숲의 연결 |
| 9단계 | 정령·달빛 등 판타지 나무 5종 | 고유 실루엣과 목재 단서 |
| 10단계 | 태초 숲 판타지 나무 5종 | 최종 구간의 희소성과 구별성 |

현재 게임의 8종 `oak/pine/birch/maple/spruce/willow/cypress/broadleaf`와 보유 목재 ID는 유지한다. 현행 단계 `1/1/1/2/2/2/3/3`을 카탈로그 단계로 바꾸는 일은 나무 HP·맵·레시피·상점·저장 복원에 영향을 주므로 이미지 제작과 별개의 게임 이행이다. 동일 나무의 HP·XP·드롭은 맵에 따라 임의로 바뀌지 않게 한다. 새 지역은 아직 미구현이며, 높은 단계 나무를 만나러 숲 깊이 갈 수는 있어도 도끼 등급만으로 지역 입장을 막지 않는다.

**기존/신규 이름 매핑:** 기존 `cypress`는 현행 게임에서 '삼나무'로 보이지만 카탈로그에서는 **편백나무**다. 내부 `cypress`와 목재 `cypress_log` 및 보유 수량을 그대로 두고 표시명만 바꾼다. 새 **삼나무**는 `cedar`/`cedar_log`로 추가한다. 두 표시명은 게임 연결 시 함께 바꿔 중복되지 않게 한다. `broadleaf`는 카탈로그에서 플라타너스로 재해석하지만 내부 `broadleaf`/`broadleaf_log`를 보존하고 기존 그림의 적합성을 확인한다. 이 매핑은 아직 게임 코드에 적용되지 않았다.

신규 수종 42종×나무·그루터기·목재 아이콘 3장 = **126장**이 필요하다. 사용자가 고른 [목재 아이콘 스타일 예시](references/forestry-item-style-2026-09-28.png)에 맞춰 기존 8종의 목재 아이콘도 후보로 다시 만들면 총 **134장**을 제작·검토한다. 참고 비교판은 글씨와 배경이 있는 이미지이지 게임용 PNG가 아니다. 게임에는 120×144 투명 나무, 96×96 투명 그루터기·목재 아이콘을 수종별로 따로 등록한다. 원본 기존 8종 파일은 후보 검수 전까지 덮어쓰지 않는다. 첫 작업은 [1단계 자산 제작안](FORESTRY_TIER1_ASSET_BRIEF.md)의 신규 2종×3장과 기존 3종 목재 아이콘 후보, 총 9장이다.

종별 목재는 판매뿐 아니라 상위 도끼·수리(추후 결정)·가구/집 재료에도 쓰인다. 10단계 도끼 제작은 주로 9단계의 보편적인 목재를 사용하고, 10단계 나무의 초희귀 보상은 장비 제작 후 집/직업 의상/꾸미기 같은 목표로 남긴다.

## 4. 벌목 속도·보상·도전의 목표

| 비교 | 플레이 목표(확정 수치 아님) |
| --- | --- |
| 기본 도끼 → 1단계 나무 | 현재 5타 수준을 기준으로 보존 |
| 철 도끼 → 1단계 나무 | 약 2타로 확실히 쉬워졌다고 느낌 |
| 적정 단계 도끼 → 같은 단계 나무 | 대체로 3–6타; 종별 차이와 동작감 검토 |
| 크게 낮은 도끼 → 고급 나무 | 장시간 타격과 더 큰 내구력/시간 소모, **피해 0이나 절대 불가 없음** |
| 기본 도끼 → 10단계 나무 | 완충전/수리 후 도전할 수 있는 극단적 과제; 예시 목표 80–150타, Android 반복 입력 부담과 실제 시간을 반드시 검증 |

나무 HP, 도끼 피해, 최소 피해, 타격 간격을 **함께** 시뮬레이션해 위 체감을 만든다. 현재 `treeType.tier` 강제 차단을 제거하더라도 하급 도끼로 최고급 목재를 대량 생산하는 편이 최적 수익/XP가 되면 안 된다. 보상은 완전 벌목에 한 번만 지급하고, 시간당 목재·XP·판매 수익과 수리비를 함께 검토한다. 하급 장비로 드물게 성공한 도전은 장비/수종을 기록하는 칭호·업적으로 인정하되 자원 보너스를 과하게 주지 않는다. 부분 HP 저장, 완료와 내구력 0이 같은 타격에 일어났을 때의 처리, 맵 이동·재접속·나무 재생을 회귀 검사한다.

## 5. 내구력·수리·‘바사삭’ 고장 규칙

**이번 요청에서 분명해진 규칙:**

1. 기본 도끼는 내구력이 0이어도 **코인·재료 없이 무료 수리**할 수 있다. 이후 도끼(철부터)는 수리비가 있다.
2. 내구력이 0이 되는 **그 타격**은 정상 적용한다. 이 타격으로 나무가 쓰러졌다면 목재와 XP도 먼저 지급한다. 그다음 도끼가 `수리 필요` 상태로 바뀌고, 장착 중이었다면 **자동 장착 해제 → 빈손**이 된다.
3. 0으로 바뀌는 순간 짧은 ‘바사삭’ 고장 효과음을 **한 번만** 재생한다. 단순히 0 상태 가방을 열거나 재접속·수리창 진입 시 재생하지 않는다. 소리의 최종 파일과 다른 효과음 대비 음량은 구현 때 선정하고 Android에서 타이밍을 검증한다.
4. 내구력 0인 도끼는 가방에서 보유·상세 확인·수리는 가능하지만 **장착 불가**다. 수리 성공 후에는 자동 장착하지 않고 사용자가 다시 선택한다. 빈손이어도 이동, NPC 대화, 상점 이용과 수리는 가능해야 한다.
5. 0이 되어도 도끼를 삭제하거나 최대 내구력을 영구히 줄이지 않는다. 0이 아니어도 미리 수리할 수 있다. 수리 거래는 결제·내구력 복원·저장에 실패 시 한꺼번에 되돌린다.

**수리비 초안:** 기본 도끼 무료. 철 이상 도끼의 0→100% 전체 수리비는 해당 단계 최초 구매 코인 가격의 **대략 4–8%**를 출발점으로 삼되 실제 벌목 한 내구력 주기에서 벌어들이는 코인의 대략 **5–12% 이내**인지 확인해 조정한다. 부분 수리는 부족한 내구력 비율만큼만 지불한다. 초반에는 코인만 받는 단순한 수리가 적합하며, 재료까지 요구할지는 플레이 테스트 뒤 결정한다. 예시로 철 도끼가 현재 3,600코인이면 전체 수리비 시안은 약 150–290코인 범위다. **이는 확정 가격이 아니다.** 상위 구매가만 무작정 키워 수리비가 감당 불가능해지지 않게 단계별 수익으로 상한을 둔다. 기본 도끼만큼은 코인 0에서도 항상 복구 가능해야 한다.

내구력 감소는 나무에 실제 피해를 준 타격에만 적용한다. 허공에서 휘두르거나 고장난 도끼로 행동 버튼을 누른 경우 감소/소리가 없다. 장거리 최고급 나무 도전이 가능하도록 기본 도끼의 한 번 완전 수리 내구력과 10단계 나무 예상 타격 수를 **함께 설계**한다. 도중 고장나더라도 종별 부분 HP가 저장되므로 재수리 후 이어서 도전할 수 있게 한다. 낮은 내구력 경고는 가방 카드와 필요할 때의 간단한 HUD로 충분하며, 평상시 화면에 큰 막대를 상시 띄우지 않는다.

**현재 코드에서 필요한 설계 변경점:** 장착 도구가 반드시 `axe`/`rod`/`sword` 하나인 저장·렌더·상호작용 가정을 깨고 `none`(빈손)을 유효한 상태로 추가해야 한다. `getEquippedForestryAxe()` 등의 기본 도끼 자동 대체가 0 내구력의 강제 장착으로 이어지지 않도록 행동·UI에서 명시적으로 검사한다. 도끼 소유 ID는 유지한 채 장비별 현재/최대 내구력을 저장하고 기존 세이브의 보유 도끼에는 안전한 기본값을 준다. 고장 직후 저장에 실패하면 나무 HP/보상/내구력/장착 상태를 함께 롤백하고 고장음·중복 보상을 확정하지 않는다. 이후 같은 공통 계약을 검·낚싯대·낫·방어구/방패에 확장할 수 있다.

## 6. 디자인 검증과 구현 순서

1. [`FORESTRY_TREE_CATALOG.md`](FORESTRY_TREE_CATALOG.md)의 50종 ID·이름·단계와 `cypress`/`cedar` 표시명 이행을 검토한다. 이 제작 목록에 경도값/출처를 필수 필드로 추가하지 않는다. 기존 `axe.master`는 표시명만 바꾸는 이행이 가능한지 점검한다.
2. 나무 HP·도끼 피해·내구력 주기·수리비·목재 가격의 10단계 시뮬레이션 표를 만든다. **철 도끼의 기본 나무 2타**, 적정 도끼의 해당 나무 3–6타, 기본 도끼의 최상급 나무 도전 가능성을 수치로 증명한다.
3. 1–4단계 벌목의 절대 도끼 제한을 소프트 난이도로 바꾸고 Android에서 타격·누르기 유지·부분 HP·수익/시간을 검증한다. 이때 새 나무 약 42종이나 새 도끼 6종을 한꺼번에 요구하지 않는다.
4. 기본/철 도끼의 내구력·무료/유료 수리·0 자동 빈손·장착 불가·고장음·저장 이행을 수직 슬라이스로 검증한다. 그다음 기존 나머지 도끼와 다른 도구로 공통화한다.
5. 새 지역/나무/목재/도끼는 두세 단계씩 추가한다. 신규 에셋은 [`LIFE_ASSET_STANDARD.md`](LIFE_ASSET_STANDARD.md), 도끼 손/동작은 [`CHARACTER_ASSET_STANDARD.md`](CHARACTER_ASSET_STANDARD.md)와 보호된 검 규격을 따른다. 변경 시 기존 4도끼·8나무·남녀/4방향·저장·상점·가방·사운드 회귀와 Android 실기기를 확인한다.

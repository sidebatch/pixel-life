## 부지와 배치

- 햇살 농장의 지정된 16칸을 개별 영구 구매한다. 기존 구매 가격·목재 비용과 초기 4칸을 유지한다. 아무 곳에 밭을 놓거나 집 구매를 요구하지 않는다.
- 밭은 x=15/17/19/21, y=22~25의 세로 한 줄씩 네 줄이다. 사이 x=16/18/20 및 양옆 x=14/22, 위아래 y=21/26은 연결된 통로다.
- `farm_01`~`farm_16` ID와 배열 순서를 유지한다. 초기 소유는 01/02/05/06이며 저장의 unlocked/cropId/plantedAt은 그대로 새 위치에 대응한다. 심은 작물을 다시 심거나 시간을 초기화하지 않는다.
- 48px 픽셀 흙 이미지 `assets/farming/terrain/soil-v1.png`를 연속된 밭 줄로 그린다. 잠긴 부지도 같은 흙 그림에 옅은 표시와 작은 잠금만 사용한다. 제작 원본은 `scripts/prepare-farm-pixel-assets.mjs`의 코드 기반 픽셀 도형이다.

## 이동과 수확

- 사용자 추가 결정에 따라 밭 자체를 고정 이동 장애물로 등록한다. 구매 전·빈 밭·씨앗·성장 중·성숙·수확 후 모두 통과할 수 없다. 플레이어/NPC 모두 옆 통로에서만 이동하며 심기/구매/수확은 인접 통로에서 한다.
- 성숙 작물은 캐릭터·나무와 같은 깊이 정렬에 참여한다. 밭 바닥 위에 미리 그려 캐릭터가 항상 덮는 방식에서 분리했다.
- 정상 이동으로는 밭에 올라갈 수 없다. 과거 저장이 빈 밭/성장 중/성숙 밭 위의 위치를 가리키면 지역의 안전한 시작점으로 복구하며, 시험 중 강제로 밭 위에 놓인 캐릭터도 옆 통로로 옮긴다. 부지 소유·작물·성장시간은 보존한다.
- 기본 낫은 새 게임과 기존 저장 모두 가방의 장비에 자동 제공되며 소유 필드를 추가하거나 기존 장비를 해제하지 않는다. 선택한 activeTool `sickle`만 기존 appearance 저장에 추가한다.
- 가방에서 낫 장착 또는 다 자란 밭 패널의 `기본 낫 장착` → `낫으로 수확`. 낫이 장착된 경우 앞쪽 작물에서 행동 버튼/인접 타일 터치로 곧바로 휘두른다.
- 실제 인접한 밭 한 칸만 수확한다. 270ms 타격/700ms 종료, 타격 시 한 번 지급한다. 수확물은 기존 개수 규칙으로 가방에 들어가며 밭은 비워져도 계속 이동을 막는다. 중복 입력·멀리 있는 밭·다른 장비 수확을 막는다.
- 기본 낫은 내구도 무제한이다. 상위 낫·농사 XP/레벨·물주기·집 텃밭·자동 재심기·반복 수확·작물 도감은 이번 구현에 포함하지 않는다.
- 씨앗 한 개를 소비해 기존처럼 심는다. 상점은 작물명·보유량·성장시간·가격을 표시하며 `수확 N~M개` 설명은 표시하지 않는다. 실제 수확 개수/가격/성장시간은 변경하지 않는다.
- 작물 제거와 아이템 지급은 기존 원자적 저장을 사용한다. 저장 실패 시 둘 다 복원되므로 작물을 잃지 않는다. 밭의 고정 이동 차단은 저장 성공 여부와 관계없이 유지된다.

## 낫 그림·모션 규격

- 공개 v1 그림은 `assets/player/sickle-v1/basic.png`다. 사용자 피드백으로 로컬은 `assets/player/sickle-v2/basic.png`의 짧은 손잡이/긴 곡선 날을 사용한다. grip=(19,62), tip=(43,21), bladeTip=(86,55), 제작/패킹/검증은 [SICKLE_ART_V2.md](SICKLE_ART_V2.md)를 따른다. v2 그림은 사용자 요청으로 공개 배포·검증 중이다.
- 독립 `src/data/farming-data.js`의 SICKLE_ACTION/SICKLE_TOOLS를 사용한다. 기존 chop Body/Grip과 머리 이동을 공유하며 낫의 각도·표시 길이만 별도 등록한다. 몸·손 좌표·옷·기존 도끼/낚싯대/검 원화와 데이터는 변경하지 않는다.
- 현행 캐릭터 보호 계약은 `character-standard-v5.json`이다. v4 계약은 역사로 보존한다. 확장은 낫 도구와 동작군이며 기존 도구 검사·검 전용 보호 검사를 계속 수행한다.

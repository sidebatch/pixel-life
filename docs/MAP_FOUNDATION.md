# Map Foundation 1.0

## 월드 규격

- 논리 타일: 48×48px
- 현재 맵: 64×48타일
- 현재 월드 픽셀 크기: 3,072×2,304px
- 최외곽 한 줄: 이동 불가 경계
- 카메라 크기: 540×960px
- 좌표 원점: 좌상단 `(0, 0)`

맵 크기는 `src/data/world-map.js`의 `width`, `height`, `tileSize`에서만 정의한다. 이동, 충돌과 카메라는 이 값을 자동으로 사용한다.

## 데이터 레이어

### Path

수평 또는 수직 선분으로 정의한다. 대각선 선분은 금지하며 자동 검사에서 오류 처리한다. 길은 시각 레이어이므로 기본적으로 충돌을 만들지 않는다.

### Stone area

`x`, `y`, `w`, `h` 직사각형으로 정의한다. 광장처럼 연결된 표면에 사용한다.

현재 시각 표현은 벽돌 격자가 아닌 연결된 흙/잔돌 표면이다. 잔돌은 월드 좌표 기준으로 고정하며 화면 밖은 그리지 않는다. 논리 타일과 이동 판정에는 영향을 주지 않는다.

### Water area

직사각형 영역으로 정의하고 필요하면 `cutCorners`로 네 모서리를 제거한다. 물 타일은 자동으로 충돌 타일이 된다.

### Bridge

물 위의 수평 또는 수직 선분으로 정의한다. 해당 타일의 물과 충돌을 제거한다.

### Solid object

건물, 나무, 바위, 표지판, 벤치와 가로등은 충돌을 만든다. 같은 충돌 타일을 두 오브젝트가 공유하면 안 된다.

### Ground decoration

꽃, 작은 풀, 수풀과 갈대는 통과 가능하며 캐릭터보다 아래에 렌더한다. 갈대를 제외한 일반 지상 장식은 물 타일에 배치하지 않는다.

## 건물 규격

건물은 다음 데이터를 반드시 포함한다.

```js
{
  id: 'building_id',
  x: 19, y: 16, w: 5, h: 4,
  drawW: 300, drawH: 293,
  depthLine: 4,
  artAnchor: { doorCenterX: 158, groundOffsetY: 10 },
  entrance: {
    door: { x: 21, y: 19 },
    approach: { x: 21, y: 20 }
  }
}
```

- `door`는 footprint 내부에 있어야 한다.
- `approach`는 footprint 외부에 있어야 한다.
- `door`와 `approach`는 정확히 한 타일 떨어져 있어야 한다.
- `approach`는 물, 나무 또는 다른 고정 오브젝트로 막히면 안 된다.

마을 정비 v1은 작은 3×3 집부터 큰 8×5 회관까지 7개 footprint 계열을 사용한다. 그림·문/바닥선·깊이 정렬 계약은 공통으로 유지하고 건물 크기를 한두 가지로 제한하지 않는다. 실제 계열/서비스 연결 기준은 [VILLAGE_POLISH_V1.md](VILLAGE_POLISH_V1.md)를 따른다.

## 자동 검사

`node scripts/check.mjs`는 다음을 검사한다.

- 맵 밖 좌표
- 대각선 path/bridge
- 중복 콘텐츠 ID
- 건물 footprint 겹침
- 건물과 물 겹침
- 잘못된 문과 접근 타일
- 막힌 플레이어 시작점
- 막히거나 중복된 NPC 시작점
- 물이 아닌 낚시 지점
- 일반 지상 장식과 물의 겹침
- 존재하지 않는 런타임 에셋

## 숲 연결 기준 v1

현재 첫 숲은 마을 남쪽이다. 1-1~1-5/거목 숲은 남쪽 줄기, 나머지 일반 상위 숲은 1-1 북서/서/동 분기, 고대/정령/태초 숲은 마을 북쪽이다. [FOREST_ROUTES_V2.md](FOREST_ROUTES_V2.md)의 정정된 왕복/나무 팻말 기준을 따른다. 새 길은 원래 나무 생성 이후에 추가하며 나무의 저장 ID/좌표/수종과 물을 변경하지 않는다.

## 디버그 표시

게임 실행 중 F3을 누르거나 URL 끝에 `?debug`를 추가한다.

특정 타일에서 시작해 검사하려면 `?debug&x=10&y=10`처럼 좌표를 함께 지정한다. 맵 밖 또는 충돌 타일은 무시된다.

- 흰 선: 타일 그리드
- 붉은 영역: 충돌 타일
- 노란 외곽선: 건물 footprint
- 파란 타일: 문
- 노란 타일: 문 접근 위치
- 청록 외곽선: NPC 로밍 범위

## 신규 배치 체크리스트

1. 고유한 ID를 지정한다.
2. 모든 좌표를 정수 타일로 작성한다.
3. 건물은 footprint, door, approach와 depthLine을 모두 지정한다.
4. NPC는 물, 고정 오브젝트와 건물 접근 타일을 피한다.
5. `node scripts/check.mjs`를 실행한다.
6. F3 화면에서 충돌과 깊이 기준을 확인한다.
7. 모바일 화면에서 주요 경로를 직접 이동한다.

## 굴 입구와 지형

마을 (48,35)의 나무 문틀을 이끼 낀 바위 둔덕의 굴로 교체했다. 어두운 입구 안쪽을 불투명하게 그리고 통로 바닥이 뒤로 이어지게 해 배경이 문틀 사이로 보이던 모습을 없앴다. 지붕과 양쪽 바위는 충돌하며 가운데 남쪽 문턱으로 들어간다. 북쪽 길에서 둔덕 오른편을 돌아 남쪽 입구로 이어지는 접근로를 만들었다. 사냥터 진입 (12,37), 출구 (12,40), 마을 복귀 (48,37)는 유지한다. 지역 아이콘도 같은 굴 원화로 바꿨다.

들녘 사냥터의 큰 평면 언덕 표현을 제거하고 이끼 바위 능선 8곳, 추가 나무·바위·수풀, 굽은 순환 길을 배치했다. 능선은 실제 충돌 지형이다. 그림은 인물과 같은 깊이 정렬을 사용하므로 앞뒤로 지나갈 때 높이감이 보인다. 연결된 길 203칸을 만들었으며 10개체의 출발점과 40개 인접 공격칸, 연못 가장자리, 출구가 모두 연결된다. 동물은 능선을 돌아 추격한다.

## 전투 규칙과 소리

- 플레이어와 야생동물 모두 유효한 공격 한 번당 독립적으로 60% 명중한다. 10회 중 6회를 강제하는 규칙이 아니다.
- 방향·거리·벽·공격 위치를 먼저 검사한다. 범위를 벗어난 공격이나 무적 중 피격에는 확률을 소비하지 않는다.
- 플레이어가 빗맞히면 `빗나감`, 동물 공격이 빗맞으면 `회피`를 표시한다. 체력·피격 무적·타격음을 적용하지 않는다. 실제 피해를 받은 개체만 반격한다.
- 동물의 빗나간 공격도 준비·휘두르기·복귀·재사용 대기를 끝까지 진행한다. 기존 600ms 준비, 1.5초 재사용, 피해량과 추격/귀소 규칙은 유지한다.
- 검·도끼·낫·낚싯대의 허공/전투 동작에 1회 휘두르는 소리를 넣었다. 도끼·검은 낮고 묵직하게, 낫·낚싯대는 가볍게 낸다. 실제 벌목·수확·낚시 음향은 기존 경로를 사용한다.
- 동물은 준비 동작의 72% 이후 공격 자세로 전환할 때 1회 휘두르는 소리를 낸다. 실제 명중 시에만 짧은 충격음이 추가된다. 플레이어 피격음은 더 낮게 구분한다.
- 효과음은 Web Audio의 필터 노이즈와 음높이 하강을 합성한다. 외부 음원과 게임 난수를 사용하지 않는다. 동작/메뉴 잠금으로 거절한 입력에는 소리를 내지 않는다.

생활 경제·보상·내구도·캐릭터 규격·장비 변환·저장 형식은 유지한다.

## 1. 새 세션 시작

- 실제 Git 저장소는 작업 폴더 안의 `pixel-life-path-redesign-v5/`다. 최상위 폴더의 WAV·첨부·옛 `pixel-life-web/`는 현재 배포 저장소가 아니다.
- GitHub: https://github.com/sidebatch/pixel-life · 공개 게임: https://sidebatch.github.io/pixel-life/

- 기본 도끼/기본 낚싯대는 내구도 무한이다. 벌목은 수종별 최소 도끼 제한 유지, 낮은 도끼의 상위 나무 도전/소프트 패널티는 추가하지 않는다.
- 기본 낚싯대·Lv.1도 장소/시간/날씨가 맞는 모든 74종에 도전할 수 있다. 상위 항로의 기존 해금과 승선권은 유지하며 어종에 새 강제 장비 제한을 넣지 않는다.

## 7. 용량과 QA 보존 운영

2026-10-12 측정: 전체 작업 폴더 약 **1.13GiB**, 실제 Git 저장소 약 923MiB, 배포 dist 약 35.73MiB. 고해상도 제작 원본/테스트/Git 기록 때문에 작업 폴더가 크며 사용자에게 전체가 전달되는 것이 아니다. 상세는 [PROJECT_STORAGE.md](PROJECT_STORAGE.md)다.

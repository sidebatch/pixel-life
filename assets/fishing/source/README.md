# 신규 낚시 원본 제작 기록

제작일: 2026-10-07

블루길·송사리·쏘가리·볼락·우럭 원본은 Codex의 내장 이미지 생성 기능으로 각각 한 장씩 제작했다. 배경은 실제 투명 알파이며, `scripts/process-fish-assets.py`로 여백·알파 가장자리를 정리하고 최근접 보간해 게임용 96×96 PNG로 변환했다.

공통 프롬프트는 다음 기준을 사용했다.

- 용도: 아늑한 생활 시뮬레이션의 2D 물고기 도감 스프라이트 원본
- 표현: 세밀하지만 절제된 자연색의 손그림 픽셀 아트, 해부학적으로 알아볼 수 있는 한 마리
- 구도: 오른쪽을 보는 완전한 옆모습, 모든 지느러미와 꼬리가 보이는 중앙 배치, 넉넉한 투명 여백
- 제한: 정확히 한 마리, 완전 투명 배경, 선명한 실루엣, 그림자·물·식물·거품·테두리·글자·로고·워터마크 없음
- 제외: 과장된 눈과 표정, 치비 비율, 사진 배경, 여러 마리

개별 대상 프롬프트:

- `bluegill.png`: 깊고 타원형인 담수 선피시 체형, 작은 입, 높은 가시 등지느러미, 올리브·차분한 청색 몸, 파란 뺨과 검은 귀덮개, 주황빛 아랫가슴
- `killifish.png`: 일본 송사리 형태의 작고 가느다란 은빛 베이지 몸, 살짝 위를 향한 입, 짧고 반투명한 지느러미, 따뜻한 금빛 등선
- `mandarin_fish.png`: 쏘가리의 튼튼하고 길쭉한 포식자 체형, 큰 입과 높은 가시 등지느러미, 황록색 몸, 짙은 갈색 표범 무늬와 띠, 옅은 배와 힘 있는 부채꼴 꼬리
- `rockfish.png`: 볼락의 단단한 연안 체형, 큰 눈과 입, 가시 등지느러미, 적갈색·올리브색 몸과 뚜렷한 짙은 세로 띠, 옅은 배와 부채꼴 지느러미
- `korean_rockfish.png`: 우럭의 튼튼하고 길쭉한 체형, 큰 입과 높은 가시 등지느러미, 검회색·흑갈색 몸과 은은한 얼룩, 옅은 배와 강한 꼬리

생성 원본은 이 폴더에, 게임용 결과는 한 단계 위 `assets/fishing/`에 보관한다.

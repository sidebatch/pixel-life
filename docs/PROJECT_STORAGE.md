# 프로젝트 용량 현황

측정일: 2026-10-12 · QA 정리 후, 이번 인수인계 문서 확장 전의 로컬 파일 크기 합계.

**개발 폴더 전체와 실제 배포 게임 크기는 다르다.** 아래 값은 파일의 논리 길이이며 압축 다운로드 크기·디스크 할당 크기·휴지통·브라우저 캐시를 포함하지 않는다. MiB/GiB는 1024 기준이다. 이후 문서/Git 커밋 등으로 조금 달라질 수 있다.

## 사용자에게 전달되는 게임

- 배포 dist는 약 **35.73MiB**(압축 전 파일 합계).
- HTML 약 **19.07MiB**: 코드/CSS/이미지/짧은 효과음 8개 내장.
- 긴 지역 음악 MP3 3개와 PWA 아이콘/매니페스트/서비스 워커는 별도 파일이다. dist 전체로 배포하며 HTML 하나만 옮기면 음악·설치·오프라인 전체를 보장하지 않는다.
- 고해상도 제작 원본/QA 캡처/로컬 Git 기록/원본 WAV/사용자 첨부 전체는 배포되지 않는다.
- 자세한 PWA 캐시/음악/검증은 [DEPLOYMENT.md](DEPLOYMENT.md)를 따른다.

## 승인된 QA 정리 결과

- 정리 전 output: 635,058,688 bytes = 605.64MiB.
- 휴지통 이동: 오래된 166개 파일/폴더 단위, 내부 **2,618파일 / 436,243,404 bytes = 416.03MiB**.
- 보존 검사 자료: 198,815,284 bytes = 189.61MiB. 작은 정리 보고서를 포함하면 189.62MiB.
- 전체 작업 폴더는 정리 전 약 1.54GiB → 약 1.13GiB. 게임 기능·원화/음악·검사 코드·기준선·Git 기록은 변경하지 않았다.
- 보존 내용 SHA-256 전후 일치, 반복 정리 시 대상 0/복구 기록 불변을 확인했다.
- 결과는 **Windows 휴지통**에 있으므로 복구 가능하다. 휴지통을 비우기 전에는 프로젝트 폴더 크기만 줄고 드라이브의 실제 여유 공간은 그만큼 늘지 않는다. 휴지통을 임의 비우지 않았다.

보존 정책과 검토 목록은 [QA_RETENTION.md](QA_RETENTION.md), [QA_RETENTION_V1.json](QA_RETENTION_V1.json). 성공 기록은 로컬 `output/qa-retention/recycle-2026-10-12.json`이다. 앞으로 검사별 기본 최신 결과/직전 비교/고정 재현만 유지하고 임시 중복을 검토한다.

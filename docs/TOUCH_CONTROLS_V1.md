# 터치 조작부 게임 도구 그림 v4

2026-10-13 사용자는 각진 나무 틀/픽셀 손 시안을 거부했고, 반투명 원형으로 수정한 v2 방향키는 괜찮아졌다고 승인했다. 이어 버튼 안 ‘행동’ 글자 제거·상황에 맞는 아이콘·필요할 때만 위에 짧은 안내 표시를 제안했고 ‘좋아요 그렇게 해주세요’로 구현을 요청했다. v3는 이 내용을 적용하고 방향키/버튼 위치·원형·색·크기를 유지한다. 아직 공개 배포 전이며 추가 농장 소품 5종도 로컬에 보존한다.

2026-10-14 사용자는 방향키와 작고 반투명한 원형 버튼은 좋지만 선으로 그린 낫이 실제 낫과 다르다고 지적했다. v4는 도구의 선 아이콘을 제거하고 캐릭터가 실제로 사용하는 같은 PNG를 버튼에 재사용한다. 낫은 기본 낫 v2 원본, 도끼/낚싯대/검은 현재 장착한 장비 그림이다. 방향키/원형·반투명/위치/버튼 크기·글자 없음·짧은 안내와 기존 행동을 유지한다. 아직 공개 배포 전이다.

## 디자인과 동작

- 스타일: styles/controls.css, index.html의 방향 화살표/비도구 SVG 기호·도구 img다. 버튼 안 ‘행동’ 글자는 없다. 도구 PNG는 기존 원본을 재사용하고 새로운 그림 파일을 만들지 않는다.
- 왼쪽 패드: 배경이 비치는 연한 초록 원형 바탕·작은 방향 화살표와 부드러운 원형 손잡이. 나무색 틀·각진 모서리·두꺼운 그림자·금색을 제거했다.
- 오른쪽 버튼과 하단 메뉴: 작은 원형/차분한 초록·얇은 밝은 테두리, 눌림 피드백과 키보드 초점 표시다. 도구는 42–44px에 최근접 픽셀 표시/object-fit:contain으로 원본 전체를 보여준다. 비도구 기호는 기존 28–30px 선 그림이다. 버튼 위치/클릭 영역은 유지한다.
- 일반 화면: 조이스틱 138px/손잡이 50px/행동 82px. 430px 이하: 132/48/78px. 360px 이하: 120/44/74px. 하단 메뉴는 44px이다. 안전 영역 여백을 유지한다.
- 기존 조이스틱 범위/데드존은 실제 패드 크기 비율(.28/.10)을 유지하고 손잡이는 테두리를 제외한 실제 내부 크기의 가운데 맞춘다. 포인터 캡처, 바깥에서 손 놓기, 취소/화면 전환·blur 정지와 키보드 이동을 유지한다.
- 기본 행동은 기존처럼 pointerdown에 즉시 실행한다. 버튼 누름으로 창이 열린 뒤 같은 터치의 후속 click이 새 창의 ‘나가기’에 전달되는 현상을 방지했다. 처음 누른 위치에서 12px 이내/700ms 이내 후속 click만 소비하며, 새로운 pointerdown은 이전 가드를 지우고 키보드 click은 막지 않는다. 일반 상점/메뉴 버튼의 독립 터치는 유지한다.
- 기존 게임 저장·캐릭터/도구·농사 규칙은 변경하지 않는다.

## 상황별 표시

src/interactions.js의 actionButtonPresentation이 실제 대상·현재 도구·농사 단계/낚시 상태에서 아이콘과 안내를 결정한다. actionButtonToolArt는 도끼/낚싯대의 장착 ID로 CHARACTER_TOOL_URLS, 낫은 SICKLE_TOOL_URLS[FARM_SICKLE.id], 검은 SWORD_TOOL_URLS에서 그림을 찾는다. 같은 종류 안에서 장비만 바뀌어도 src를 갱신한다. 캐릭터/이미지 원본·장비/저장 규칙은 수정하지 않는다.

도구 그림과 비도구 SVG 중 하나만 표시한다. HTML img의 hidden 속성과 SVG의 hidden 속성(명시적 setAttribute/removeAttribute)을 각각 사용하며 숨김 CSS도 지정한다. 버튼/자식 노드를 재생성하지 않아 포인터 누름과 후속 click 방지를 유지한다. aria-label도 실제 동작에 맞춰 갱신한다.

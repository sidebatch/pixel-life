# 제작 · 무기 · 던전 동선 · 계단과 회피 공개 배포

2026-10-23 · 공개 배포 준비

## 포함한 변경

- 준의 도구점에서 목재 20개로 휴대용 제작대 제작, 가방의 재료 탭에서 별도 조합창.
- 일반 가죽 30개 → 튼튼한 가죽 1개, 튼튼한 가죽 3개 + 브락 엄니 1개 → 브락의 검.
- 일반 동물 5종과 브락의 전투·가죽/엄니 보상, 재접속에도 유지되는 재등장 대기. 브락 체력 320 / 피해 26 / 준비 1.5초.
- 기본 목검과 브락의 검의 이름·그림, 과거 로컬 `sword.iron` 저장의 보유/내구도 이전, 제작 검 내구도/수리/파손.
- 갈림길 남쪽 진입, 첫 입구까지 북쪽 4칸, 10지역을 남→북 순서로 배치, 지역별 남쪽 진입·남쪽 귀환 계단.
- 계단을 캐릭터 아래에 그리고 상행/하행 높이를 표현하여 캐릭터 가림 해소.
- 공격 예고와 실제 타격 범위를 발 기준 타원으로 통일. 타격 순간 범위 밖 이동은 피해 없이 회피. 사냥 중 장비 휘두르기를 이동으로 취소하되 700ms 공격 간격 유지.

다른 54종은 외형 탐방 상태를 유지한다. 새 마법/원거리 전투·채광·철검은 추가하지 않는다. 일반 동물 5종과 브락은 선제공격 없이 맞은 개체만 반격한다. 양쪽 명중률 60%, 기존 생활 경제·캐릭터 규격·원화·저장 버전 2 유지.

## 배포 기준과 검사

이전 공개 기준은 `f41025b6cb79354f5145030d2172c3b65bca901e`다. 별도 숲 세션 배치 실험 7개 작업 파일/연결 부분은 원본 바이트를 보존하고 커밋에서 제외한다. `src/world.js`에는 브락의 중복 고정 충돌을 제외하는 연결만 추가한다.

큰 전체 소스 복사본을 만들지 않는다. 검증할 Git 트리의 텍스트를 읽기 전용으로 제공하여 전체 검사와 빌드를 실행하고, 원본 작업 파일은 덮어쓰지 않는다. 바이너리 리소스도 Git 트리 해시와 대조한다. `dist/`와 검증 결과는 Git 제외다.

검사와 게시 결과는 완료 후 이 문서에 기록한다. 로컬 결과 경로는 `output/deploy-crafting-dungeons-v2/`이며 수정 전 버그 재현은 `output/dungeon-combat-qa/before-*`를 보존한다.

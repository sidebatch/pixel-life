# 나무 다리·잔교 정비 v1 — 2026-10-10

사용자 승인대로 나무 다리를 기존 게임 그림체에 맞췄다. 같은 프레임 달린 판자를 한 칸마다 반복하던 모습을 없애고 연결된 널판 바닥·낮은 가장자리 보·간격을 둔 짧은 지지 기둥으로 바꿨다.

## 적용/보존

- 마을 연못 5칸, 산악 호수 잔교 6칸, 폭포 계곡 가로 다리 9칸, 늪 잔교 7칸, 항구 세로/가로 잔교 합계 21칸, 총 48칸의 기존 위치/이동 폭/물/충돌/낚시 지점을 그대로 쓴다.
- 널판 방향은 다리 연결 방향에 맞춘다. 꺾임/분기에서 서로 연결된 칸 사이에는 가장자리 보를 그리지 않는다. 실제 물과 접한 바깥면에만 보를 그리고 땅으로 이어지는 입구는 연다. 기둥은 끝/모서리와 직선 3칸 간격에만, 겹친 꼭짓점은 한 번만 표시한다.
- 연결 모양/기둥은 맵 정의별로 캐시하고 화면 밖은 그리지 않는다. 바닥/보/기둥 모두 캐릭터 이전 지면 레이어여서 통행·낚시 동작을 가리지 않는 낮은 구조다. 새 충돌 물체/난간 잠금/다리 확장/수리 기능을 추가한 것이 아니다.
- 어선 선수 갑판은 별도 원화를 사용하므로 이 다리 타일을 그리지 않는다. 캐릭터/도구/주민/배 원화, 맵 연결, 출현/가격/XP/도감/저장 버전과 키는 변경하지 않았다.

## 원화와 재현

imagegen 스킬/내장 이미지 생성 도구로 기존 파란 지붕 집과 늪 원화의 그림체를 참고해 널판 재질·짧은 기둥을 각각 생성했다. 기존 집/늪 이미지는 참조일 뿐 수정하지 않았다.

- 게임 사용: `assets/world/bridge-deck-v1.png` (64×64, 논리 32px 재질), `assets/world/bridge-post-v1.png` (24×32, 실제 표시 12×18).
- 원본/정확한 프롬프트/패킹 명세: `assets/world/source/wood-bridges-v1/`의 `deck.png`, `post.png`, `PROMPTS.md`, `manifest.json`.
- `node scripts/pack-wood-bridges.mjs`는 최근접 축소/확대와 기둥의 투명 경계 자르기/종횡비 유지 배치만 한다. 원화는 코드로 다시 칠하지 않는다. 기존 `assets/world/bridge.png`는 비교/복구용으로 보존하되 런타임에서는 새 파일을 읽는다.
- 가장자리 보는 새 재질에 맞춘 낮은 대비 게임 렌더링 보조 선이며 원본 PNG의 수정이나 새 물리 구조가 아니다.

## 사용자 결정

- 섬·바위·부표 등 바다 배경이 겹치지 않게 한다.
- 부표는 가까운 바다에서만 사용하고 무엇인지 알아볼 수 있게 바꾼다.
- 얕은 바다 승선권은 **300 → 2,000코인**으로 변경한다. 중간 바다 900/심해 2,400/빙하 4,800코인은 이번 변경 대상이 아니다.
- ‘쉽게 내리지 못하게’는 높은 승선 비용으로 남은 운항 시간을 아끼게 하자는 의미다. 사용자가 명시적으로 정정했으므로 조기 귀항 잠금/대기 시간/추가 확인/추가 요금을 넣지 않는다. 기존 조기 귀항·미환불·표시 중 10분 운항 규칙을 유지한다.

## 구현

`src/voyage-scenes.js`에서 좌우 배경 통로에 이전 오브젝트의 전체 그림 높이와 20px 여백을 예약한다. 다음 오브젝트는 그 위에서 화면 밖으로 진입한다. 모든 배경의 이동 속도를 공유하므로 배치 후에도 겹치지 않으며, far/mid 레이어·장면 경계에도 같은 규칙을 적용한다. 화면 안의 그림을 갑자기 지우거나 숨기지 않는다. 2px 이동 격자와 기존 배 바깥 배치 규칙도 유지한다.

재접속 시 여행 시드로 이전 장면의 예약 순서까지 재구성한다. 이미 퇴장한 그림은 작은 캔버스로 해제하고 현재/다음 장면 메타데이터와 살아 있는 그림만 보관한다. 매 프레임 새 그림을 만들지 않는다. 여행 저장 형식·낚시·물고기 선택·충돌·보행은 바꾸지 않는다.

부표는 기존 픽셀 그리기 방식으로 넓은 둥근 받침, 빨강/흰색의 위로 좁아지는 몸통, 작은 표지/깃발을 그린다. 얕은 바다 해당 장면에서 1~2개만 배치한다(기존 3~5개). 중간 바다·심해·빙하의 배경 목록에는 없으며 생성 경로에도 얕은 바다 제한을 둔다.

승선권 가격은 `src/data/voyage-data.js`의 얕은 바다 항목만 변경한다. 매표소 표시/1장·5장 결제/잔액 부족 검사는 기존 동일 데이터에서 가격을 읽는다. 기존 구매한 승선권/진행 중 여행을 소급 차감하지 않는다.

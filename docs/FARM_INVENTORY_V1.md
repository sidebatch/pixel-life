# 농장 교환권·소품 가방 표시

2026-10-15 로컬 변경, 공개 배포 전. 하단 도구 바·보유 씨앗 목록·숲 이름 정정을 포함한 HTML 20,545,854 bytes/PWA `439a1f39c178`. 전체 검사 52 scripts/142 UI IDs/452 assets/74 fish 통과.

교환권과 소품 소유권은 기존 `progression.farmOrders`에 저장됐지만 가방에는 표시되지 않았다. 설치 메뉴는 밭 설명창 → 농장 꾸미기에만 있어 교환 후 설치 경로를 찾기 어려웠다.

## 이용 흐름

- 가방에 다섯 번째 **농장** 탭을 추가한다. 농장 교환권 잔액(0장 포함), 획득/교환 안내, 보유한 소품 8종의 실제 그림·이름·배치 위치·보관/설치 상태를 표시한다.
- 농장에서 해당 카드의 **설치하기**를 누르면 기존 지정 자리에 설치한다. **회수하기**를 누르면 보유 상태로 돌아가 다시 설치할 수 있다. 소모/재구매는 없다.
- 농장 밖에서는 설치/회수를 비활성화하고 ‘농장으로 이동한 뒤 가방 → 농장’ 경로를 안내한다. 교환은 기존 하루의 농사 상점에서 진행한다.
- 교환 완료 문구와 상점 안내에도 가방 → 농장 경로를 표시한다. 기존 밭 설명창 → 농장 꾸미기 경로도 유지한다.
- 5개 분류 탭과 설치/회수 버튼은 최소 44px 터치 크기를 유지한다. 긴 소품 목록은 가방 내부에서 스크롤한다.

## 저장·동작

새로운 아이템 사본/화폐/저장 버전을 만들지 않는다. 잔액은 `tickets`, 보유는 `ownedDecorationIds`, 설치는 `placedDecorationIds`를 직접 조회한다. 따라서 이전에 교환한 소품도 같은 탭에서 표시된다.

기존 `setFarmDecorationPlaced`와 `commitLifeChange`를 사용한다. 플레이어가 설치 자리에 있으면 설치를 막고, 저장 실패 시 소유/설치 상태와 충돌을 복원한다. 설치/회수만으로 교환권·코인·일반 인벤토리를 변경하지 않는다. 가방에서 실행할 때 숨겨진 상점 화면을 갱신하지 않는다. 상점 경로의 기존 갱신은 유지한다.

# 벌목 진행·밸런스 표

기준: 사용자 제공 「Pixel Life 벌목 시스템 최종 설계 문서 v1.3」. 아래 **수치는 첫 플레이 테스트용 임시 밸런스**이며, 구조(도끼 단계로 나무 제한, 완료 보상, 저장, 상점 강화)는 구현 기준이다. 실제 값의 단일 기준은 `src/data/life-content-data.js`다.

철 도끼 재료는 기본 도끼로 얻고, 강철 도끼 재료는 철 도끼로 얻는다. 따라서 상위 등급 나무를 먼저 베어야 강화되는 순환 잠금은 없다. 도끼 단계는 벌목 레벨과 별도이며, 벌목 레벨이 높아도 미장착 상위 도끼를 대신하지 않는다. 일반 통나무(옛 저장 데이터)는 계속 개당 12코인에 팔고 밭 확장에도 사용하지만 도끼 재료에는 포함하지 않는다.

숲 1-2는 남쪽 입구에서 북쪽으로 진행한다. 중급 나무는 입구 쪽부터 보이고, 상급 나무는 북쪽 절반(`y≤23`)에서만 생성한다.

완전히 벴을 때 해당 나무 통나무 1~3개와 종별 XP를 한 번만 준다. 중간 타격은 보상이 없고 남은 HP를 저장한다. 벤 나무는 현실 시간 5분 후 재생하며 게임을 꺼도 시간이 흐른다. 상점의 `도끼` 탭에서만 다음 도끼·재료·코인 정보를 보여준다. 장착 도끼는 캐릭터와 가방 장비 탭에 반영된다. 4방향 각각 준비→휘두름 2단계로 렌더링하고, 타격 프레임에서 피해·체력바·나무 조각·효과음을 함께 적용한다. 현재 도끼는 3개의 원본 PNG를 방향과 프레임에 따라 합성한다. 별도의 8장 스프라이트 시트 제작은 미진행이다.

다음 플레이 테스트에서 확인할 값: 나무 1~3개 드롭의 확률 분포, 5분 재생 시간, 도끼 비용과 단계별 소요 시간, 종별 XP·판매가, 벌목 모션의 손·도끼 결합감. 벌목 Lv.1–20 XP 곡선은 기존 공통 스킬/낚시 저장 호환을 위해 유지했고, Lv.21 이후는 임시 수치다.

# 휴대용 제작대 · 브락 전투 · 사냥 보상 v1

2026-10-22 · 로컬 구현 / 공개 미배포

최신 무기·던전 동선은 [목검·브락의 검 / 남쪽 진입 v2](WEAPONS_DUNGEON_ROUTE_V2.md)를 따른다.

## 이용 흐름

1. 마을 **준의 도구점 → 제작**에서 목재 20개로 휴대용 제작대를 만든다. 목재 종류는 섞어 쓸 수 있고 코인은 들지 않는다. 제작대는 하나만 소유하고 영구 사용한다.
2. **가방 → 재료 → 제작대 사용**으로 별도 조합창을 연다. 바닥 설치는 없다. 전투·공격·낚시 중에는 사용할 수 없다.
3. 재료 가공 / 장비 분류에서 결과물을 선택한다. 이미지, 설명, 보유 / 필요 재료와 수량 `− / + / 최대`를 표시한다. 부족한 제작법도 보이지만 제작 버튼은 비활성화한다.
4. 일반 가죽 30개 → 튼튼한 가죽 1개. 튼튼한 가죽 3개 + 브락 엄니 1개 → 브락의 검 1개. 성공률 100%, 대기·코인 수수료 없음. 단단한 가죽은 후속 장비용으로 보류한다.
5. 가공 재료는 가방의 재료, 브락의 검은 장비에 지급한다. 검은 자동 장착하지 않는다. 제작대는 조합 시 소모되지 않는다.

## 브락과 사냥 보상

기존 일반 5종 10마리를 유지하고 브락 1마리를 실제 전투로 연결했다. 다른 새 54종은 계속 외형 탐방 단계다. 브락의 기존 고정 그림·충돌을 전투 개체로 대체하여 중복 표시하지 않고, 처치한 자리를 지나갈 수 있다.

- 브락: 체력 320, 명중 피해 26, 준비 1.5초, 타격 후 다음 준비까지 최소 2.5초.
- 실제 맞은 개체만 반격하며 양쪽 명중률 60% 유지. 접근 → 직접 공격 → 이동 회피. 준비 때 지정한 위치에서 벗어나면 공격을 피한다.
- 네 방향 별도 돌진 그림, 움츠림·전진·복귀, 피격 점멸·피해 숫자, 왕관·후광·체력, 휘두름·타격 효과음. 동작 줄이기에서는 큰 위치/크기 변화를 끈다.

| 대상 | 처치당 확정 지급 |
| --- | --- |
| 멧돼지 | 일반 가죽 3개 |
| 사슴 | 일반 가죽 2개 |
| 여우 | 일반 가죽 1개 |
| 늑대 | 일반 가죽 4개 |
| 곰 | 일반 가죽 6개 |
| 브락 | 일반 가죽 10개 + 브락 엄니 1개 |

가방으로 직접 지급하고 획득 수량을 알린다. 코인·수렵 XP는 별도로 지급하지 않는다. 준의 **판매**에서 목재와 사냥 재료를 함께 판매한다. 일반 가죽 3코인, 튼튼한 가죽 90코인, 엄니 160코인으로 가죽 조합 전후 판매 가치는 같다.

일반 동물은 처치 후 실제 시간 60초, 브락은 5분 뒤 다시 등장할 수 있다. 처치 대기를 저장하여 지역 왕복·재접속으로 생략하지 못한다. 대기 종료 후에도 플레이어가 원래 자리의 3타일 이내면 등장을 미룬다. 체력 소진으로 마을에 돌아와도 전리품은 보존한다.

## 브락의 검

| 항목 | 적용 |
| --- | --- |
| 명중 피해 | 목검 16 / 브락의 검 24 |
| 동작·명중률 | 공통 0.7초 / 60% |
| 내구도 | 목검 무제한 / 브락의 검 200 |
| 마모 | 실제 명중이 저장된 공격만 1. 허공·빗나감·벽·저장 실패 제외 |
| 파손 | 마지막 공격 피해 적용 후 빈손으로 변경. 가방에서 목검을 선택해 계속 사냥 가능 |
| 수리 | 준의 기존 **수리**에 도끼와 함께 표시. 부족 내구도 / 2 올림, 전체 수리 100코인 |
| 표시 | 장비 카드·상세·하단 검 선택 칸에 내구도 표시 |

브락의 검 그림도 기존 96px 도구 규격과 손잡이 회전축을 따른다. 목검과 브락의 검의 새 그림은 각 재료에 맞추고, 기존 캐릭터 규격·손 회전축·공격 각도는 유지한다.

## 저장과 검증

기존 저장 이름/버전 2 유지. 새 재료와 제작대, 검 보유·내구도, `progression.hunting.defeatedUntil`을 추가한다. 오래된 저장에는 제작대를 무료 지급하지 않는다.

재료 소모·결과 지급·검 마모·처치 보상을 저장과 하나의 거래로 처리한다. 저장 실패 시 재료·장비·코인·대기 기록을 되돌리고 전투 피해도 적용하지 않는다. 중복 장비 제작·잘못된 수량·보유 수량 상한을 재검사한다.

- `scripts/qa-crafting.mjs`: 29/30/95 가죽, 최대/잘못된 수량, 중복 제작, 6종 보상, 저장 실패 복구, 파손·수리·목검, 대기 복원, 그림 규격.
- `scripts/qa-crafting-browser.mjs`: 320/393/1280px 실제 상점·가방·제작·장착·수리 조작, 브락 선공 금지/반격/예고/회피/피격/처치, 재료·내구도·재접속·Escape.
- 던전 QA는 브락 고정 장애물 대신 전투 충돌을 검사한다. 기존 사냥 QA도 새 가죽 지급과 실제 시간 재등장 기준을 반영했다.
- 스크린샷·보고서: `output/crafting-qa/`. 첫 브락의 검까지의 실전 소요 시간은 후속 플레이 조정 대상이며 기획의 10~15분을 실측으로 주장하지 않는다.

검증 완료: 전체 검사 60 scripts / 164 UI IDs / 532 runtime assets / 74 fish, 독립 조합·보상 검사, 빌드 검증. 실제 소스와 단일 HTML 빌드의 320/393/1280px 조합·전투·저장 검사를 통과했다. 기존 5종 사냥, 10지역 탐방, 상점 서비스·거래, 목검 회귀도 통과했다. 브락의 검 남녀 × 사방향 × 준비/타격 16자세의 공통 손 회전축·실제 그림을 확인했다. 실제 모바일 기기에서의 장시간 플레이나 첫 브락의 검 소요 시간은 아직 실측하지 않았다.

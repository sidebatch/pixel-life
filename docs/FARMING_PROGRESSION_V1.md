# 농사 레벨 v1

2026-10-13 후속 회의에서 농사 레벨과 보유 밭 규모를 다음 랜덤 주문의 작물 수/후보에 연결했다. 새 농장 주문·교환권·꾸미기는 [FARM_ORDERS_V1.md](FARM_ORDERS_V1.md)대로 로컬 구현했으며 수확 XP 곡선/값은 유지한다. 새 기능은 아직 공개 배포 전이다.

2026-10-13 사용자가 ‘농사 레벨도 이제 만들어주세요’로 구현을 요청했고 후속 ‘배포해주세요. 실력이 늘었어요는 없애주세요’로 공개 배포를 요청했다. 농사 레벨·14종 확장/가격·기본 알림 문구 제거를 공개 배포 완료했다. 게임 커밋 1c01b22 / PWA 0ffa41864680이며 성공 배포와 공개 검증은 DEPLOYMENT.md에 기록한다.

## 동작

- 농사(farming)는 별도 Lv.1–100이며 낚시/벌목 XP를 변경하지 않는다. Lv.100 이후 숙련도와 숙련도 XP를 누적한다.
- 기본 곡선은 생활 스킬 v2와 같다. Lv.1→2는 72 XP, Lv.100까지 누적 187,230 XP다. 숙련도 요구량은 4,000 + 현재 숙련도 × 250 XP다.
- 기본 낫으로 성장 완료된 인접 밭 한 칸을 실제로 수확하고 저장이 성공할 때 경험치를 한 번 지급한다.
- XP는 수확물 개수·가격과 독립적이다. 작물의 설정 성장시간 1분당 12 XP로 계산한다. 작물을 성장 완료 이후 더 오래 두어도 추가 경험치는 없다.
- 씨앗/부지 구매, 씨앗 심기, 성장 완료 자체, 수확물 판매는 XP를 지급하지 않는다. 빈 밭/성장 중/거리 밖/잘못된 도구/중복 수확/저장 실패도 지급하지 않는다.
- 이전 저장에 농사 진행이 없으면 Lv.1 / 0 XP부터 시작한다. 재고에서 과거 수확 XP를 추측해 소급 지급하지 않는다.
- 현재 작물 14종/씨앗/수확물·밭 가격·재배 가능 조건·낫/그림은 그대로다. 기존 작물에 레벨 제한을 새로 걸지 않는다.

## 화면

밭 관리 창 상단, 엘리의 씨앗 구매/작물 판매 목록 상단에 기존 생활 스킬 카드와 같은 농사 레벨·XP·진행률 바를 표시한다. 수확 시 공통 +XP 알림/바 채움/레벨업 소리·알림을 사용한다. 기존 심기 후 창 닫기와 짧은 수확물 알림도 유지한다.

여러 레벨이 한 번에 오르는 경우 공통 애니메이션은 최대 세 단계만 재생하되 마지막 알림은 최종 도달 레벨을 표시한다. 첫 고추 수확 480 XP는 정확히 Lv.6이며 알림도 Lv.6으로 표시한다. 농사뿐 아니라 같은 표시기를 쓰는 스킬에도 정확한 마지막 레벨을 표시한다.

## 저장

키 pixel-life.save.v2 / 버전 2는 유지한다. progression.farming에 xpCurveVersion:2, level, xp, totalXp, mastery, masteryXp를 저장한다. 기존 공통 정규화로 로드한다.

수확 아이템·밭 초기화·농사 XP는 commitLifeChange 안에서 함께 변경해 한 번 저장한다. 저장 실패 시 beforeFarming을 포함해 모두 복원하고 XP/레벨업 알림을 표시하지 않는다. 낚시·벌목·장비/내구도·도감·코인·밭 소유·심은 작물/시간은 기존 저장을 보존한다.

## 성장 계산의 가정

scripts/simulate-farming-growth.mjs에서 14종 × 4/16칸 × 즉시/15/30/60분 재방문 = 112가지 설정으로 1/6/24시간 진행률과 Lv.10/20/100 도달 시간을 계산했다. 씨앗 자본이 충분하고 모든 밭을 동시에 경작하며 이동/심기/낫 동작과 부지 확장 비용은 제외한다. 보고서는 output/farming-progression-v1/growth.json이다.

즉시 재심기 기준 각 작물의 밭당 XP/분은 12로 같다. 초기 4칸은 최대 48 XP/분, 16칸은 192 XP/분이다. Lv.100까지 순수 이론 재배 시간은 약 65.01시간/16.25시간이며 실제 시간은 조작·방문 간격·확장·씨앗 자본에 따라 길어진다. 긴 작물의 XP를 크게 하여 당근 반복만으로 성장 효율이 더 높아지지 않게 했다. 성장 완료 후 자동 재수확/자동 재심기는 없다.

농사 레벨은 현재 독립 성장 기록이다. 상위 낫·레벨별 새 작물·도감/첫 수확 보상·요리는 별도 후속 설계이며 사용자 요청 없이 재배 제한을 추가하지 않는다.

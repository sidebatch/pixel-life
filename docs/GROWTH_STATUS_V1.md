# 성장 현황 창 v1

2026-10-16 로컬 구현·검증. **아직 공개 배포 전입니다.**

여행 메뉴 → 성장 현황에서 현재 진행 가능한 낚시·벌목·농사를 한 번에 확인합니다. 별도 종합 레벨이나 새로운 성장 수치를 만들지 않고 기존 `GAME_STATE.progression`의 실제 값을 읽습니다. 아직 플레이할 수 없는 채집·채광·요리·수렵은 표시하지 않습니다.

상단 왼쪽 지역 표시 아래에는 28px 높이의 작은 반투명 바를 배치했습니다. 낚시·벌목·농사 아이콘과 레벨만 보여 주며 누르면 상세 성장 현황을 엽니다. 상세 창을 닫아도 레벨이 바뀌면 즉시 갱신하며, Space/Enter로도 열 수 있습니다. 닫으면 진입한 버튼으로 포커스를 돌려줍니다. 항해 시간·경험치/아이템 알림·디버그 패널은 작은 바 아래로 배치해 겹치지 않게 했습니다.

각 항목은 기존 게임 PNG 아이콘, 현재 레벨, 경험치 바·현재/필요 XP·진행률, 다음 레벨까지 남은 XP, 누적 XP를 보여 줍니다. Lv.100에서는 숙련도와 다음 숙련도까지 남은 XP로 표시합니다. 열린 상태에서 수치가 바뀌면 갱신하며, 닫았다 다시 열거나 재접속해도 저장된 실제 진행 상태를 읽습니다.

창은 모바일·PC 화면 중앙에 표시합니다. 화면 높이가 작으면 내용만 스크롤하며 닫기 버튼은 유지합니다. 닫기·배경 터치·Escape/X·브라우저/휴대폰 뒤로가기를 지원합니다. 키보드 Tab 포커스는 창 안에 유지하고, 열려 있을 때 이동과 도구 단축키 입력을 막습니다. 낚시 중이나 다른 주요 창이 열린 상태에서는 중복 진입하지 않습니다.

현황 조회는 저장·보상·레벨·재화·인벤토리를 변경하지 않습니다. 저장 버전 2와 경험치 곡선/장비/가격을 유지합니다. 공통 경험치 카드 그림을 재사용하지만 `data-growth-skill`로 분리해 경험치 알림이 애니메이션 중 보여 주는 과거/중간 값의 영향을 받지 않도록 했습니다. 현재 값이 바뀔 때만 다시 그리며 스크롤 위치를 유지합니다.

여행 메뉴는 가방·물고기 도감·나무 도감·성장 현황의 2×2 배열로 정리했습니다. 320px 화면에서 지역 표시의 고정 최소 폭 때문에 메뉴 버튼을 누르면 화면이 가로로 밀리던 문제도 함께 보완했습니다. 지역 표시가 가용 폭에 맞게 줄어들고 메뉴 버튼은 화면 안에 유지됩니다.

추가 기술을 실제 플레이할 수 있게 만들면 `src/growth-status.js`의 `GROWTH_STATUS_SKILLS`에 등록합니다. 기존 기술 정보·저장 진행 상태·아이콘이 갖춰져 있어야 합니다. 공통 카드 렌더링과 성장식은 기존 시스템을 사용합니다.

- UI: `src/growth-status.js`, `styles/growth-status.css`, `index.html`
- 메뉴/뒤로가기/키보드: `src/interactions.js`
- 상태 갱신: `src/main.js`
- 검증: `scripts/qa-growth-status-browser.mjs` / `qa:growth:status-browser`
- 증거: `output/growth-status-qa/`

로컬 검증은 320/393px 모바일과 PC 1280px에서 실제 메뉴 클릭, 세 기술만 표시, 0 XP/레벨 경계/일반 진행률/Lv.100 숙련도, 실시간 갱신·XP 애니메이션 분리, 조회 시 저장 호출 없음·진행 상태 불변, 배경/키보드/뒤로·앞으로가기/재접속을 확인합니다. 기존 가방과 두 도감의 메뉴 진입·복귀도 확인합니다. 작은 바의 위치·28px 높이·아이콘 로딩·닫힌 상태의 레벨 갱신·직접/키보드 진입·포커스 복귀·항해 시간 및 알림 간격도 같은 세 화면에서 검증합니다. 전체 검사 결과는 53 스크립트/150 UI ID/481 에셋/74 물고기이며 신규 UI 외 성장·장비·가격·보상을 변경하지 않습니다.

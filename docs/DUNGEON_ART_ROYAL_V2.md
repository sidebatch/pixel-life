# 던전 몬스터 교체·우두머리 표시 v2

작성: 2026-10-22 · 상태: 로컬 적용, 공개 배포 전

기존 픽셀 그림 스타일을 유지하면서 불쾌감을 주던 두 몬스터를 완전히 교체하고, 우두머리를 일반 개체와 구분했다. 총 10지역·60종·110마리와 탐방 경로는 유지한다.

## 교체한 네 개체

| 이전 | 현재 | 구분 |
| --- | --- | --- |
| 리치 / Leech | 왜가리 / Heron (`heron`) | 습지의 푸른 회색 날개·밝은 가슴·노란 부리와 다리. 거머리와 원형 이빨 입 제거 |
| 샌드웜 / Sand Worm | 아르마딜로 / Armadillo (`armadillo`) | 협곡의 붉은 모래빛 둥근 등갑·짧은 발·닫힌 입. 벌레 몸과 커다란 이빨 입 제거 |

| 보른 | 보른 | 직립 서리 거인, 푸른 피부·얼음 갑각, 왕관형 얼음 뿔, 긴 은빛 수염. 웅크린 흰 예티와 체형을 구분 |

새 일반 개체의 영어 이름과 후속 물리 공격 기획도 [구성안 개정 6](DUNGEON_REGIONS_MONSTERS_V1.md)에 반영했다. 미리보기 몬스터의 상태나 전리품을 저장하지 않으므로 두 표시 ID 변경에 따른 저장 데이터 변환은 필요하지 않다. 기존 생활·장비·보상 데이터는 건드리지 않는다.

## 모든 우두머리의 공통 표시

우두머리 10종에 지역별 색의 은은한 후광, 바닥의 이중 빛고리, 천천히 올라가는 작은 빛 조각, 이름 옆 금색 픽셀 왕관을 표시한다. 왕관은 시스템 이모지나 글꼴에 의존하지 않고 게임 캔버스의 고정 픽셀 패턴을 사용한다.

| 우두머리 | 빛 색 |
| --- | --- |
| 브락 | 황금빛 |
| 토르가 | 연두빛 |
| 루고 | 녹색 |
| 그룬 | 구리빛 |
| 모그라 | 청록빛 |
| 바스크 | 주황빛 |
| 보른 | 얼음 하늘빛 |
| 카르덴 | 옅은 보랏빛 |
| 발록 | 밝은 금빛 |
| 오르칸 | 수정 보랏빛 |

우두머리 표시 크기는 168px, 새 일반 개체는 104px이다. 원본 셀과 발 기준은 그대로다. 충돌은 기존 발 위치의 한 칸을 유지한다. 동작 줄이기 설정에서는 호흡·후광 변화·빛 조각의 이동을 멈추며 왕관과 고리는 계속 보인다. 후광은 캔버스 그라데이션 하나와 소수의 작은 픽셀로 그리며 흐림 필터를 사용하지 않는다.

이 효과는 우두머리 식별 연출이다. 마법 공격·피해·드롭·처치 처리나 새로운 전투 규칙을 추가하지 않는다. 기존 일반 동물 5종의 전투는 유지하고 나머지는 계속 외형 미리보기 단계다.

## 그림과 제작 기록

내장 `image_gen.imagegen`으로 네 개체를 각각 생성했다. [전체 프롬프트·입력 그림·원본 위치](art/dungeon-prompts-v2.json)에 기록했다. 원본 생성 이미지는 원래 저장 위치에 보존한다.

- `assets/dungeons/brak-v2.png`: 네 방향, 192×192, 96px 셀 / 발 90px.
- `assets/dungeons/swamp-v2.png`: 왜가리 셀만 교체, 384×256.
- `assets/dungeons/redrock-v2.png`: 아르마딜로 셀만 교체, 384×256.
- `assets/dungeons/frost-v2.png`: 보른 셀만 교체, 384×256.

`scripts/pack-dungeon-assets-v2.mjs`는 새 그림을 자르고 최근접 축소하여 해당 셀에만 넣는다. 브락은 연결 영역 단위로 네 방향을 추출하여 칸 경계를 조금 넘은 엄니도 자르지 않는다. 세 지역 아틀라스의 나머지 15개 셀은 이전 RGBA와 픽셀 단위로 동일하다. v1 파일은 비교용으로 보존하고 실제 게임의 네 참조만 v2로 바꿨다.

## 확인 결과

- `node scripts/qa-dungeon-preview.mjs`: 두 이전 개체 ID 제거, 새 두 개체 반영, 다른 15개 셀 원본 유지, 60개 이름·그림 여백·발 기준, 11개 관련 맵의 출입·접근·충돌 확인.
- 같은 검사에서 일반 개체에 후광이 없고, 우두머리 10종 모두 지정색을 사용하며, 동작 줄이기 상태가 시간에 따라 바뀌지 않고 게임 상태도 변하지 않는 것을 확인한다.
- 브라우저 탐방 검사: 320px(동작 줄이기), 393px, 1280px. 우두머리 효과가 실제 캔버스에 그려지는 것을 관찰하고 10지역 출입·귀환, 저장 재접속과 경제 유지도 확인한다.
- 기존 사냥 브라우저 회귀 검사로 5종 중립·반격·회피·피해·처치·재등장·마을 복귀를 확인한다.
- 배포용 독립 HTML도 같은 탐방 검사로 확인한다. 빌드: 25,962,024 bytes, PWA `1a7a20f7e755`.
- 결과: `output/dungeon-art-v2-qa/`. `all-10-bosses.png`는 실제 게임 캔버스에서 잘라 만든 우두머리 모음, `all-60-monsters.png`는 교체 반영 후 전체 그림이다. `standalone/`은 배포용 HTML 검증 결과다.

공개 사이트로 게시하지 않은 로컬 수정이다. 후속 전투·드롭·조합의 구현 상태는 [외형·탐방 v1](DUNGEON_VISUAL_PREVIEW_V1.md)을 함께 확인한다.

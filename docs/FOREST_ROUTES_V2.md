# 숲 연결 정정·나무 팻말 v2 — 2026-10-09

## 사용자 정정이 우선

사용자는 기존 숲 1-1~1-5와 거목 숲의 혼합 수종을 그대로 유지하고 나머지 일반 상위 숲을 1-1에서 나누도록 확정했다. 이전 v1의 1-2/1-3/1-4 개별 분기는 잘못 이해한 연결이며 현재 기준이 아니다.

| 출발 | 연결 방향·순서 |
| --- | --- |
| 마을 남쪽 | 숲 1-1 |
| 숲 1-1 남쪽 | 숲 1-2 → 남쪽 1-3 → 남쪽 1-4 → 남쪽 1-5 → 남쪽 거목 숲 |
| 숲 1-1 북서쪽 | 붉은 거목림(나무 5단계) |
| 숲 1-1 서쪽 아래 | 은빛 경목림(나무 6단계) |
| 숲 1-1 동쪽 | 검은 경목림(나무 7단계) |
| 마을 북쪽 | 고대 숲 → 정령 숲 → 태초 숲 유지 |
| 숲 1-1 서쪽 위 | 기존 산악 호수 유지 |

숲 1-1에는 1단계, 1-2~1-5에는 1·2·3단계, 거목 숲에는 1·4단계가 있던 구성을 그대로 유지한다. 맵 이름/번호와 필요한 도끼 단계는 서로 다르며 이번에 수종을 분리하거나 맵 번호를 도끼 단계로 다시 붙이지 않았다.

붉은/은빛/검은 상위 숲은 현재 각각 한 맵이다. 이후 같은 구역의 다음 맵을 추가한다면 붉은 구역은 북쪽, 은빛 구역은 서쪽, 검은 구역은 동쪽으로 확장한다. 현재 없는 추가 맵이나 준비 중 입구를 임의 생성하지 않았다. 판타지 숲을 마을 북쪽에 둔 앞선 결정은 유지한다.

## 실제 입구

첫 숲의 중앙 북쪽 `(25,1)`은 마을 귀환, 북서쪽 `(14,1)`은 붉은 거목림, 서쪽 아래 `(1,36)`은 은빛 경목림, 동쪽 `(62,40)`은 검은 경목림, 남쪽 `(25,46)`은 1-2다. 기존 산악 호수 `(1,24)`는 유지한다.

1-2~1-5와 거목 숲은 북쪽으로 직전 맵에 돌아오고 남쪽으로 다음 맵에 간다. 거목 숲 이후 붉은 거목림으로 이어지던 연결은 제거했다. 붉은 거목림은 남쪽으로 1-1의 북서쪽에, 은빛 경목림은 동쪽으로 1-1 서쪽에, 검은 경목림은 서쪽으로 1-1 동쪽에 돌아온다. 도착은 대응 귀환 출구에서 2타일 안쪽이며 즉시 귀환 루프가 없다.

## 화면 안내 대신 길옆 팻말

사용자 요청대로 떠 있는 초록 목적지 배지와 마을/숲 바닥의 노란 출구 표시는 제거했다. 나무 팻말 27개를 마을·12숲의 길옆에 고정 배치한다. 화면 위치 보정/플레이어 따라오기/접근 시 갑자기 나타나는 표시가 아니라 실제 월드 좌표의 오브젝트다.

- 하나의 기둥 타일만 이동을 막는다. 길·물·기존 나무·문 앞·도착점·시작점·기존 고정물 위에는 배치하지 않는다.
- 팻말 그림은 기존 건물/표지판과 맞춘 픽셀 원화이고, 나무/캐릭터와 같은 깊이 정렬·낮밤/날씨 처리를 받는다. 나무나 건물 그림과 겹치지 않는 길옆 자리부터 고른다.
- 방향과 목적지를 판자 위에 직접 그린다. 가까이서 `읽기`로 전체 목적지를 확인할 수 있으며 읽기가 코인/재료/XP/도감/저장을 변경하지 않는다.
- 모든 길/출구/낚시 지점과 읽기 접근이 계속 가능하다. 기존 저장 위치가 새 기둥 타일일 경우 기존 안전 시작 위치 규칙으로 복원하며 진행 기록은 유지한다.
- imagegen 스킬과 내장 이미지 생성 도구로 기존 팻말/파란 지붕 집을 그림체 참고로 제작했다. 기존 이미지/캐릭터/리그는 교체하지 않았다.

# 벌목 1~10단계 진행·내구도 시뮬레이션

기준일: 2026-10-05. 실제 수치의 단일 기준은 `src/data/life-content-data.js`이며, `node scripts/simulate-forestry-balance.mjs`가 그 데이터를 직접 읽는다. 시뮬레이터는 저장을 변경하지 않는다.

## 계산 기준

- 새 저장, 시작 코인 0, 기본 도끼부터 태초의 도끼 구매까지 계산한다.
- 목재 드롭은 `0/1/2/3개` 균등 확률이며 평균 1.5개다. 제작 재료는 보관하고 초과분만 판매한다.
- 부족한 코인은 현재 접근 가능한 나무 중 **수리비를 뺀 시간당 순수익**이 가장 높은 수종으로 충당한다.
- 타격은 700ms, 나무 한 그루마다 이동·선택 2초를 더한다. 수리하러 마을을 왕복하는 시간, 나무 재생 대기, 맵의 동시 나무 수 제한은 아직 제외한다.
- 기본 도끼는 무한 내구도다. 유료 도끼는 실제 타격마다 나무 단계만큼 감소하고, 0이 된 뒤 다음 타격이 필요할 때 전체 수리한다.
- 벌목 XP는 수종 기준값의 5%를 반올림하며 최소 1이다. 인상된 수리비 때문에 늘어난 코인 파밍에서도 최종 도끼보다 Lv.100이 먼저 되지 않게 조정했으며, 공통 생활 스킬 요구량과 기존 저장 누적 XP는 바꾸지 않는다.

## 역주행 방지

수리비를 포함하면 고단계 나무의 타격당 내구도 소모가 커지므로 판매가도 함께 검토해야 한다. 8/9/10단계 목재 판매가는 각각 `285/340/400`코인으로 조정했다. 나무당 이동·선택 2초와 평균 1.5개 드롭 기준으로 모든 도끼 단계에서 새로 열린 나무가 양의 순수익을 내며, 접근 가능한 이전 단계 나무보다 시간당 순수익이 높다. 이 조건은 `scripts/check.mjs`와 시뮬레이터가 회귀 검사한다.

## 다음 확인

1. Android에서 실제 나무 이동·선택 시간과 깊은 숲에서 마을 수리까지의 왕복 시간을 잰다.
2. 26~36그루마다 파손되는 주기가 먼 숲에서 지나치게 잦으면 수리비가 아니라 최대 내구도를 먼저 늘린다.
3. 파손 직전 마지막 타격, 완료와 파손이 같은 타격, 저장 실패 복구, 수리 후 수동 재장착을 실기기에서 확인한다.
4. 낮은 도끼로 상위 나무를 베는 소프트 난이도는 아직 계산에 넣지 않는다.

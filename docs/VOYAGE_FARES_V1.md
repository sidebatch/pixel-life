## 확정 가격

| 항로 | 이번 변경 전 | 새 가격 |
| --- | ---: | ---: |
| 얕은 바다 | 2,000 | 2,000 |
| 중간 바다 | 900 | 3,500 |
| 심해 | 2,400 | 5,000 |
| 빙하 해역 | 4,800 | 8,000 |

모두 코인/1장이다. 얕은 바다의 앞선 300→2,000 조정을 기준으로 기본 낚싯대 10분 판매액의 대표값에 대해 약 28~34%를 승선 비용으로 부담하게 맞춘다. 기본 장비로도 정상 운항 비용을 회수할 수 있고 같은 장비/날씨/시간대에서는 다음 항로의 순수익이 높아야 한다. 단순히 먼 항로라는 이유로 과도하게 인상하지 않는다.

`src/data/voyage-data.js`의 실제 가격을 바꾼다. 1장/5장 구매·잔액 부족·상점 표시는 같은 데이터를 사용한다. 기존 승선권 수량/해금·진행 중 여행·물고기 가격/확률/XP·장비 효과/수리·표시 중 10분 운항은 유지한다. 조기 귀항은 기존대로 가능하며 사용한 승선권은 환불하지 않는다. 귀항 대기/금지/추가 요금은 없다.

## 수익 검증

`scripts/simulate-voyage-fares.mjs`는 실제 어종 풀/연속 추첨 보정/크기별 판매가/장비 마모·수리를 읽는다. 입력/결과 처리를 0/3/8초로 바꾸어 네 항로×열 장비×12개 시간·날씨 조건의 정적 수익과 실제 랜덤 운항을 검사한다. 모든 입력 속도에서 같은 조건의 다음 항로 순수익이 더 높아야 한다.

입력 처리 3초, 기본 낚싯대로 정상적인 10분 운항을 하는 정적 조건 모델의 승선비 차감 후 예상 수익:

| 항로 | 예상 순수익 범위 |
| --- | ---: |
| 얕은 바다 | 약 4,300~6,000 |
| 중간 바다 | 약 7,100~10,000 |
| 심해 | 약 9,800~13,300 |
| 빙하 해역 | 약 13,000~20,500 |

방치/취소/낚시 실패/매번 다른 조작 속도에 대한 수익 보장이 아니다. 이동 15초/항구·판매 45초, 유료 장비의 손상과 수리 비용을 반영한다. 운항 중 파손 시 모델이 기본 장비를 직접 선택하고 귀항 후 선호 장비를 수리한다. 게임의 자동 교체/해상 수리 기능을 추가하는 것은 아니다. 최초 발견 보상은 낚시 수익에 포함하지 않는다.

재현: `node scripts/simulate-voyage-fares.mjs`. 결과 `output/voyage-fares-v1/simulation.json`, 전체 검사 `check.txt`, 실제 매표소 393/320px 검증 `browser/report.json`.

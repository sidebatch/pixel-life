# 하단 도구 빠른 교체 바

후속 가방 농장 탭을 포함한 현재 로컬 빌드는 [FARM_INVENTORY_V1.md](FARM_INVENTORY_V1.md)를 따른다. 아래 수치는 도구 바 구현 단계의 검증 기록이다.

2026-10-15 로컬 구현/검증 완료, **공개 배포 전**. 씨앗 목록/독립 숲 이름 정정과 함께 로컬에 포함한다. 빌드 HTML 20,542,170 bytes/PWA `d87dd4bd1590`. 공개는 직전 `39793b0`/`d3df644ac5ba`다.

화면 하단에 도끼·낚시·낫·검·빈손 5칸을 제공한다. 탭하면 해당 종류에서 가방으로 골라 둔 장비를 장착하고 선택 테두리를 표시한다. 같은 종류의 다른 등급을 고르는 기존 가방 기능도 유지한다. 숫자키 1/2/3/4/5로 각각 전환할 수 있고 키보드 포커스의 Space/Enter도 동작한다.

## UI/장비 계약

- `src/tool-hotbar.js`, `styles/tool-hotbar.css`. 기존 장비 선택 함수와 저장 버전 2를 그대로 사용한다. 교체만으로 아이템/코인/XP/내구도에 영향을 주지 않는다. 저장 실패 시 장착을 복원한다.
- 각 종류의 현재 도구 ID를 표시하며 도끼/낚싯대/낫/검은 실제 캐릭터용 PNG를 재사용한다. 빈손은 기존 손 SVG다. 새로운 도구 원화/캐릭터/리그/무기 크기 규격은 만들지 않는다.
- 기존 조이스틱/원형 행동 버튼의 크기·색·모양은 유지하고 아래 바와 겹치지 않도록 74px 위로 옮긴다. 바는 중앙 정렬, 최대 너비 268px, 5칸, 슬롯 높이 52px이다. 안전 영역을 고려하며 320px에서도 각 슬롯이 최소 44px 너비를 확보한다.
- 가방/상점/대화·발견/보상 창, 낚시·벌목·수확·검 휘두르기, 승선 중에는 교체를 잠근다. 망가진 도끼/낚싯대는 ‘수리’로 표시하고 장착할 수 없다. 기본 도구로 임의 교체하거나 자동 수리하지 않는다.
- 같은 슬롯을 다시 눌러도 반복 저장/효과음을 내지 않는다. 숫자키는 입력 필드/메뉴/동작 중에는 가로채지 않는다. 슬롯의 Space/Enter가 월드 행동까지 실행되지 않도록 분리한다. 걷기 입력은 교체가 지우지 않는다.
- 매 프레임 거대한 PNG URL을 캐시 키에 합치거나 DOM 전체를 다시 만들지 않는다. 도구 ID/소유/파손 변경 시만 슬롯을 재구성하고, 장착/활동 변화는 선택·비활성 상태만 갱신한다.

# 벌목 진행·밸런스 표

기준: 사용자 제공 「Pixel Life 벌목 시스템 최종 설계 문서 v1.3」. 아래 **수치는 첫 플레이 테스트용 임시 밸런스**이며, 구조(도끼 단계로 나무 제한, 완료 보상, 저장, 상점 강화)는 구현 기준이다. 실제 값의 단일 기준은 `src/data/life-content-data.js`다.

후속 방향: [`LONG_TERM_CONTENT_DESIGN.md`](LONG_TERM_CONTENT_DESIGN.md)에서 도끼 10단계와 **낮은 도끼로도 상급 나무를 매우 느리게 벨 수 있는 방식**을 요청했다. 따라서 이 문서의 나무별 최소 도끼 단계는 **현행 구현 설명이지 최종 장기 규칙이 아니다**. 변경 시 기존 철 도끼까지의 도달감, 종별 보상/시간, 부분 HP·저장, 기존 장비 소유권을 함께 검증한다. 내구력·수리 역시 아직 구현되지 않았다.

10단계 이름·단계당 기본 5종(총 50종)의 전 세계 실제/판타지 나무 확장·무료/유료 수리와 고장 시 자동 빈손의 구체적인 **미구현 설계안**은 [`FORESTRY_10_STAGE_DESIGN.md`](FORESTRY_10_STAGE_DESIGN.md)를 본다. 50종 제작 목록은 [`FORESTRY_TREE_CATALOG.md`](FORESTRY_TREE_CATALOG.md)에 있다. `cypress`는 기존 ID·재료 그대로 **편백나무**로 표시하고, 신규 `cedar`가 **삼나무**다. `청금 도끼` 이름은 아직 후속 제안이며 게임에는 `명장의 도끼`가 남아 있다. 기존 22종 구상은 최신 설계가 아니다.

2026-09-29 첫 이미지 연결: 숲 1-1에 오동나무·삼나무 각 3그루를 추가했다. 두 나무는 현행 기본 도끼로 5타, 목재 1~3개, 5분 재생이다. 소나무·버드나무·가문비나무 목재 아이콘도 새 그림으로 연결했다. **50종 카탈로그의 단계 재배치는 아직 적용하지 않았다.** 따라서 버드나무·가문비나무는 현행처럼 철 도끼가 필요하고, 참나무·자작나무와 도끼 제조법도 아래 표 그대로다. 기존 저장 나무의 종과 HP, 목재 ID/수량을 보존하기 위한 순서다.

2026-09-29 두 번째 이미지 연결: 숲 1-2 중간 구역에 은행나무·낙엽송·벚나무를 각 3그루 추가했다. 셋 다 현행 **철 도끼**로 120HP/3타이며, 새 목재·벌목 XP·준의 판매에 연결된다. 편백·자작나무의 목재 그림만 버전 파일로 바꿨고 기존 ID/수량·나무 단계는 유지했다. 아래 표와 별개인 50종 카탈로그의 재배치는 여전히 미적용이다.

2026-09-29 세 번째 이미지 연결: 숲 1-2 북쪽에 밤나무·호두나무·느티나무를 각 3그루 추가했다. 현행 **강철 도끼**로 160HP/4타이며, 목재 1~3개·종별 XP·준 판매가를 연결했다. 단풍나무·활엽수의 목재 그림만 버전 파일로 바꿨으며 기존 ID·수량·나무 HP는 유지했다. `broadleaf`의 플라타너스 표시명 전환은 기존 원화와 맞지 않아 보류한다. 이 3단계는 현행 도끼 3단계와 연결한 임시 수치이며, 장기 10단계 설계의 소프트 난이도 전환이나 기존 수종 재배치는 아니다.

2026-09-29 숲 맵 확장: 기존 1-1·1-2의 나무는 같은 위치·ID·종으로 유지하고, 별도 ID의 나무를 각각 약 60그루 더 배치했다. 1-3·1-4·1-5를 북쪽으로 연결했고 각 맵에는 서로 다른 물가, 낚시 접근 지점, 왕복 출입구가 있다. 1-3은 입구의 기본 수종→중간 철 도끼 수종→북쪽 강철 도끼 수종, 1-4·1-5는 깊이 들어갈수록 강철 도끼 수종의 비중이 높다. 이 세 맵의 나무는 현재 게임에 연결된 **16종만 재사용**하며, 50종 목록의 미제작 수종은 아직 등장하지 않는다. 나무의 HP·도끼 요구·XP·목재/판매가는 **지역이 아니라 종별 기존 값 그대로**다. 숲 다섯 맵 모두 기존 `woodland` 음악과 강 서식지 낚시를 사용한다. 자동 맵 접근성 및 393px 브라우저 화면/저장 복원 검사를 통과했으며 Android 실기 확인은 별도다.

숲 지형 구분: 1-1은 밝은 입구 숲과 개울, 1-2는 어두운 능선과 기존 숲물길, 1-3은 청록빛 계곡·굽이치는 물길과 우회 산책로, 1-4는 서쪽 호수·동쪽 언덕, 1-5는 높은 물웅덩이에서 아래 호수로 떨어지는 움직이는 폭포와 짙은 숲이다. 지형 팔레트·길 구조·물의 형상은 다섯 맵 각각 다르다. 언덕은 현재 **시각적 경사 지형**이며 등반 높이/낙하/고저차 이동 규칙은 없다. 폭포의 물 타일은 걸을 수 없고 하류의 낚시터는 걸어서 접근할 수 있다. 기존 1-1·1-2의 나무 위치와 저장 HP, 장비·수종 밸런스는 바꾸지 않았다.

명장의 도끼 재료는 강철 도끼로 얻을 수 있다. 현재 4단계 나무는 없으므로 이 도끼는 기존 숲 나무를 더 빠르게 베는 상위 장비다.

준의 도구점에는 네 도끼가 모두 보인다. 미구매 장비는 각 재료·코인 요구량을 표시하되 실제 구매는 현재 보유 최고 단계의 바로 다음 도끼만 가능하다.

철 도끼 재료는 기본 도끼로 얻고, 강철 도끼 재료는 철 도끼로 얻는다. 따라서 상위 등급 나무를 먼저 베어야 강화되는 순환 잠금은 없다. 도끼 단계는 벌목 레벨과 별도이며, 벌목 레벨이 높아도 미장착 상위 도끼를 대신하지 않는다. 일반 통나무(옛 저장 데이터)는 계속 개당 12코인에 팔고 밭 확장에도 사용하지만 도끼 재료에는 포함하지 않는다.

숲 1-2는 남쪽 입구에서 북쪽으로 진행한다. 입구 주변에도 참나무·소나무·자작나무가 있으며, 같은 종은 숲 1-1과 똑같이 기본 도끼로 벤다. 중급 나무는 중간 구역, 상급 나무는 북쪽 구역(`y≤23`)에서 생성한다. 단풍나무의 붉은 잎과 가문비나무의 청록색 가지는 참나무·소나무와 한눈에 구별되도록 별도 그림을 사용한다.

완전히 벴을 때 해당 나무 통나무 1~3개와 종별 XP를 한 번만 준다. 중간 타격은 보상이 없고 남은 HP를 저장한다. 벤 나무는 현실 시간 5분 후 재생하며 게임을 꺼도 시간이 흐른다. 준의 도구점 `도끼` 탭에서 다음 도끼·재료·코인 정보를 보여주고 구매한다. 구매는 보유 도끼만 늘리며 자동 장착하지 않는다. 가방 장비 탭에서 직접 도끼를 장착해야 벌목 동작과 나무 단계에 반영된다. 평상시 캐릭터 위에 떠 있던 도끼 레이어는 숨긴다. 벌목 중에는 새 캐릭터 4방향 × 준비·휘두름 8칸 스프라이트와 현재 도끼 이미지를 결합한다. 준비 270ms 후 휘두름 타격 프레임에 피해·체력바·나무 조각·효과음을 함께 적용하고, 전체 동작은 700ms 유지한다.

다음 플레이 테스트에서 확인할 값: 나무 1~3개 드롭의 확률 분포, 5분 재생 시간, 도끼 비용과 단계별 소요 시간, 종별 XP·판매가, 벌목 모션의 손·도끼 결합감. 벌목 Lv.1–20 XP 곡선은 기존 성장 곡선의 기준으로 유지했고, Lv.21 이후는 임시 수치다. 이번 초기화 버전은 이전 저장을 자동 불러오지 않는다.

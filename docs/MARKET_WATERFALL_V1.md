## 구매·수리 소리

- 낚싯대·도끼 구매: 해당 장비의 짧은 나무/금속 소리와 코인 지출 소리.
- 낚싯대·도끼 수리: 짧은 작업 타격 세 번과 마무리음. 장비 종류에 따라 음색을 다르게 한다.
- 귀환석·씨앗·승선권 구매: 짧게 내려가는 코인 소리만 재생한다.
- `src/fishing-effects.js`의 기존 Web Audio 경로와 sweep/noise 함수를 재사용하는 합성음이다. MP3/새 자산·별도 네트워크 요청은 추가하지 않는다. 독립된 고정 노이즈 시드를 사용해 게임의 Math.random 추첨 순서를 바꾸지 않는다.
- 시장/매표소의 실제 결제 저장 성공 뒤 한 번만 호출한다. 코인/재료 부족·비활성 버튼·저장 실패/복원에는 재생하지 않는다. 거래 함수 내부에 넣지 않아 시뮬레이션·저장 복구·자동 검사에서 소리가 발생하지 않는다.
- 구매·수리·가격·재료·내구도/장착·저장 계약은 유지한다. 수리/구매가 장비를 자동 장착하지 않는다. 오디오가 사용 불가여도 구매를 취소하지 않는다.

## 움직이는 폭포

이전에는 정지 폭포 그림 위의 작은 반짝임 9개만 움직여 물줄기 전체가 멈춘 것처럼 보였다. 기존 `drawForestWaterfalls`에서 바위/이끼 그림은 고정하고 물이 흐르는 좁은 영역을 클리핑한다. 기존 그림의 물 텍스처를 아래로 스크롤하고 빠른 물결 18개, 하단에 퍼지는 포말·튀는 물방울을 추가한다. 원본 PNG를 왜곡하거나 바위 전체를 흔들지 않는다.

공통 폭포 렌더러에 적용하므로 폭포 계곡과 같은 그림을 쓰는 숲 폭포도 흐른다. 화면 밖에서는 기존대로 그리기를 생략한다. 매 프레임 새 캔버스/픽셀 읽기/배치 생성/랜덤 추첨을 하지 않는다. 동작 줄이기 설정에서는 물줄기·포말·물안개 시간을 모두 0으로 고정한다. 지형/물/충돌/출구/나무/낚시 위치·어종·캐릭터·카메라 데이터는 그대로다.

## 검증

`scripts/qa-market-waterfall-browser.mjs`는 393/320px의 실제 구매/수리 버튼으로 낚싯대/도끼/귀환석/씨앗/승선권을 확인한다. 각 거래에서 저장 실패 후 무음·전체 거래 상태 복원, 성공 후 정확히 한 번 재생, 잔액 부족 무음을 확인한다. 실제 OfflineAudioContext로 다섯 음색의 파형/에너지·피크·꼬리 종료·구분을 검사한다.

같은 폭포의 시각만 230ms 바꿔 물 영역의 픽셀 변화와 바위 고정을 비교하고, 동작 줄이기에서는 차이가 0인지 검사한다. 그리기 전후 게임 상태/충돌 불변·프레임 시간도 확인한다. 결과 `output/market-waterfall-v1/{check.txt,browser/report.json,browser/waterfall-393.png,browser/waterfall-320.png}`.

393/320px에서 모두 통과했다. 물 영역 13,282개 픽셀이 변화하고 바위 영역 변화는 0, 동작 줄이기 변화도 0이었다. 다섯 합성음 모두 실제 파형이 있고 피크는 0.14 미만이며 끝난 뒤 소리가 남지 않는다. 브라우저 오류 없음. 실제 스피커/기기 청취를 수행한 것으로 표현하지 않는다.

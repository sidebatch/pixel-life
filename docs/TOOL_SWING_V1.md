# 손에 든 장비의 허공 휘두르기 v1

2026-10-19 사용자 요청으로 로컬 구현·검증. **아직 공개 배포 전이다.**

도끼 10종·낚싯대 10종·기본 낫·기본 검, 현재 장착 가능한 손 장비 22개를 빈 공간에서 행동 버튼 또는 Space/Z로 휘두를 수 있다. 현재 장착한 품목의 실제 PNG를 쓰며 빈손·의상·가방은 무기로 취급하지 않는다. 소유한 상위 품목도 같은 동작군을 사용한다.

## 동작과 기존 활동

- 낚싯대는 별도 rodSwing 동작이다. 기존 chop 몸/오른손 좌표와 검 동작의 사방향 궤적을 재사용하고 낚싯대 길이 48·축 직각 폭 2배를 적용한다. 실제 낚시 fish 자세·휴대 길이·찌 끝점은 바꾸지 않는다.
- 낫의 허공 동작은 실제 수확과 같은 sickle 자세를 쓰며 대상 밭은 없다. 검·도끼의 기존 자세/각도/길이는 유지한다.
- 준비 270ms, 전체 700ms의 기존 박자를 따른다. 동작 중 이동·교체/연타 재시작은 기존 공통 잠금으로 막는다.
- 허공 동작에는 나무/밭 대상이 없어 자원·코인·XP·내구도·발견 기록·저장·게임 추첨 난수를 변경하지 않는다.
- 물가에서는 기존 낚시가 우선하고, 다 자란 인접 밭에서는 낫으로 실제 수확한다. 대화/출구/상점/밭 관리의 기존 상호작용도 우선한다.
- 나무 앞에서 검·낚싯대·낫은 휘두르되 나무에는 피해를 주지 않는다. 도끼는 기존 단계/소유/내구도 규칙으로 벌목한다.
- 이동·메뉴·대화·낚시·승선/보상/발견·이미 휘두르는 동안에는 새 허공 동작을 시작하지 않는다. 파손된 낚싯대/도끼는 사용할 수 없다.

## 변경 위치와 규격

src/tool-swing.js의 startHeldToolSwing과 ROD_SWING_ACTION, interactions.js의 대상 없는 행동/나무 앞 처리, character.js의 rodSwing 자세 선택·기존 레이어 합성을 연결했다. index.html과 검사 목록에 새 런타임 모듈을 등록했다.

사용자 요청에 따른 호환 확장을 character-standard-v5.json의 approvedExtensions.held-tool-free-swing-v1에 기록했다. 기존 renderer 해시를 남기고 새 해시를 등록했으며, geometryHash·기존 도구 좌표·PNG·발 기준·손 피벗·기존 검/낫/도끼/낚시 변환은 바꾸지 않았다. 기존 규격 검사를 완화하지 않는다.

## 검증

scripts/qa-tool-swing-browser.mjs는 격리된 저장을 사용하는 320/393px 모바일·PC 1280px에서 실제 행동 버튼/Space, 22장비×남녀×사방향=화면당 176회 휘두르기와 준비/타격 352프레임을 확인한다. 기존 480개 자세/도구 변환을 직전 커밋의 렌더러와 비교한다.

허공 동작 전후 저장 상태/실제 저장 문자열·내구도·재화·XP·게임 난수 불변, 연타/잠금·파손/빈손 차단, 나무 무피해·물가 낚시·실제 낫 수확을 확인했다. 실제 캐릭터 합성 시트도 검토했다. 관련 캐릭터·검 규격 검사와 전체 검사 결과는 output/tool-swing-qa에 보존한다. 모바일 크기 검사를 실제 Android 손 조작 검사로 표현하지 않는다.

작업 시작 전부터 존재하던 숲 배치 관련 미커밋 변경은 별도 작업이다. 이번 모션 추가와 혼동하거나 함께 배포했다고 기록하지 않는다.

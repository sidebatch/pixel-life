# 벌목·농사 이미지 규격

2026-09-24 기준. 현재 게임에서 쓰는 생활 콘텐츠 PNG는 모두 투명 배경의 독립 파일이다. 게임 타일은 48×48이며 원본 비율을 유지한 채 Canvas에서 픽셀 스냅으로 그린다.

| 용도 | 파일 | 게임용 크기 | 사용처 |
|---|---|---:|---|
| 숲의 살아 있는 나무 8종 | `assets/forestry/trees/*.png` | 120×144 | 숲의 장식·벌목 나무 |
| 벌목 후 그루터기 8종 | `assets/forestry/stumps/*.png` | 96×96 | 해당 나무가 재생되기 전 |
| 통나무 아이템 | `assets/forestry/items/log.png` | 96×96 | 가방·상점 |
| 현재 판매하는 씨앗 4종 | `assets/farming/seeds/*.png` | 96×96 | 엘리 상점·가방·밭 심기 창 |

사용자 제공 `Trees.zip`에는 살아 있는 나무 8종과 그루터기 7종, 통나무 그림이 있었다. 실제 PNG 이름이 무작위이므로 숲의 8종을 참나무·소나무·자작나무·단풍나무·가문비나무·버드나무·삼나무·넓은 활엽수 순서로 게임에 매핑했다. 빠진 삼나무 그루터기 1종은 기존 삼나무와 다른 그루터기를 스타일 참조로 새로 만들었다. 큰 원본은 최근접 보간으로 위 게임 규격에 맞추었고 원본 압축 파일은 변경하지 않았다.

`Seeds.zip`의 이름이 붙은 96×96 PNG 중 현재 게임에 작물 데이터가 있는 당근·감자·옥수수·딸기만 가져왔다. 나머지 여섯 씨앗은 아직 게임 작물·수확물이 없으므로 기능을 임의로 추가하지 않았다. 수확 작물과 밭 위의 성장 단계 이미지도 이번 ZIP에는 없어 기존 이모지·Canvas 표현을 유지한다. 후속 이미지가 오면 씨앗을 수확물 그림으로 재사용하지 말고 별도 PNG로 연결한다.

빌드 검사에서 21개 새 이미지의 PNG 형식·크기·알파 채널과 참조 경로를 확인한다. 숲의 나무 종과 나무 상태는 `src/data/region-maps.js`와 `src/rendering.js`가 선택한다. 씨앗·통나무 아이콘은 `src/assets.js`와 `src/life-content.js`의 공용 마크업을 통해 상점·가방·밭 창에서 공유한다.

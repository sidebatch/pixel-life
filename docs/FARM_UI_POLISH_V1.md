2026-10-13 사용자 요청: 밭 번호 숨김, 양파이 등 조사 오류 수정, 씨앗을 심은 뒤 설명창을 계속 띄우지 않기, 공개 배포.

## 적용 규칙

- 화면 제목의 `밭 1`/`밭 2` 등 번호를 제거했다. 구매 전 부지는 `부지 구매`, 빈 밭은 `씨앗 심기`, 심은 밭은 작물 이름을 표시한다. 내부 밭 ID/좌표/소유/작물 저장은 유지한다.
- 작물 이름의 마지막 한글 받침에 따라 이/가를 선택한다. 성장 안내와 수확 가능한 상태 양쪽에 적용한다. ‘당근이’, ‘순무가’, ‘감자가’, ‘양파가’, ‘양배추가’, ‘밀이’, ‘옥수수가’, ‘토마토가’, ‘딸기가’, ‘호박이’로 표시한다.
- 수확 버튼은 `낫으로 수확하기`로 표시한다.
- 씨앗 한 개를 실제로 소비하고 심은 상태의 저장이 성공한 뒤 창을 닫는다. 짧은 심기 완료 알림만 남고 이동이 가능해진다. 다시 `작물 살펴보기`를 선택하면 성장시간을 확인할 수 있다.
- 심기/저장이 실패하면 선택창을 유지하고 기존 원자적 롤백으로 씨앗/밭 상태를 보존한다. 닫힌 창의 뒤로가기 이력도 정리한다.
- 밭 상시 이동 차단/통로에서의 심기·낫 수확/씨앗 가격·성장시간·수확량·농장 구매 비용은 유지한다. 새 낫 v2와 남녀 캐릭터도 유지한다.

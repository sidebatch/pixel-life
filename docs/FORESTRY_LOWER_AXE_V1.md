# 상위 도끼 획득 후 하위 도끼 대체 벌목

2026-10-16 후속 승인: 단계 차이별 위력 **40% / 25% / 15% / 10%**로 수정했다. 최초 로컬 구현은 2026-10-15다. **공개 배포 전**이며 기존 공개는 `57317c4`(게임 변경 `97e11ef`, PWA `6ea80bf54583`)다.

## 규칙

- 한 번 획득한 도끼의 최고 단계까지 나무가 해금된다. 구매 가능 상태나 벌목 레벨만으로는 해금되지 않는다. 처음에는 해당 도끼를 실제로 획득해야 한다.
- 획득한 상위 도끼가 파손돼도 기존 `ownedAxeIds`를 기준으로 해금을 유지한다. 저장 버전 2와 기존 보유 기록을 사용하며 새 해금 필드나 저장 이관은 만들지 않는다.
- 장착 도끼보다 나무가 1/2/3/4단계 이상 높으면 **해당 도끼 원래 피해량의 40%/25%/15%/10%**를 적용한다. 감점률은 60%/75%/85%/90%다. 4단계 이상은 10%로 유지하며 소수점은 버리고 최소 피해는 1이다. 같은 단계 또는 낮은 나무에는 원래 피해량을 적용한다. 처음 제안한 고정 40% 방식은 사용자 후속 승인으로 대체했다.
- 파손된 도끼 자체는 사용할 수 없다. 가방에서 정상인 하위 도끼를 직접 골라 이어서 벤다. 부분 HP/기존 소유/마모·파손/수리·선택/저장을 유지한다. 나무 단계별 타격 내구도 소모도 그대로이므로 낮은 유료 도끼는 많은 타격으로 더 빨리 파손될 수 있다.
- 나무 옆 행동 안내에 실제 단계 차이에 따라 `벌목 · 위력 -60%/-75%/-85%/-90%`를 표시하고, 도끼 상세에 단계별 위력 규칙을 설명한다. 아직 미해금인 나무는 필요한 도끼 안내를 유지한다.
- 타격/완료 효과음과 보상 판정 모두 실제 감점 피해량을 사용한다. 목재 0~3개 확률, 경험치, 최초 발견, 마지막 타격 보상, 수리비/마모량/상점 레시피는 변경하지 않는다. 실패한 저장은 타격/마모/보상을 복원한다.

예: 단풍나무 HP 120은 철 도끼(50)로 3회, 철 도끼 획득 후 기본 도끼(20→8)로는 15회 필요하다. 태초 단계 HP 3,000은 태초 도끼(620)로 5회, 바로 아래 별빛 도끼(450→180)로 17회, 기본 도끼(20→2)로 1,500회가 필요하다. 같은 나무의 보상은 그대로이며 수리를 통한 정상 도끼 사용이 빠르다.

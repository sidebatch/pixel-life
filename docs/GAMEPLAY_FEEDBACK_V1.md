## 적용 내용

- 완전 벌목 때 50종 모두 `목재 이름 +N개`를 표시한다. 0개도 `+0개`로 명시한다. 최초 발견/수집 보상/레벨업 창이 가릴 때는 큐에 보관하고 닫힌 뒤 표시한다. 일반 경험치 바와는 함께 표시할 수 있으므로 계속 벌목할 때 경험치 알림이 끝나기만을 기다리지 않는다. 마지막 타격에 도끼가 망가지면 같은 알림에 획득 수량과 수리 안내를 함께 표시한다. 부분 타격은 조용하게 유지하고 저장 실패 때 획득 알림을 넣지 않는다.
- 귀환석은 라일락 마을 중앙 광장 `(25,24)`, 아래 방향으로 도착한다. 마을 안에서도 1개를 소모한다. 실패 시 아이템/이전 지역·좌표/운항 상태를 복원하는 기존 처리는 유지한다. 새 게임 시작점과 숲 입구는 변경하지 않았다.
- 유한 내구도 도끼/낚싯대는 가방 장비 카드와 상세 창, 하단 도구 바에 막대를 표시한다. 50% 이하는 노랑, 20% 이하는 빨강, 파손은 빈 막대와 수리 상태다. 기본 무한 도구·낫·검·외형에는 막대를 만들지 않는다. 하단 바는 내구도 값/색/너비만 갱신하고 마모마다 슬롯 DOM을 재구성하지 않는다. 수치 `현재 / 최대`도 접근성 속성·툴팁·상세 설명으로 제공한다.
- 낚싯대 10종의 축 직각 두께를 2배로 표시한다. 월드/캐릭터, 가방/상세, 상점, 행동 버튼, 하단 바에 함께 적용한다. 각 도구의 기존 색/릴/장식과 실제 PNG를 사용한다. 손잡이 중심·축 길이·끝점·낚싯줄 연결과 남녀 공통 몸/손/동작 좌표는 유지한다. 기존 PNG를 덮어쓰거나 새 에셋을 만들지 않았다. 사용자 요청에 따른 표시 확장을 `character-standard-v5.json`의 `rod-width-presentation-v1`에 기록하고 렌더러 해시를 고정했다.
- 폭풍 번개는 매번 위치·길이·꺾임 수·방향·1~3개 가지·발생 간격/지속시간이 달라진다. 한 번의 번개가 보이는 동안 모양은 고정한다. 4.8초 창 안에서 시차를 두고 300~500ms 표시하며, 게임 추첨용 `Math.random`을 소비하지 않는다. 동작 줄이기에서는 번개와 번쩍임을 표시하지 않는다.

목재 0/1/2/3개 확률·경험치, 장비 능력치/마모량/수리비, 물고기 추첨·경제는 바꾸지 않았다. 저장 버전 2를 유지하며 초기화/이관은 필요 없다.

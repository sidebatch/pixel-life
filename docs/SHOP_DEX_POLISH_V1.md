## 사용자 요청과 현재 동작

- 씨앗 목록에서 성장시간과 ‘농장 부지에 심는 씨앗’ 설명을 제거했다. 이름·보유 수량·가격·구매 버튼과 농사 레벨은 유지한다. 재배 시간·가격·수확량은 변경하지 않았다.
- 나무에 인접하면 하단에 생기던 6×8px 노란 표시만 제거했다. 벌목 가능 여부는 기존 행동 버튼에서 확인하며, 타격·손상 HP 표시와 동작은 유지한다.
- 마을 엘리는 물고기 판매·낚싯대 구매/수리만 담당한다. 햇살 농장 입구에 하루의 농사 상점을 추가하여 씨앗·작물 판매·농장 주문·꾸미기를 옮겼다. 하루에게 말을 걸거나 농가 문을 바라보면 같은 상점이 열린다. 메뉴는 2열×2줄이다.
- 물고기·목재·작물 판매 행마다 ‘전부’ 바로 옆에 ‘취소’를 제공한다. 취소는 그 행의 선택 수량만 0으로 바꾸고 다른 행의 선택, 재고, 코인은 유지한다. 전체 합계와 판매 버튼 상태는 즉시 갱신하며, 0개일 때 취소를 비활성화한다.
- 후속 상점 UI 정리: 판매 카드는 그림과 이름/보유 수량/단가/‘판매 합계’를 하나의 상단 행에 모으고, 수량·전부·취소는 구분선 아래 전체 너비를 사용한다. 금액이 오른쪽 아래에 따로 떨어지거나 그림 아래 빈 열이 남지 않는다. 그림은 상단 상품 정보의 세로 중앙에 배치한다. 씨앗/귀환 도구 가격은 ‘구매 · 12코인’ 형태로 구매 버튼 안에 넣고, 하단 전체 판매 합계에도 코인 단위를 표시한다.
- 도감 항목을 누른 상세 카드는 이미지·이름을 중앙에 크게 배치한다. 물고기 이미지 190×166px, 나무 172×200px로 기존 68×58/82×104보다 크게 표시한다. 작은 화면에서는 내용만 스크롤하고 닫기 버튼은 위에 유지한다. 미발견 물고기는 ?/???, 미발견 나무는 실루엣/???로 유지한다.

## 저장·상점 권한

`MARKET_SHOPS.haru`는 seeds/crops/orders/decorations, elli는 fish/rods, workshop은 wood/axes다. 기존 원격 `farm`은 꾸미기만 제공한다. 씨앗 구매·작물 판매·주문 납품·교환권 교환 함수도 새 상점으로 연결하여 숨긴 메뉴를 우회해 엘리에서 농사 거래할 수 없게 했다.

저장 키/버전/작물 ID/성장/주문 ID·요구량·보상·교환권·소품 소유/설치는 변경하지 않는다. 진행 중인 주문은 새 상점에서도 동일하게 유지하며 새로 추첨하지 않는다. 납품 단계·경제·레벨·저장 실패 롤백도 유지한다.

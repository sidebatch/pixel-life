# 사냥 지역 10곳 · 몬스터 구성안

작성일: 2026-10-22 · **개정 6: 왜가리·아르마딜로 교체, 우두머리 외형 구분** · 상태: 이름·전투 기획 / 외형·탐방 로컬 구현

같은 날 [던전 외형·탐방 v1](DUNGEON_VISUAL_PREVIEW_V1.md)에서 아래 60종의 그림과 10지역 출입을 구현했다. 기존 동물 5종 외에 새 55종의 전투·드롭은 아직 구현하지 않았다. 아래 전투 설명은 후속 기획이며 공개 배포 전이다.

숲·골짜기·폐광·성소처럼 장소의 분위기로 사냥 지역을 나눈다. 지역마다 **일반 5종 + 보스 1종**, 전체 **일반 50종 + 보스 10종 = 60개 몬스터 항목**으로 구성한다. 기존 야생동물 5종을 포함한다.

전투는 **접근 → 직접 공격 → 이동해서 피하기**를 기본으로 유지한다. 플레이어와 몬스터 모두 마법 공격을 도입하지 않는 것을 이번 안의 기준으로 삼는다. 몬스터는 물기·돌진·앞발·무기·몸통·돌이나 화살 같은 물리 공격을 사용한다. 판타지 외형은 살리고, 모바일에서 이동과 행동 버튼만으로 상대할 수 있게 단순하게 설계한다.

## 1. 요청 반영과 적용 범위

| 구분 | 기준 |
| --- | --- |
| 유지할 요청 | 환경에 맞는 사냥 지역 10곳, 지역마다 몬스터 5~6종의 문서 기획 |
| 이번 수정 | 사용자 지정 8종 이름 반영 및 참고 자료 삭제. 영어 이름·구성·전투 방식은 유지 |
| 보스 이름 | 한국어 2~3글자의 고유명. 종족·긴 수식어는 이름 대신 설명에 기록 |
| 일반 몬스터 이름 | 알아보기 쉬운 동물 이름과 익숙한 판타지 종족 이름을 혼용. 한국적인 합성어를 모든 종에 붙이지 않음 |
| 현재 공개판 | 들녘 사냥터 1곳, 멧돼지·사슴·여우·늑대·곰 5종, 공격받은 개체만 반격, 양쪽 명중률 60% |
| 후속 설계 | 첫 지역의 전투·전리품·철검은 [들녘 숲 수치 표](HUNTING_MEADOW_BALANCE_V1.md)에 검토용 초안 작성. 실제 검증·적용과 나머지 지역 수치는 후속 단계 |

**지역마다 대표 던전 1개, 총 10개**를 계획한다. 숲·골짜기도 사냥 구역이라는 의미에서 던전에 포함하며 층수와 방 개수는 미정이다. D01~D10은 문서 식별 번호다. 실제 지역 이름에는 붙이지 않는다.

첫 지역은 현재 들녘 사냥터를 활용하는 방향을 제안한다. 기존 저장 키 `wildwoodHunt`나 벌목 숲 12개 지역을 교체하는 계획은 아니다. 현재 구현은 [들녘 사냥터](HUNTING_GROUND_V1.md), [전투 피드백 v2](HUNTING_TERRAIN_COMBAT_V2.md), [지형 v3](HUNTING_DYNAMIC_MUSIC_V3.md)를 따른다.

## 2. 이름과 모바일 전투 기준

### 이름·영문 표기

몬스터별 표에 적힌 한국어·영어 이름을 기준으로 사용한다. 기본 영어식 이름에 아래 사용자 지정 표기를 반영하며, 하나의 번역 규칙으로 다시 일괄 변경하지 않는다.

| 한국어 표시 이름 | 영어 표시 이름 |
| --- | --- |
| 바위거북 | Rock Turtle |
| 케이브뱃 | Cave Bat |
| 크록 | Croc |
| 스카랍 | Scarab |
| 북극토끼 | Snow Hare |
| 북극여우 | Snow Fox |
| 아이스뱃 | Ice Bat |
| 발록 | Valrok |

나머지 이름과 영어 60항목은 유지한다. 문서 ID는 이름이 바뀌어도 유지하며, 구현 시 표시 이름을 저장 ID로 사용하지 않는다. 한국어·영어 표시 문구를 분리하고, 종족과 긴 별칭은 상세 설명에 둔다.

### 모바일에서 사용할 공격

| 사용 | 이번 구성의 범위 |
| --- | --- |
| 근접 | 물기, 뿔 밀기, 발톱, 앞발, 몸통, 꼬리, 검·창·곤봉 공격 |
| 이동 공격 | 방향을 먼저 보여주는 짧은 돌진·도약. 이동 버튼으로 피할 수 있는 속도와 폭 |
| 물리 원거리 | 일부 몬스터만 돌·가시·화살 사용. 적의 방향과 발사 동작으로 알아볼 수 있게 설계 |
| 방어 | 등껍질·방패로 잠깐 버티기. 물리적인 자세 변화가 보이고 공격할 빈틈이 있음 |
| 이번 범위에서 제외 | 주문·혼불·전기·얼음탄·마법진·보호막·회복/강화 지원·소환·부활·순간이동·원소 저항 |
| 상태 이상 | 독 지속 피해·빙결·감전·행동 불가·조작 반전도 도입하지 않음 |

일반 몬스터는 **주 공격 1개**, 보스도 **주 공격 1개와 선택적인 보조 공격 1개 이내**를 기본안으로 한다. 빠른 연속 회피, 패턴 순서 암기, 별도 회피 버튼, 정밀 조준과 스킬 버튼을 요구하지 않는다. 물리 원거리 공격은 몬스터의 패턴이며 플레이어에게 활이나 조준 조작을 새로 추가하는 제안은 아니다.

후반 난도도 화면 전체 효과와 많은 장판보다 **적의 사거리·준비 동작·공격 후 빈틈과 지형 배치**에서 만든다. 구체 속도·피해·공격 폭은 실제 모바일 이동 속도로 검증한 뒤 정한다.

### 진행 방향

**숲 → 골짜기 → 뿌리굴 → 폐광 → 습지 → 협곡 → 산굴 → 묘지 → 성소 → 유적**으로 새로운 형태와 공격을 조금씩 소개한다. 마을의 기존 사냥터 입구에서 시작해 탐험로에서 분기하는 구성을 우선 검토한다. 실제 연결·해금·필수 보스 처치 여부는 후속 결정이다.

지역 이름의 독안개·서리·별은 배경 분위기다. 독 피해·빙결·별 마법을 뜻하지 않는다. 해골과 움직이는 석상 같은 판타지 생물도 공격은 물리적으로 표현한다.

## 4. 지역별 몬스터 상세

각 표는 목표 설계다. 기존 동물의 새 돌진도 아직 구현된 기능으로 보지 않는다. N1~N5는 일반, B는 보스이며, 종족 설명은 표시 이름에 매번 붙이지 않는다.

### D01. 들녘 숲

**분위기:** 마을 근처의 밝은 숲. 기존 길·군락·바위·거목과 동물 원화를 활용한다. **대표 생물:** 멧돼지. **보스:** 브락, 검은 갈기·높은 어깨·돌 같은 등갑과 네 개의 큰 엄니를 가진 멧돼지 왕. 갈색 일반 멧돼지와 색·실루엣을 구분한다.

| --- | --- | --- | --- | --- | --- |
| D01-N1 | 멧돼지 | Boar | 낮은 몸과 짧은 엄니·돌진 | 땅 긁기 → 짧은 정면 돌진 | 옆으로 피하고 멈춘 뒤 반격 |
| D01-N2 | 사슴 | Deer | 넓은 뿔과 가는 다리·전방 견제 | 머리 낮추기 → 뿔로 밀기 | 정면을 벗어나 옆에서 접근 |
| D01-N3 | 여우 | Fox | 작은 몸과 긴 꼬리·짧은 도약 | 몸 웅크리기 → 뛰어 물기 | 착지한 뒤 반격 |

**지형·배치:** 입구에서 한 종씩 소개하고 깊은 공터에 브락을 배치한다. 공터에 옆으로 피할 공간과 출구를 확보한다. 기존 5종과 사방향 원화는 재사용하고, 이번 이름 제안 때문에 기존 동물 ID를 바꾸지 않는다.

## 5. 공통 전투·배치 원칙

- **공격받은 개체만 반격**한다. 플레이어가 실제 피해를 주기 전에는 보스를 포함해 선공하지 않는 것을 기본으로 한다. 빗나감이 중립 개체나 주변 무리를 깨우지 않는다.
- 현재 플레이어·동물의 **명중률 60%**를 계승한다. 범위·거리·벽을 먼저 확인하고 한 번의 공격에 판정을 반복해 사실상 반드시 명중하게 만들지 않는다.
- 돌진·물리 투사체·방패 방어는 아직 새 기능 제안이다. 기존 동물의 그림만 전진하는 모션을 실제 돌진 이동으로 간주하지 않는다.
- 준비 동작 때 공격 방향이 보이고, 타격 뒤 반격할 시간이 있다. 플레이어를 향해 공격 도중 급회전하거나 계속 추적하는 방식은 피한다.
- 보스의 큰 공격도 이동 버튼으로 피할 수 있어야 한다. 짧은 시간에 두 번 연속 피하기, 패링, 정밀한 스킬 타이밍을 필수로 만들지 않는다.
- 비행 생물·슬라임·석상도 벽을 통과하지 않는다. 적의 몸과 공격이 닿는 곳을 원화와 실제 판정에서 맞춘다.
- 입구는 쉬는 공간으로 두고, 길·공터·엄폐·우회로를 연결한다. 모든 개체의 접근 위치, 복귀 경로와 출구까지 이동 가능해야 한다.
- **6종은 한 던전의 종류 수**다. 한 화면에 6종을 모두 넣거나 동시에 6마리와 싸우게 한다는 뜻은 아니다. 처음에는 한 종씩 소개한다.
- 실제 모바일 화면에서 손가락·조종키가 공격 예고를 가리지 않는지 확인한다. 밀집 전투·작은 투사체·비슷한 배경색만으로 난도를 올리지 않는다.
- 장식용 안개·눈·발광 수정은 공격 예고보다 약하게 표시한다. 배경 분위기 때문에 피해나 상태 이상이 발생하지 않는다.

## 6. 이미지·규격 방향

현재 게임과 같은 픽셀 밀도, 외곽선, 위에서 내려다보는 시점, 발 기준과 그림자를 사용한다. 판타지 이름은 허용하되 다른 게임의 고유 캐릭터나 원화를 복제하지 않는다. 일반 몬스터는 **몸 구조·소도구·공격 자세로 구별**하고 보스는 얼굴·엄니·갈기·부서진 갑옷 같은 고유 표식을 더한다.

| 대상 | 제작 방향 |
| --- | --- |
| 기존 동물 5종 | 현재 원화와 사방향 공격 자세 활용. 새 패턴에 필요한 자세만 검토 |
| 신규 일반 45종 | 물리 공격이 몸과 도구에서 읽혀야 함. 주문 시전 자세나 마법 효과에 의존하지 않음 |
| 보스 10종 | 짧은 이름과 기억에 남는 얼굴·실루엣. 몸집만 크게 늘려 완성하지 않음 |
| 지역 10곳 | 숲·이끼·뿌리·광차·갈대·붉은 바위·얼음·묘비·제단·별 수정으로 다른 지도 아이콘 |
| 공격 예고 | 몸을 낮추기·팔 들기·꼬리 당기기 등 큰 동작 우선. 필요 시 단순한 방향 표시 보조 |
| 이름 표시 | 한국어·영어 전환을 고려해 이름과 종족 설명 분리. 긴 별칭을 보스 머리 위에 붙이지 않음 |

현행 동물 공격 시트는 **96px 셀, 발 기준 y=90, 사방향 192×192 아틀라스**다. [현행 공격 원화 기준](HUNTING_ATTACK_MOTION_V1.md)을 출발점으로 삼는다. 큰 보스에 별도 규격이 필요하면 몬스터용 계약을 먼저 정의하고, [플레이어·NPC 규격](CHARACTER_ASSET_STANDARD.md)은 유지한다.

대기·이동·준비·타격·복귀·피격·처치 자세를 종별로 검토한다. 실제 모바일 화면에서 네 방향 공격의 시작과 끝을 알아볼 수 있는지 확인한 뒤 등록한다. 신규 판타지 생물이 기존 캐릭터·도구 크기를 바꾸는 이유가 되어서는 안 된다.

## 7. 지역 보상 방향

아래는 후속 제안이다. 현재 사냥터에 드롭·수렵 레벨·판매 보상이 구현되어 있다는 뜻은 아니다. 이름 변경에 맞춰 보스 표식도 짧은 고유명을 사용한다.

| 지역 | 재료·표식 후보 | 재방문 목적 후보 |
| --- | --- | --- |
| 들녘 숲 | 숲의 흔적, 브락 표식 | 초보 사냥 의뢰·동물 장식 |
| 이끼 골짜기 | 이끼석, 토르가 등껍질 | 돌길·연못 장식 |
| 뒤엉킨 뿌리굴 | 마른 뿌리, 루고 표식 | 뿌리·버섯 소품 |
| 잿빛 폐광 | 광맥 조각, 그룬 쇠띠 | 광등·광차 소품·장비 재료 후보 |
| 독안개 습지 | 습지 가죽, 모그라 이빨 | 갈대·목재 장식 |
| 붉은바위 협곡 | 붉은 비늘, 바스크 표식 | 붉은 돌 소품·장비 외형 |
| 서리송곳 산굴 | 산굴 수정, 보른 갈기 | 겨울 장식·전리품 소품 |
| 고요한 묘지 | 낡은 훈장, 카르덴 문장 | 기록 복원 의뢰·오래된 석물 |
| 잊힌 성소 | 석상 파편, 발록 인장 | 성소 장식·수호자 기록 |
| 별무덤 유적 | 수정 조각, 오르칸 목편 | 유적 장식·후반 반복 의뢰 |

마법 공격을 쓰지 않아도 판타지 소재와 장비 외형·장식 보상은 구성할 수 있다. 재료가 곧 마법 능력을 부여한다는 의미는 아니다. 기존 낚시·벌목·농사 진행을 사냥 재료로 강제 차단하지 않는다.

가격·수량·드롭 확률은 처치 시간, 이동, 피해 위험과 수리비를 함께 시뮬레이션한 뒤 정한다. 초반 재료도 해당 지역의 의뢰와 장식에 계속 사용할 이유를 남긴다.
